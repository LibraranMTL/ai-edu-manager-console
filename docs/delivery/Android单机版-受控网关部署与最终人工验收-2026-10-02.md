# Android 单机版：受控网关部署与最终人工验收

此文档是部署和验收手册，不是已上线、真机通过或完整计划完成的证明。

## 1. 当前源代码接入

Android 的任务 Agent、视觉、知识消化、学习卡片、规划及自动研究共用模型路由。原生系统设置提供受控网关设置；默认关闭。启用后需管理员登记确切学生与设备公钥，客户端用非导出 Android Keystore EC 私钥签名，并提交现有 AIE3 签名许可证。服务器同时验证许可证产品、签名、设备、期限、学生席位、管理员登记、设备签名和一次性 nonce，再签发最多5分钟的凭据。

网关拒绝、撤销、过期和未知结果不自动退回到个人 API Key。普通高级用户仍可明确配置个人接口；两种模式不混淆。关闭网关后应重新配置个人 Key，避免错误地复用切换前凭据。ASR 仍是独立接口、独立凭据、逐次云端授权，不把聊天模型当作音频模型。

## 2. 必须由服务器管理员配置的内容

必须先确认既有正式服务目录、运行用户、Node 版本、HTTPS 代理、备份与启动方式。本仓库没有替用户创建新账号、购买模型服务或登记真实学生。

服务启动环境：

| 环境变量 | 含义 |
| --- | --- |
| `EDU_MODEL_GATEWAY_ENABLED` | 仅明确设置 `1` 才启用；默认关闭 |
| `EDU_MODEL_GATEWAY_REGISTRY` | 管理员维护的授权登记 JSON 绝对路径；位于受限目录，不公开访问 |
| `EDU_MODEL_GATEWAY_ISSUERS` | 受信任许可证签发者公钥文件绝对路径，采用原产品 issuer 格式；只含公钥 |
| `EDU_MODEL_GATEWAY_MODELS` | 允许的真实模型 ID，逗号分隔，不凭名称假定能力可用 |
| `EDU_MODEL_GATEWAY_MONTHLY_LIMIT` | 每许可证月度请求安全上限，默认200次；由管理员配置，不是费用报价 |
| `EDU_MODEL_PROVIDER_ENDPOINT` | HTTPS 完整 `chat/completions` 地址 |
| `EDU_MODEL_PROVIDER_KEY` | 仅服务器进程读取的产品供应商密钥；不放入 APK、源码、文档或普通备份 |

沿用报告服务的 `CLOUD_REPORT_DATA_DIR`、管理员凭据及 HTTPS 反向代理配置。数据目录新增持久化的 `gateway-receipts.sqlite` 和 `gateway-nonces.sqlite`；不得使用内存数据库充当正式回执。网关只接受文本或有界内嵌图片，不允许远端图片 URL、工具角色或任意文件操作。

授权登记格式示例（全部为占位值，不能直接生产使用）：

```json
{
  "schema": "edu-manager.model-gateway-grants.v1",
  "grants": [
    {
      "enabled": false,
      "licenseId": "从真实许可证核验",
      "deviceId": "从设备登记信息核验",
      "studentId": "确切本机学生ID",
      "publicKeyDer": "由客户端登记入口提供的公钥Base64",
      "expiresAt": 0,
      "dailyLimit": 6
    }
  ]
}
```

管理员应通过受信渠道核对设备和学生，再写登记；不自动接受客户端自报公钥。`expiresAt` 是 Unix 毫秒，必须是实际授权期限。授权撤销、到期和额度调整会在后续生成请求重新校验。客户端展示的登记信息不包含激活码或私钥。换机必须重新登记，备份恢复不会复制原设备私钥或网关启用状态。

正式发布采用“确认目标 → 冻结文件与哈希 → 备份 → 隔离暂存上传 → 验证 → 切换 → HTTPS 冒烟 → 回滚演练”。不要根据本地构建成功直接覆盖现有 ECS 服务，更不能把管理员凭据或供应商密钥写到下载页面。

## 3. 本机安全调用上限

代码按整个家庭设备限制月度文本、视觉、研究、ASR 调用次数，另有学习/规划日上限。当前值是保守的本机安全限制，不是已购买的服务器权益，不是费用报价，也不能防止修改系统时钟的恶意客户端绕过。本机失败和未知调用不自动退还安全预留；缓存结果不产生新的供应商调用。正式模型额度以服务器实际授权、持久回执和供应商账单为准。现阶段仍需真实账单确定最终家庭额度和价格。

## 4. 最后人工验收矩阵

用户已要求人工验收放在最后，以下项目未执行前均不得记为通过：

- 至少两台 Android 真机，包含手机/平板、横竖屏、较大字体、TalkBack、后台与省电限制。
- 1.2.6、1.2.7 及已安装候选的覆盖升级，保留学生、项目、资料、收藏、报告、绑定与设置。签名匹配不能替代覆盖安装测试。
- 两名以上学生切换，页面迟到结果、后台任务、云摘要、回收恢复和备份无串档。
- 文件、相机、系统分享、屏幕/课程采集、显式对话与录音的来源登记和原件定位。
- 重复事件、同内容不同来源、Room 首次迁移中止、JSON 副本损坏/缺失、SAF 权限撤销、存储不足和进程终止。
- 真实文本、视觉、结构化输出、联网来源、ASR、取消、限流、未知计费回执；手写、公式、模糊扫描和多页失败恢复。
- 网关拒绝伪造许可证/签名/nonce、错学生、未登记设备、撤销、过期、额度耗尽，不回退个人 Key。
- 报告和摘要真实云端重复上传、撤回不复活、许可撤销、备份恢复；确认 HTTPS 正式目标和服务版本。
- 卡片作答与审核回流、行动历史、分享题目无答案、打印/PDF、选题草稿仍需人工确认。
- 七天连续运行与真实耗电/内存/冷启动测量；四周家庭试点的资料找回、改分类、建议采用和成本数据。

## 5. 签名交付的准确含义

签名 APK 表示该二进制可以进行原证书安装与验收。它不表示完整计划的真实质量、性能、云端及市场闸门已经通过。签名候选、设备验收、正式发行、Git 提交和线上发布必须分别记录。
