# Windows 学生端横屏布局 Demo

这是独立交互原型，不会调用真实学生数据，也没有修改正式 Windows 学生端页面。

## 三版布局

- A 全功能宫格：4 列 × 2 行，全部常用入口一屏可达。
- B 主任务工作台：主操作占 2 列 × 2 行，四个次要入口环绕，推荐作为正式方案基础。
- C 学习路径分区：3 列 × 2 行，按“收集资料—开始学习—查看成长”组织。

直接在浏览器打开 `index.html`，或使用任意静态服务器访问。页面支持通过 `?variant=balanced`、`?variant=focus`、`?variant=path` 直接切换方案。
