# AI教育管家 Android 单机版 1.3.3 产品说明

## 产品定位

Android 单机版面向家庭手机和平板，不依赖 Windows 主机即可管理独立学生档案。主要覆盖资料采集、OCR 与视觉解析、资料消化、课程学习、学习卡片、项目与成果、成长模型、学情报告、云端同步以及加密备份。

应用以当前学生和当前项目为数据边界。原始资料、OCR 正文、候选知识、成长证据和正式报告分层保存；模型生成内容不会绕过来源核验直接成为正式学情结论。

## 1.3.3 主要修复

- 图片已经完成 OCR 时，资料消化会复用已保存且可核验的 OCR 正文，不再反复要求补充或重新识别。
- 修复候选摘录未纳入固定输入校验范围造成的消化失败；失败重试只重置消化任务，不清除成功的 OCR 结果。
- 兼容旧版 U 盘迁移档案的实际目录结构，优先读取“学生姓名学情分析汇总”下的学情报告和成长模型，减少全目录扫描和界面等待。
- “完整教育档案”可只读浏览旧档案中的四份报告文档；内容为空且状态为 `draft` 的模板不会被标记为正式学情报告。
- 数据库、报告和成长数据读取继续在后台执行，避免阻塞主界面。

## 使用边界

- 应用不自动读取第三方 App 的私有对话；用户可在“资料”中主动导入复制、分享或导出的智能体对话。
- 原“AI助手问答”“受控模型网关”“知识与协作”和外部 AI 应用快捷启动已删除。任务 Agent 只服务资料消化、学习卡片、规划候选、成长模型和学情报告。
- 空白历史模板、单次 OCR 或模型推断不能单独证明学生已经稳定掌握知识点。
- 覆盖升级前建议制作加密备份；Debug 或早期不同签名的测试版不能直接覆盖正式版。
