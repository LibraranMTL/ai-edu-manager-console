# Windows 0.9.5 资料处理状态卡死修复

> 发布日期：2026-07-22  
> 升级基线：Windows 0.9.4  
> 配套平板：Android 0.5.8（本次未修改）

## 修复内容

0.9.4 中，旧版资料消化任务可能保留在 `reviewing` 或 `waiting_result`，即使资料业务账本已经显示全部完成，普通页面仍会显示“正在处理”并禁用按钮。

0.9.5 改为：

- “已完成、部分完成、需要帮助”优先由资料业务账本决定；
- 已完成且待处理数量为 0 时，不再受过期任务状态影响；
- 旧消化任务自动迁移到机器校验后自动验收策略；
- 后台自动收口已经校验通过或业务状态已经完成的遗留任务；
- 出现新资料时，即使旧任务曾经成功，也会重新显示“待处理”。

升级后无需删除资料、任务记录或知识库。应用启动后通常在 5 秒内完成旧任务状态修复。
