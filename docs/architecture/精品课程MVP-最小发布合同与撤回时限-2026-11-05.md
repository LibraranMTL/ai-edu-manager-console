# 精品课程 MVP 最小发布合同与撤回时限

日期：2026-11-05  
版本：v1.0  
状态：实施合同草案；冻结后作为 `WP-003` 的唯一课程发布合同  
合同标识：`edu-manager.public-course-mvp.v1`  

## 1. 适用范围

本合同覆盖精品课程 MVP 的最短闭环：

```text
云端课程草稿与发布
→ 签名公共清单与资源
→ Windows 主机 / Android 单机版同步
→ Windows 主机生成当前学生有效课程投影
→ Windows / Android 学生端展示与安全打开
→ 撤回、回滚、last-good 和对账
```

公共学习卡模板、学生私有资料上传、学情报告和项目成果不属于本合同的发布阻塞项，使用后续合同扩展。

## 2. 稳定身份与版本

| 对象 | 稳定身份 | 修订字段 | 规则 |
| --- | --- | --- | --- |
| 课程 | `courseId` | `courseRevision` | 首次发布后不改；语言变化不复制课程身份 |
| 本地化 | `courseId + locale` | `localizationRevision` | 标题、简介、法律说明、封面和入口 URL 变更均产生新修订 |
| 资源 | `assetId` | `assetRevisionId` | 原文件不可变，内容变化生成新修订和 SHA-256 |
| 发布 | `releaseId` | `manifestRevision` | 每次发布、撤回和回滚生成不可变记录 |
| 受众 | `audienceKey` | `audienceRevision` | 匹配规则变化生成新修订 |
| 学生投影 | `hostId + studentId` | `projectionRevision` | 云端清单或本机策略改变时更新 |

旧 ID 只能通过显式 `legacyCourseId → courseId` 映射迁移。不得使用课程名称、URL 或数组位置推断身份。

## 3. 规范语言

正式发布只接受：

```text
zh-CN, zh-TW, en-US, en-GB, fr, es, es-419, ja, ko, vi, ms
```

`locale` 表示课程内容本地化语言；客户端界面语言、用户所在地区和课程受众语言分别存储。旧 `en`、`zh`、空值及其他自由文本不得直接进入新发布清单，必须经过 `WP-002/WP-014` 审计和映射。每门课程可以只发布已经审核的部分语言版本。

## 4. 公共清单最小结构

```text
PublicCourseManifest
  contractId
  schemaVersion
  manifestId
  manifestRevision
  releaseId
  audienceKey
  audienceRevision
  selectionReason
  issuedAt
  effectiveAt
  expiresAt
  previousRevision
  minClientVersions
  courses[]
  assets[]
  tombstones[]
  keyId
  signatureAlgorithm
  signature
```

`courses[]` 最小字段：

```text
courseId, courseRevision, sourceCategory,
localizationRevision, locale, title, summary,
provider, launchUrl, allowedHosts[], coverAssetRevisionId,
gradeBands[], ageRange, legalNotice, accountRequirement,
defaultEnabled, offlineOpenTtlSeconds, minClientVersions
```

`assets[]` 最小字段：

```text
assetId, assetRevisionId, sha256, bytes, mimeType, downloadPath
```

`tombstones[]` 最小字段：

```text
courseId, withdrawnAt, reasonCode, severity, replacementCourseId
```

清单不得包含学生 ID、姓名、分配、作答、报告或学习状态。客户端读取接口只返回已生效且匹配受众的清单。

## 5. 最小 API

| 方法与路径 | 用途 | MVP 要求 |
| --- | --- | --- |
| `GET /v2/public-content/manifest` | 获取当前受众清单 | 支持 ETag、304、完整签名清单 |
| `GET /v2/public-content/assets/{assetRevisionId}` | 下载资源 | 支持 Range、哈希和大小校验 |
| `GET /v2/public-content/revocations` | 获取签名撤回增量 | 独立短缓存，不依赖下载完整清单 |
| `GET /v2/public-content/releases/{manifestRevision}` | 查询精确发布状态 | 用于回滚、诊断和对账 |
| `POST /v2/admin/releases/validate` | 生成候选清单 | 返回质量门和依赖报告 |
| `POST /v2/admin/releases/publish` | 批准、定时或灰度发布 | 幂等键为 `releaseId` |
| `POST /v2/admin/releases/rollback` | 切回已验证修订 | 生成新发布记录，不修改历史 |
| `POST /v2/admin/releases/emergency-withdraw` | 紧急撤回 | 成功响应前必须切换签名撤回指针 |

管理和客户端接口使用不同凭据、权限和限流。客户端凭据不能调用管理接口。

## 6. 发布状态机

```text
draft
→ validated
→ approved
→ scheduled / canary
→ active
→ superseded / withdrawn

active → rollback_release → active(previous verified revision)
```

约束：

1. 新课程、版权变化、受众扩大、入口域名变化必须由发布者确认。
2. 已批准发布单可按计划自动生效。
3. 灰度指标越阈值时自动暂停扩量。
4. 回滚和撤回都生成新记录、签名清单和审计回执。
5. 结果未知时按同一 `releaseId` 查询和对账，不重复创建发布。

## 7. 发布质量门

发布前必须全部通过：

- 稳定 ID、修订和引用图完整；
- locale 属于 11 个规范值；
- 标题、简介、提供方、法律说明和账号要求齐全；
- HTTPS 入口、允许域名、重定向和证书检查通过；
- 历史 HTTP 例外有审批、明确域名和到期时间；
- 封面及资源存在，大小、MIME 和 SHA-256 一致；
- 年级、年龄、国家/地区和产品受众可解释；
- 最低客户端版本与清单能力匹配；
- 课程重复、ID 冲突、版权和敏感内容检查通过；
- 候选环境真实打开关键路径通过。

任一阻塞门失败时不得生成 active 指针。

## 8. 客户端同步和 last-good

1. 客户端先校验 HTTPS、签名、schema、版本、受众、资源路径和哈希，再原子切换 active。
2. 下载或校验失败时保留 last-good，不用部分目录覆盖 active。
3. `expiresAt - issuedAt` 在 MVP 中不得超过 24 小时。
4. Android 单机版和 Windows 主机在前台启动、网络恢复、手动刷新及定时间隔检查 ETag。
5. Windows 主机把云端清单与本机策略合并为学生投影；两个学生端不读取云端完整清单。
6. 学生投影缓存按 `hostId + studentId` 隔离，`projectionRevision` 只作为版本，不作为缓存命名空间。
7. 课程打开前重新检查当前投影、撤回增量和 `offlineOpenUntil`。
8. 清单过期后可以只读显示历史课程信息，不允许新打开。

## 9. 撤回等级与时限

### 9.1 普通撤回

适用于课程下线、内容替换或受众调整：

- 云端在批准的 `effectiveAt` 生成 tombstone 清单；
- 在线客户端在下一次 15 分钟同步周期内取得变更；
- 学生端收到主机目录事件后 60 秒内刷新；
- 已经完成的作答、采集和学习记录保留。

### 9.2 紧急撤回

适用于安全、版权、敏感内容或错误入口：

| 环节 | 可验收时限 |
| --- | ---: |
| 管理端接受授权撤回到云端签名撤回指针生效 | 95% ≤ 2 分钟；最大目标 5 分钟 |
| 在线 Windows 主机 / Android 单机版取得撤回 | 云端生效后 ≤ 2 分钟 |
| 在线学生端取得主机投影变化 | 主机取得撤回后 ≤ 60 秒 |
| 在线端到端停止新打开 | 95% ≤ 5 分钟；最大目标 8 分钟 |

客户端要求：

- 在线 Windows 主机和 Android 单机版每 2 分钟读取轻量签名撤回增量；应用回到前台时也检查。
- 撤回增量年龄超过 60 秒时，Windows 主机/Android 单机版在课程打开前刷新；学生端通过主机投影复核。
- 收到紧急 tombstone 后立即阻止新打开；已经打开的课程关闭并显示原因。
- 高风险课程的 `offlineOpenTtlSeconds` 最大 900 秒；普通课程 MVP 默认最大 21600 秒，且不得超过清单 `expiresAt`。

### 9.3 离线边界

无法联网的设备不能保证即时获得新的紧急撤回。验收和用户文案必须如实区分：

- 缓存的打开租约未到期：可继续打开，最长受 `offlineOpenTtlSeconds` 限制；
- 打开租约已到期：课程卡可只读展示，连接云端或主机确认前禁止新打开；
- 设备重新联网：立即刷新撤回增量，优先于普通清单同步。

“紧急撤回已完成”只证明云端和已在线目标版本达到时限，不证明离线设备已经收到通知。

## 10. 学生有效课程投影最小合同

```text
StudentCourseProjection
  schemaVersion
  hostId
  studentId
  projectionRevision
  manifestRevision
  policyRevision
  generatedAt
  expiresAt
  cloudFreshUntil
  courses[]
  tombstones[]
  disclaimer
```

投影修订由 `manifestRevision + policyRevision + studentId + projectionSchemaVersion` 的确定性摘要生成。ETag 等于投影修订。学生切换时先清空内存结果，再读取对应命名空间；乱序响应不得覆盖新学生或更高修订。

## 11. MVP 放行证据

1. 同一受众在 Windows 主机和 Android 单机版取得相同课程、资源和修订。
2. Windows 本地隐藏、排序和学生分配在云端课程更新后保持。
3. 两个学生端只获得当前学生的有效投影。
4. 坏签名、坏哈希、部分下载、进程退出和 304 均有合同测试。
5. 普通撤回、紧急撤回、离线租约到期和重新联网均达到第 9 节时限。
6. 回滚恢复历史已验证内容，不覆盖学生数据和本机策略。
7. 11 种语言准入和旧值阻断有迁移报告。
8. 候选、真实设备、签名制品、灰度和正式发布证据分别记录。

## 12. 合同变更

冻结后新增必填字段、改变签名输入、缩短兼容期或改变撤回语义，必须提升 `schemaVersion` 并更新跨端夹具。文案、非语义展示字段和可选诊断字段可兼容扩展，但不能改变签名校验和安全默认值。
