AI教育管家 Android 学生端操作手册

适用版本：Android 学生端 0.6.16

配套主机：Windows 主机端 0.16.10

1. 产品定位

Android 学生端安装在学生使用的平板或手机上，用于进入本人学生空间、上传与采集资料，以及只读查看本人成长模型、学情报告和教育档案。档案初始化、项目管理、知识治理和报告发布仍由 Windows 主机端完成。

首页采用适合中小学生的自适应学习工作台。大横屏显示左侧导航和三列彩色方块卡片，竖屏及中等宽度自动降为两列并隐藏侧栏；设备旋转时按钮即时重排。连接、迁移等低频功能仍收纳在折叠区域，避免一次铺满屏幕。

2. 安装与首次连接

  1. 安装 AI-edu-manager-tablet-terminal-0.6.16.apk。
  2. 主机在“系统设置 → 使用模式”中选择“主机-终端模式”，启动学生终端协作服务。
  3. Android 与主机位于同一局域网时，可查找附近主机并核对固定主机码；也可使用扫码、粘贴连接信息或连接备份。
  4. 主机接受连接后，为该设备选择“个人终端”或“共享终端”。

3. 个人终端与共享终端

  • 个人终端：主机固定绑定一名学生，连接后自动进入本人空间，适合一人长期使用的平板。
  • 共享终端：学生在平板上输入个人 ID，或点击“扫码进入”拍摄主机生成的学生二维码；进入后只加载本人项目、报告和档案，使用结束后点击“退出当前学生”。

不需要 PIN 或密码。学生 ID 由主机在创建或升级学生档案时自动生成。共享终端未进入学生空间前不会获取或显示学生名单。

4. 上传本地资料

Android 支持拍照、选择图片、选择普通文件、扫描下载目录，以及从浏览器、相册、PDF 阅读器或文件管理器分享资料。

  1. 先进入学生空间。
  2. 选择文件或拍照。
  3. 选择“学生原始资料库”或当前学生绑定且未封存的“项目原始资料库”。
  4. 确认上传。终端会分块传输文件，主机端同步执行限额校验和流式落盘，大文件上传不再需要整体加载到内存。

按钮会用文字和背景颜色反馈按下、上传中、成功、失败和禁用状态：开始后显示“正在上传…”，成功时显示“上传完成”，失败时显示“上传失败，点击重试”。本地源文件不会因上传而删除。

4.1 导入智能体对话

在其他智能体应用中对当前对话点击“分享”，选择 AI教育管家学生端；也可以先复制对话正文，再到“资料搜集上传 → 导入智能体对话”点击“粘贴智能体对话”。

学生端自动使用当前学生，默认存入本人教育档案；如需归入项目，可在确认窗口选择本人关联项目。核对正文预览和存入位置后点击“发送到主机”，页面会立即显示已存入、已经存在或等待主机确认归属的结果。

如果网络失败，对话草稿会保留，恢复连接后点击重试。只分享一个网页链接时，学生端不会自动登录或抓取外部服务，请复制实际对话正文后粘贴。首版不自动读取其他应用的聊天历史，也不附带或推断附件。

5. 屏幕资料采集

  1. 进入学生空间，并可选择一个绑定学习项目。
  2. 选择智能混合、内容变化或固定间隔策略。
  3. 设置时长并通过 Android 系统授权屏幕捕获。
  4. 采集中可重点截取、暂停、继续和结束。
  5. 结束后确认上传到学生资料库或绑定项目资料库。

采集开始时会记录当前学生和可选项目，并保存在该学生的独立采集目录。采集运行中不能退出学生；结束后也不能把该批截图投递给另一名学生。

点击“查看与清理采集资料”可以：

  • 只查看当前学生的采集会话和缩略图；
  • 清理已经上传成功的图片，同时保留未上传图片；
  • 确认后删除整个已结束会话；正在采集的会话不能删除；
  • 检测到升级前未标记学生的旧会话时，只显示数量，不展示其中图片，避免串档。

6. 自动投递文件夹

自动投递只在个人终端可用：

  1. 点击“选择文件夹”，在 Android 系统文件选择器中授权一个目录。
  2. 选择投递到当前学生原始资料库或某个绑定项目原始资料库。
  3. 点击“启用自动投递”。应用打开时会检查一次，系统联网时通常约每 15 分钟检查一次，也可点击“立即检查”。
  4. 新文件稳定后才上传；同一文件版本和同一目标不会重复入库，失败文件稍后重试，本地文件不会删除。

切换为共享终端时会自动关闭自动投递，避免下一位学生沿用上一位学生的文件夹和投递位置。普通文件仍可手动上传。

7. 资料进展与每日提醒

首页显示已提交资料、已完成知识化、近 7 天新增和近 30 天活跃频率。“已完成知识化”按已经消化完成的资料数统计，不等同于知识库文件数量。

当天没有新资料时显示“提交本日学习资料”提醒。点击“现在上传”进入普通文件上传；点击“稍后再说”只关闭当天提醒，不会伪造已提交状态。

8. 查看成长模型、学情报告、教育档案和项目知识

进入学生空间后，可在“我的成长模型”卡片点击“查看成长模型”，查看能力画像、项目贡献和已确认或观察中的近期成长证据。成长信息来自主机已经形成的成长索引，只读展示，不在学生端触发评估、审核或重新分析。

打开“学情档案与关联项目知识”后，来源列表可在“我的学情档案”和当前学生关联项目之间切换；已封存项目仍可只读查看。终端只从主机读取当前学生会话有权访问的公开 Markdown，并可缓存最近查看内容。主机会再次校验学生与项目关联，退出当前学生时成长模型、页面、项目列表和正文都会清空。

9. 精选课程与课程资料采集

进入学生空间后，展开“精选课程”。终端只显示主机已经启用并分配给当前学生的课程。

0.6.9 已修复手机竖屏或自适应布局中课程封面下方异常留白；0.6.10 增加课程目录明确登记域名的 HTTP 兼容。

Android 学生端没有“课程管理”菜单，也不能导入或修改课程。课程启用、年级限制和学生分配由已激活的专业版或机构版 Windows 主机在“精选课程 → 课程管理”中设置。

  1. 点击“安全打开课程”，课程会覆盖当前页面显示在独立 WebView 中。
  2. WebView 只允许课程目录明确登记的 HTTP 或 HTTPS 域名，不提供本机文件访问、JavaScript Bridge、定位、摄像头、麦克风、弹窗或下载权限。课程提供方没有 HTTPS 时可以由主机管理员登记 HTTP 地址；这不会放开其他域名，也不会忽略 HTTPS 证书错误。
  3. 顶部课程采集按钮初始显示“待开始”，进入课程不会自动录屏。
  4. 点击采集按钮后，继续选择模式、目标和时长；只有确认 Android 系统屏幕捕获授权后才开始采集。
  5. 结束采集后回到资料区确认上传。资料会保留当前学生、课程、提供方、页面 URL、采集时间和目标资料库归属。

退出课程会停止加载并清理临时页面会话。打开课程、停留在网页或采集资料不代表课程完成、答题正确或形成学情结论；账号、会员、收费和服务条款以第三方页面当时说明为准。

如果看不到应有课程，请先退出并重新进入学生空间；仍为空时，让教师或家长在主机端检查课程是否启用、年级是否匹配、当前学生是否被分配，并确认已经点击“保存并下发”。

如果金榜学霸课程打不开，请让主机管理员把课程链接保存为 http://www.jinbangxueba.com/。新版主机也会把该站点旧的 HTTPS 地址自动迁移为 HTTP；不要在 Android 端选择“忽略证书错误”。

10. 连接备份

  • 导出连接备份：保存主机地址、连接模式和设备身份；
  • 导入并连接：用于同一设备重装后的恢复。

连接备份恢复的是设备连接，不会替代共享终端的学生 ID 登录。

11. 升级为 Android 单机版

该功能用于把当前学生从“Windows 主机 + Android 学生端”一次性迁移为一台平板上的完整单机教育管家。

  1. 先连接最新版 Windows 主机，并进入需要迁移的准确学生空间。
  2. 展开“系统设置”，点击“从 Windows 主机升级到单机版（少量资料）”。
  3. 核对学生姓名和学生 ID 后开始。Windows 主机会固定该学生档案、资料、成长记录、学情报告和关联学习项目的迁移快照。
  4. 已安装最新 Android 单机版时，先按页面提示完成本机设备绑定激活，再返回学生端发起迁移；未安装时先从官方下载页安装并激活。
  5. 在单机版中选择一个空目录。单机版会直接从主机下载迁移包，校验文件清单和 SHA-256，并保留原学生 ID。

这是一次性迁移，不建立双向同步。迁移完成后，后续新增资料应在 Android 单机版中继续管理。

如果当前学生达到约 1000 个文件或 3 GB，学生端会停止网络 ZIP 路径并提示使用 U 盘。请在 Windows 主机端为准确学生执行“导出到 Android 单机版（U盘）”，再到 Android 单机版“教育档案 → 从 U 盘迁移并接管”。该路径支持逐文件校验和中断续传。学生端升级入口继续保留，不影响少量资料用户。

12. 常见问题

已连接但没有进入学生

共享终端需要扫码或输入个人 ID；个人终端需要教师或家长在主机设备卡片中绑定学生。

学生 ID 无效

向教师或家长核对主机“学生登录 ID 与二维码”中的完整 ID；系统会校验 ID 格式和校验位。

看不到绑定项目

确认项目已经绑定当前学生且尚未封存，然后重新进入或刷新。

上传按钮没有反应

先确认已经进入学生空间，并观察按钮背景和文字状态；失败时检查主机服务和网络后重试。

截图上传后没有知识内容

学生端只负责采集和上传。知识消化、成长模型和学情报告更新由 Windows 主机端继续完成。
