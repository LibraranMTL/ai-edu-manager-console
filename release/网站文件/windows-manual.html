AI教育管家 Windows 主机版操作手册

适用版本：Windows 0.7.51

配套平板终端：Android 0.5.7

1. 启动与升级

  1. 关闭所有旧版 AI教育管家窗口。
  2. 启动新版程序。程序启用单实例保护，重复启动时会聚焦已有窗口。
  3. 首页“当前版本”应显示 v0.7.51。
  4. 升级后系统优先读取主机学生索引，并同步界面缓存；不移动学生知识库物理目录。
  5. 升级前建议执行“备份主机数据”，完整迁移电脑时还应单独备份学生资料根目录。

2. 创建学生档案

  1. 打开“初始化教育管家”或“新建教育智能体”。
  2. 填写学生姓名、年级、学校和学习目标。
  3. 选择创建标准知识库或接管已有知识库。
  4. 点击“保存学生档案并初始化”。

一次操作会创建知识库目录、AGENT.md、LLM Wiki 目录、索引、日志和基础学情报告。右侧 Agent 工具连接是可选步骤，不会再次创建目录或覆盖 AGENT.md。

点击任一 Agent 步骤卡片即可复制该步骤指令；如在“高级”中修改过内容，则复制修改后的指令。

3. 接管已有知识库

  1. 选择“接管已有知识库”。
  2. 选择现有知识库根目录。
  3. 确认系统识别出的 AGENT.md、原始资料库、综合汇总和输出目录。
  4. 对未识别目录进行手动指定。
  5. 查看路径健康检查；需要时生成逻辑路径草稿或执行“备份后修复旧路径”。
  6. 确认接管。

接管不移动、不复制、不删除原文件。系统使用工作空间身份、逻辑路径和当前主机映射处理跨电脑同步后的路径差异。

4. 资料收集与处理

资料可从 Windows 导入、平板上传、项目工作空间晋升或屏幕采集箱进入系统。处理区按学生显示：

  • 待提交消化：尚未交给 Agent 的资料；
  • 等待 Agent 回执：已提交，但 Agent 尚未写回完成证据；
  • 已处理：已匹配完成回执；
  • 失败或需复核：回执失败、低置信度或覆盖不足。

5. Agent 资料消化

  1. 选择学生和待消化批次。
  2. 点击复制消化指令。
  3. 将指令粘贴给 QClaw、OpenClaw、Codex CLI、Marvis 或其他能访问知识库的 Agent；具备适配器时也可从任务中心执行。
  4. 确认 Agent 已开始后，点击“标记已提交”。
  5. Agent 完成后点击“同步消化结果”。

系统通过 .edu-manager/digest-state.json 或逐文件回执确认完成。没有有效回执时，资料会继续停留在“等待 Agent 回执”，不会被误报为已处理。

6. 消化覆盖审计

大量图片或复杂资料消化后建议执行二次核对：

  1. 点击“生成覆盖审计”。
  2. 查看完整覆盖、部分识别、失败、待回执、源文件缺失等状态。
  3. 选择待复核资料并复制二次核对指令。
  4. 将指令交给任意可访问知识库的 Agent。
  5. Agent 独立执行视觉识别、OCR 和逐文件比对，并写入 digest-receipt.json。
  6. 点击“同步复核结果”。

若 Agent 回执包含未转义引号或字符串换行，系统会尝试容错修复并保留无效回执备份；无法修复时会明确提示格式错误。

7. 屏幕资料采集

位置：资料收集与处理 → 屏幕资料采集。

Windows 支持整个屏幕或指定应用窗口，并提供智能混合、内容变化、固定间隔三种策略。可设置 15 至 120 分钟，采集中支持暂停、继续、重点截取和结束。

快捷键：

  • Ctrl+Shift+1：立即截取；
  • Ctrl+Shift+2：暂停或继续；
  • Ctrl+Shift+3：标记重点。

截图先进入候选采集箱并登记为候选资产。只有点击“晋升资料”后，才进入学生原始资料库和待消化队列。

8. 文件资产中心

文件资产中心用于查看资产身份、来源、版本、重复组、引用关系和治理风险。

选择学生后，资产总数、重复组、治理候选、风险、最近七日曲线、资产列表和详情会统一切换到该学生范围。搜索、来源、类型和“只看重复”只筛选列表，不改变学生范围看板。

“最近 7 天资产变化”包括每日新增资产和每日新增引用。旧记录缺少历史日期时不会猜测日期，并会显示未计入数量。

9. 新建学习项目

位置：学习项目 → 新建学习项目。

  1. 填写项目名称、类型、目标和参与学生。
  2. 选择项目模板或自定义模板配置。
  3. 自定义项目工作空间文件夹，或选择“使用已有项目文件夹”。
  4. 确认工作空间与知识空间位置。
  5. 创建项目。

项目工作空间面向学生和教师，项目知识空间使用原始资料、概念、实体、摘要、问答精华、综合汇总的统一结构。

10. 研究暂存层工作流

工作空间中的候选资料进入知识空间前，依次经过：

  1. 导入暂存：收集网页、论文、截图、草稿等候选资料。
  2. 初筛：判断相关性、重复性和是否值得继续处理。
  3. 治理：决定保存完整副本、仅保存来源、保留快照或排除，并处理重复与风险。
  4. 晋升：把确认采用的资料登记为正式资产，并引用到项目原始资料库。
  5. 消化：Agent 基于原始资料库生成结构化知识。
  6. 审核与贡献：审核项目知识并发布到学生长期档案或成长模型。

“直接导入原始资料库”适合已经确认的核心资料，会跳过暂存筛选，但仍保留来源和资产登记。

11. 已有学习项目

位置：学习项目 → 已有学习项目。

项目详情提供：

  • 打开项目根目录、项目工作空间、项目原始资料库和项目知识空间；
  • 编辑项目记录，但不改动物理目录；
  • 重新定位丢失或迁移后的项目路径；
  • 复制项目模板和知识策略，不复制无关资料或历史贡献；
  • 导入、导出项目包；
  • 移除项目记录和恢复已移除项目；
  • 生成贡献申请、归档确认、贡献审计和发布到成长模型。

多学生项目共享项目知识，但每名学生的成长证据独立生成和审核。

12. 项目仪表盘

仪表盘用于检查资料治理、知识覆盖、待审核项、贡献状态和风险。可查看指标应作为入口打开对应清单，不只是静态数字。

自动化触发可由新资料、项目阶段变化和定时任务产生。关闭自动运行总开关后，触发器只生成待办，不会自动调用 Agent。

13. 统一任务中心

任务中心统一承接 Agent 自动任务和人工任务，记录任务输入、执行工具、权限、审批、状态、日志、超时、重试和结果审核。

支持方式：

  • OpenClaw：受支持任务可直接执行；
  • QClaw：通过任务收件箱领取；
  • Codex CLI、Marvis 或其他 Agent：复制任务指令并人工回填结果；
  • 手动模式：一次关闭全部自动运行，避免后台任务消耗资源。

每日行动建议由成长模型按日生成，进入任务中心审核后发布到学情报告。

14. 学生成长模型与学情报告

项目知识不是直接复制到学生目录。项目结束后生成知识贡献申请，用户审核新增概念、实体、成果和能力证据，再发布到成长模型。

成长模型看板分为三个视图：

  • 能力画像：按能力维度汇总已确认、观察中和待审核的证据，并显示成熟度、趋势、来源项目和最近观察时间；
  • 项目贡献：列出项目状态、贡献发布状态、支撑能力和已确认证据，可点击进入对应学习项目；
  • 成长证据：按状态、能力和关键词筛选候选证据，并执行确认、观察或驳回。

“成长模型目录”卡片可直接打开学生知识库下的成长模型文件夹。旧版 成长证据.md 会在结构化索引升级时兼容导入，不移动、不删除、不覆盖原文件。

学情报告是独立呈现层，只读取成长模型中的已确认结论：整体画像引用能力画像，历史变化引用能力时间线，阶段总结引用项目贡献和成长证据，每日行动建议由统一任务中心生成并审核发布。报告为空时，应依次检查：资料是否完成消化、成长证据是否确认、项目贡献是否发布、成长模型索引是否刷新。

15. 主机服务与平板授权

  1. 切换到主机-平板模式并启动主机服务。
  2. 确认主机服务状态正常，并查看 Windows 端显示的 6 位平板配对码。主机同时在局域网内广播不含令牌的发现信息。
  3. 在同一 Wi-Fi 下，平板点击“查找附近主机”，选择当前电脑并输入 6 位配对码。也可继续使用扫码、粘贴连接信息或导入连接备份。
  4. 平板完成设备登记后显示“已连接，等待 Windows 授权”。此时设备还不能读取任何学生资料。
  5. Windows 设备列表会显示待授权设备。核对设备名称和登记时间后，授权全部学生或指定学生。
  6. 授权后平板每 5 秒自动检查一次，通常会在数秒内载入学生，最长自动等待约 60 秒；超过时间后可在平板手动刷新学生。

局域网自动发现使用主机服务端口 18777 和发现端口 18778。若平板找不到主机，请确认两端处于同一 Wi-Fi、Windows 主机服务正在运行，并允许 AI教育管家通过 Windows 防火墙的专用网络。

6 位配对码是一次性短码，成功登记后即失效。局域网广播只包含主机名称、版本和可连接地址，不包含 API Token、设备令牌或配对码。

设备可在卡片内重命名。已撤销设备可恢复或删除记录；活跃设备需先撤销才能删除。删除授权记录不会删除历史上传审计。

16. 备份与恢复

“备份主机数据”保存完整学生档案字段、设备授权、上传记录和应用索引。恢复后学生列表、学习项目、文件资产和主机状态会立即刷新。

注意：主机状态备份不等于完整知识库文件备份。迁移电脑或更换磁盘时，还必须备份学生资料根目录中的 PDF、图片、Word、Markdown 和项目文件。

17. 常见问题

新版看不到原学生

先确认旧版窗口已关闭。0.7.51 使用单实例保护和主机索引校准；如仍缺失，恢复主机备份并检查学生知识库路径。

待消化数量不变

先确认已点击“标记已提交”，再等待 Agent 写回状态，最后点击“同步消化结果”。只有生成知识文件但没有写回回执时，仍会显示等待状态。

数学图片未被识别

生成覆盖审计，选择失败或低置信度图片，执行二次核对并同步复核结果。

项目知识空间打不开

先执行“重新定位”，确认知识空间目录存在；再使用项目详情中的文件夹入口。路径健康检查中存在错误时先修复映射。

平板已连接但没有学生

Windows 端检查设备是否处于待授权状态，并授权学生范围。Android 0.5.7 会短时自动检查授权并载入学生；若约 60 秒后仍为空，请在平板点击刷新学生，并检查设备是否只授权了不存在或已删除的学生。

平板找不到附近主机

确认 Windows 0.7.51 主机服务已启动，电脑和平板连接同一 Wi-Fi，且路由器没有启用访客网络或客户端隔离。允许 Windows 防火墙的专用网络访问后重新搜索。仍无法发现时，可使用扫码、粘贴连接信息或连接备份完成连接。

程序运行变慢

在任务中心关闭全部自动运行，停止不需要的屏幕采集会话，并检查是否存在大量待处理 OCR、审计或资产扫描任务。
