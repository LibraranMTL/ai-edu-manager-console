日期：2026-10-02。目标架构：Windows 0.19.3。Android 源码仍为 1.2.8 / versionCode 32，本轮不升级正式发布清单。

## 验收安排与状态边界

用户明确要求“验收等最后人工执行”。真实模型样本与账单、真机、七天运行、历史签名连续性和覆盖安装均后置；不以模拟结果替代人工验收。本记录只说明本地源码和自动检查，不表示完整计划已完成或已正式发布。

当前目录为有大量既存修改的嵌套工作区；本批未提交、未推送、未修改在线服务器。版本相同的未签名候选不能作为正式覆盖升级包。

## 本批实现

### 资料、隔离与运行安全

- Room V3 在 V2 基础上增加按学生隔离的搜索、候选版本、收藏、作答、草稿、选择记录及处理检查点；迁移不删除旧表。
- 搜索从当前学生与参与项目的已授权目录建立本地索引；不移动、自动采用或上传原件。扫描有数量、深度、字节上限；不完整扫描保留旧索引，避免把读取失败误判为文件删除。
- 文件导入登记操作意图，使用学生与来源事件/内容哈希去重；已完成事件复用原件，未知结果不盲目重复执行。
- 学生、项目、资料和对话索引读取失败关闭；项目队列跨进程中断转为需要核对，不自动重新付费调用模型。
- 相同项目、相同对话内容按学生分别登记，避免把其他学生的记录误当作当前学生的重复记录。
- 消化结果必须关联真实资料 ID 和非空证据片段；写入前复核原件/识别文本哈希，不将机器观察当作已确认成长结论。

### 学习与规划工作室

- 新增原生入口、八业务域导航及首页常用入口配置，兼容旧导航入口。
- 从选定 TXT/Markdown 资料或正式已发布学情报告生成 1—10 个学习卡片候选。报告入口校验正式路径、发布元信息和学生归属，不使用未发布草稿。
- 发送前显示实际去标识输入 JSON。确认后重新计算同一输入指纹；资料变化则拒绝发送，要求重新预览。自动去标识并非完整匿名化。
- 学习卡片先结构化校验，再进行独立模型复核；结果仍标记候选，不能保证答案正确。文字与受限类型文件作答保存在待审核记录中，不自动认定掌握。
- 分享及 PrintManager 打印仅导出题目，不包含答案、档案与历史作答。
- 选题支持不可变版本、比较、收藏、忽略和项目草稿。草稿可以进入原项目创建表单预填；项目名称、参与学生、目录等仍由用户确认，不自动创建。
- 总体规划、路径、学校、专业、职业、比赛具有不同字段合同；模型必须返回真实供应商来源，关键字段逐项对应 URL 或明确“待核验”。禁止把没有来源的输出保存为已核验研究。
- 所有生成版本保留证据快照。失败、取消、未知结果或资料变化不覆盖历史版本；未知计费不自动重试。

### 自动化与 ASR

- 自动练习默认关闭，需单独授权。每日约束任务与正式报告更新触发使用同一服务及去重策略；仅选正式报告，不后台任意发送原始资料。
- 当前学习/规划额度为每学生每日最多 6 个预留模型请求；卡片生成与复核占 2 次。此限制不是费用估算，也不是全系统统一额度。
- 录音只在用户启动后的前台界面运行，离开界面停止；最长 10 分钟、20 MB。保存原件后才可另行授权 ASR 发送。
- ASR 独立配置、独立密钥，不假设聊天/视觉模型兼具转写接口。当前适配兼容 `/audio/transcriptions` 的服务；实际阿里云 ASR 协议与服务能力需专项确认。
- 音频格式及大小检查、原件哈希复核、转写检查点、请求回执和未知结果保护已接入；转写标为机器观察、待审核，可供后续消化。
- 未归档录音有本机恢复记录。记录损坏停止录音；完整备份/迁移遇到待归档录音时阻止导出并提示处理，不静默遗漏缓存。

### 备份、恢复与网关试点

- 逻辑备份升级至 V3，保留 V2 读取兼容；新增内容表、非敏感设置、首页常用入口、惰性协作历史归档。
- 不迁移 API Key、设备凭据、短时令牌或旧设备 SAF 授权；协作历史是只读历史，不能复制活跃配对。
- 恢复后的搜索需要重新建索引；自动发送授权关闭，需重新同意。
- 历史候选和收藏的证据 JSON 不随新设备路径重映射，保持内容指纹；实际来源定位使用当前索引重新校验。
- 本地试点网关实现短时作用域凭据、许可证/设备/学生校验回调、持久化去重、配额及未知结果保护；Android 有对应模型适配器。未挂载到正式服务，不代表用户可直接启用平台网关。

1. 两名学生切换、相似资料与同项目对话，确认任务、收藏、作答、草稿和云端回执均不串档。

3. 授权去标识样本检查文本、视觉、复杂公式、Schema、供应商来源、ASR、取消、实际用量及账单。缺少能力应失败关闭。
4. 自动练习授权前后、额度耗尽、后台约束、断网、杀进程、迟到结果和未知调用人工核对。
5. 作答文件安全、题目分享与打印、选题草稿人工创建、研究关键字段实际来源及日期。
6. 旧 V2/V3 数据恢复、待归档录音阻止备份、新设备授权/凭据重新建立；七天两台设备连续运行。
