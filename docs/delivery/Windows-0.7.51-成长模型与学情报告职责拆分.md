# Windows 0.7.51 成长模型与学情报告职责拆分

## 更新内容

- 成长模型页面改为“能力画像、项目贡献、成长证据”三个视图，不再重复展示四份学情报告。
- 页面中的“学情报告目录”改为“成长模型目录”，并可直接打开物理文件夹。
- 能力画像显示成熟度、趋势、证据覆盖、来源项目和最近观察时间。
- 项目贡献显示贡献发布状态、支撑能力和已确认证据，可直接进入对应学习项目。
- 成长证据支持关键词、能力和状态筛选，并保留人工确认、观察、驳回流程。
- 结构化索引升级为 `edu-manager.growth-model.v2`。
- 自动兼容导入旧版 `成长证据.md` 的有效记录，不移动、不删除、不覆盖原文件。
- 资料消化不再直接覆盖学情报告；项目发布后优先刷新成长模型。
- 学情报告明确为呈现层，每日行动建议继续通过统一任务中心审核发布。

## 兼容说明

现有学生知识库目录与 Markdown 文件保持不变。首次进入成长模型或点击“重建结构化索引”时，系统会自动升级索引并导入可识别的旧证据记录。占位行和重复记录不会被导入。
