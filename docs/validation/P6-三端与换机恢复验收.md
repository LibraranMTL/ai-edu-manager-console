# P6 三端与换机恢复验收

## 自动门禁

1. Windows 主机：资料导入、知识处理、成长模型、报告与档案读取、知识协作队列。
2. Windows 学生终端：当前学生登录、资料上传、成长模型、学情报告、教育档案和关联项目知识只读访问。
3. Android 学生终端：当前学生登录、资料上传、屏幕采集、成长模型、学情报告、教育档案和关联项目知识只读访问。
4. 数据隔离：学生终端只返回当前登录学生及其有效关联项目，不回退到其他学生。
5. 恢复：主机备份包含完整学生记录；换机恢复后重建协作索引，未完成传输从已接收位置续传。

## 候选包真机门禁

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| Windows 主机 | 新增一份资料并完成自动处理 | 首页依次出现处理中、知识更新；无需人工审核低风险结果 |
| Windows 学生终端 | 以学生 ID 登录后上传文件并查看成长模型 | 文件进入本人目标库；只显示本人及关联项目 |
| Android 学生终端 | 以同一学生登录，采集并上传图片 | 按钮有明确反馈；主机收到资料；报告和成长模型可读取 |
| 局域网与 Tailscale | 分别关闭一种通道完成一次上传 | 可用通道自动接替，普通用户不填写技术地址 |
| 换机恢复 | 在新主机恢复备份并重新连接终端 | 学生、项目、档案和队列恢复；不重复导入历史包 |
| 异常恢复 | 传输中断后重启两端 | 自动续传或给出一次可执行的重试，不丢失、不重复 |

以上任一场景出现跨学生数据、空项目覆盖已有项目、重复资料膨胀或不可恢复阻塞，均阻止稳定版发布。
