# AI教育管家装机人员检查清单

**适用版本：Windows 0.7.49 / Android 平板终端 0.5.4**

## 1. 发布文件

- [ ] Windows 主机版 0.7.49 发布包
- [ ] Android 平板终端 0.5.4 APK
- [ ] `edu-manager-version.json` 中双端版本与下载地址正确
- [ ] Windows 与 APK 文件可正常打开，文件哈希已留档
- [ ] 用户协议、隐私政策和更新地址可访问

## 2. Windows 环境

- [ ] Windows 10/11 可正常运行程序
- [ ] 当前用户可写入学生资料根目录
- [ ] 磁盘空间充足，系统时间正确
- [ ] 防火墙允许主机服务端口，默认 `18777`
- [ ] 同时启动两次时只保留一个主实例
- [ ] 首页显示 `v0.7.49`

## 3. 学生档案初始化

- [ ] 填写测试学生并点击“保存学生档案并初始化”
- [ ] 一次生成知识库目录、`AGENT.md`、LLM Wiki 目录、索引、日志和基础学情报告
- [ ] 初始化失败时不产生无效学生记录
- [ ] Agent 步骤卡片可直接复制指令
- [ ] 右侧不再出现重复的目录创建与 `AGENT.md` 写入步骤

## 4. 接管与路径迁移

- [ ] 可选择已有知识库并识别真实目录
- [ ] 接管不移动、不复制、不删除原文件
- [ ] `.ai-manager/metadata.json` 和 `pathmap.json` 可生成或读取
- [ ] 路径健康检查可发现旧主机绝对路径
- [ ] “备份后修复旧路径”先生成备份再修改

## 5. 资料消化闭环

- [ ] 导入测试资料后“待提交消化”数量增加
- [ ] 可复制消化指令并选择任意 Agent 工具
- [ ] 点击“标记已提交”后资料进入“等待 Agent 回执”
- [ ] Agent 写回状态后“同步消化结果”更新计数和最近消化时间
- [ ] 没有回执时不会误标为已处理
- [ ] 资料收集与处理页面无空白

## 6. 消化覆盖复核

- [ ] 可生成逐文件覆盖审计
- [ ] 可查看完整覆盖、部分识别、失败和源文件缺失
- [ ] 可复制二次核对指令
- [ ] Agent 写回逐文件结果后可同步复核结果
- [ ] 回执格式错误时显示错误并保留备份

## 7. 屏幕资料采集

- [ ] Windows 可选择全屏或应用窗口
- [ ] 智能混合、内容变化和固定间隔策略可启动
- [ ] 暂停、继续、重点截取、结束和快捷键有效
- [ ] 截图先进入候选采集箱
- [ ] 晋升后才进入原始资料库与待消化队列
- [ ] Android 会话需要系统授权并显示前台通知

## 8. 文件资产中心

- [ ] 资产总数、重复组、治理候选和风险可显示
- [ ] 最近七日新增资产与新增引用曲线可显示
- [ ] 切换学生后看板、曲线、列表和详情同步变化
- [ ] 资产详情不会残留其他学生资料
- [ ] 重复扫描不会重写引用首次建立时间

## 9. 学习项目

- [ ] “新建学习项目”和“已有学习项目”二级菜单可进入
- [ ] 工作空间文件夹可自定义
- [ ] 可直接使用已有项目文件夹且不移动资料
- [ ] 项目工作空间和知识空间分别创建
- [ ] 项目根目录、工作空间、原始资料库和知识空间入口可打开
- [ ] 研究暂存资料可初筛、治理、晋升并进入项目原始资料库
- [ ] 项目编辑不改动物理目录
- [ ] 项目移除不彻底删除文件，并可恢复记录
- [ ] 项目复制、导入导出和重新定位有效
- [ ] 多学生项目可生成独立成长证据
- [ ] 仪表盘指标可打开对应详情

## 10. 统一任务中心

- [ ] 任务状态、执行工具、审批、日志、超时和重试可查看
- [ ] OpenClaw 直接执行与 QClaw 任务收件箱按部署情况可用
- [ ] 无接口 Agent 可使用复制指令与人工回填
- [ ] “全部关闭自动运行”可切换为手动模式
- [ ] 手动模式下自动触发只生成待办，不调用 Agent
- [ ] 每日行动建议可生成、审核和发布

## 11. 主机与平板授权

- [ ] 主机服务启动后显示连接信息
- [ ] 平板首次连接后显示待授权，不误报为完全连接
- [ ] Windows 可实时看到待授权设备
- [ ] 可授权全部学生或指定学生
- [ ] 设备卡片内可重命名
- [ ] 已撤销设备可恢复或删除记录
- [ ] 活跃设备必须先撤销再删除

## 12. Android 连接备份

- [ ] 可导出连接备份
- [ ] 重装或清除数据后可“导入并连接”
- [ ] 不同安装身份会要求确认
- [ ] 导入后可验证主机并恢复设备身份
- [ ] 已告知用户连接备份含授权令牌，不可公开分享

## 13. 档案与报告

- [ ] Windows 可打开教育档案和学情报告
- [ ] 平板可读取已授权学生档案
- [ ] 项目贡献发布后成长证据可审核
- [ ] 学情报告能显示已审核成长证据和每日行动建议

## 14. 备份、恢复与升级

- [ ] “备份主机数据”成功导出
- [ ] 备份包含完整学生档案字段、设备授权、上传记录和应用索引
- [ ] 恢复后学生、项目、资产和主机状态立即刷新，无需重启
- [ ] 已单独备份学生资料物理目录
- [ ] 旧版全部关闭后可直接启动新版并看到原学生

## 15. 交付确认

- [ ] 家长知道如何连接、等待授权、上传资料和查看档案
- [ ] 管理员知道如何执行消化、同步回执和覆盖复核
- [ ] 管理员知道如何关闭全部自动运行
- [ ] 管理员知道主机状态备份不包含完整知识库文件
- [ ] 已记录主机版本、平板版本、安装日期和交付人员
