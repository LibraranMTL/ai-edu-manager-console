## 本轮行为

1. 自动采集的 Agent 会话完成并归档后，仍先进入所选学生的本地对话资料箱，不自动进入原始资料库。
2. 「智能体知识管理 → Agent 会话自动采集」的最近会话行，直接提供学生/关联项目原始资料库投递、回收站、恢复、彻底删除入口；另有「管理全部对话资料」入口。
3. 移入回收站后，该会话不再进入教育管家的跨 Agent 最近上下文；恢复后重新可见。彻底删除会清除资料箱原文、Interaction/Asset、未晋升知识候选、自动采集会话正文及主机待处理队列中可识别的同一会话事件，仅保留无正文的身份墓碑防止延迟 Hook 重建。
4. 有资料投递或已晋升知识时拒绝彻底删除；未晋升候选不是阻塞项，而随原文删除。项目归属和学生 ID 均由后端再次校验。
   删除范围仅限教育管家的本地副本与索引，不删除 Codex/QClaw/WorkBuddy 自身的原会话，也不能擦除系统备份或用户另行导出的副本。
5. 此候选还包含此前开发中、默认关闭的 Codex 截图视觉开关；其真实学生截图质量和文件级只读隔离尚未验收，不属于本次 Agent 会话管理验收结论。

## 真机验收清单

请先在非生产学生资料或已备份的测试配置中试用；不要直接用真实学生私密对话做删除首测。

1. 关闭旧版，运行候选 EXE。选择测试学生，确认 Codex/QClaw/WorkBuddy 授权接入状态；完成一段**新授权会话**，刷新列表，确认会话进入对话资料箱且显示可管理按钮。授权前旧历史不应出现。
2. 选择一段会话投递到学生原始资料库，确认 `Agent对话资料` 内出现对应文件；重复投递应提示已存在而不生成重复文件。关联项目目标要再测一次，未关联项目不得接受。
3. 对未投递、未晋升的测试会话：移入回收站，确认对话资料箱与自动会话列表状态一致，跨 Agent 最近上下文不再返回它；恢复后状态恢复。
4. 再次移入回收站并彻底删除，确认会话从两处列表消失、原文与未晋升候选不再存在；重启应用及 Agent 后不能被延迟事件重建。
5. 对已投递或已晋升知识的会话，确认「彻底删除」禁用并显示依赖；此时回收站操作不能删掉既有原始资料或已发布知识。
6. 在两名测试学生之间切换，确认会话和投递目标互不串用；观察前台切换、列表刷新是否卡顿。

如真机出现异常，保留候选 EXE 的哈希、应用版本、操作时间、所选学生 ID、会话状态和错误提示；不要在反馈中附带完整私人对话或 Token。真机验收、签名、干净来源重建和发布批准之前，不应替换现有正式包。
