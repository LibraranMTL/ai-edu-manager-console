## 本候选补齐的 P1 闭环

- Windows 学生端授权采集会话停止后自动进入持久化送达队列，断网或瞬时失败自动退避恢复，不要求用户确认上传。
- 主机端先把远端截图写入候选采集区，完整接收并校验学生、项目和会话后自动结束会话、排入语义处理；正式资料库只接收生成的会话资料包和关键证据。
- 回执按活动段校验学生、批次、来源事件和内容哈希；某一活动段失败时只隔离该段，不回滚已经通过的段。
- 资料包带有每批最多 8 张的可选视觉复核清单，识别缓存按学生、哈希和策略版本复用；仍被资料包或正式知识引用的缓存不会被容量清理删除。
- 知识资产、成长模型和学情报告可回到精确活动段及关键截图，语义搜索覆盖 OCR、摘要、视觉补充和知识概念。
- 调度器使用真实前台延迟、CPU、内存、磁盘、供电、空闲和采集信号自动调整 0～2 并发；采集或资源紧张时不运行 OCR/视觉/AI 重任务。

## 双机真机验收

1. 主机电脑运行主机端候选，学生电脑运行学生端候选，并保留原有授权和学生映射。
2. 在学生端选择非敏感学习窗口，连续采集至少 30 分钟；停止后不点击任何上传确认，观察主机是否自动收到并形成活动段。
3. 采集中断开网络，再恢复局域网；验证队列自动送达、没有重复截图、重复活动段或重复资料包。
4. 等待真实 Agent 完成正式资料消化，检查部分失败是否只隔离对应活动段，其余内容正常形成知识状态与指导响应。
5. 分别从知识资产、成长模型和学情报告打开时间线来源，核对学生、活动段、采集时间与关键截图一致。
6. 快速滚动时间线、切换模块并同时排队报告/消化任务，记录 CPU、内存、磁盘和 UI 响应；采集期间重任务并发必须为 0。
7. 重启双端，确认仅恢复未完成队列，不扫描或重复处理全部历史。
