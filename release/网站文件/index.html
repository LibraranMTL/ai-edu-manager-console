完整 Windows 主机 · 知识协作

跨主机知识协作，保留清晰的学生范围与来源

两台已经建立知识协作关系的 Windows 主机，可以定向发布项目、交换任务，并在授权范围内查询本机或远程知识。

01 / 知识查询

本地优先，远程按需

本机没有命中时才访问协作主机；局域网不可达时尝试 Tailscale，对方离线时明确显示快照时间或等待状态。

02 / 团队范围

长期权限开关控制范围

本机团队和远程协作团队分别授权；学生终端始终只读取当前登录学生及其有效关联项目。

03 / 对话沉淀

一次授权，自动沉淀新会话

Codex、QClaw、WorkBuddy、OpenClaw、Claude Code、Hermes 可自动采集授权后当前新会话；不读取授权前历史、系统提示、密钥或其他私有聊天。

04 / 成果协同

确认成果与原始资料分开

已确认知识、成长模型、已发布报告和完整档案使用成果通道；原始资料通过上传、投递或项目发布交付。

重要边界：学生原始资料不自动双向同步。每台主机保留自己的原始资料权威目录，避免重复消化、大文件常驻传输和同名覆盖。
