# Windows 0.7.34 统一任务中心

## 本次完成

- 将侧边栏“定时任务”升级为“任务中心”。
- 新增跨学生、跨项目任务汇总接口。
- 统一展示学生资料消化、知识库维护、项目消化、知识审核和贡献归档任务。
- 新增全部、待处理、执行中/等待、已计划、已完成五类可点击统计。
- 支持按任务状态、来源和执行者筛选。
- 学生任务可直接复制对应指令，项目任务可定位到项目工作流中的处理板块。
- 汇总现有学生任务账本作为最近执行历史。
- 补齐此前缺失的定时任务账本 Electron preload 接口。

## 保留能力

原有学生资料消化、标记提交、同步结果、lint、路径检查、维护报告和单学生账本均继续保留。

## 后续

下一阶段按照《统一任务中心开发计划》接入版本化任务协议和多 Agent 执行适配器。
