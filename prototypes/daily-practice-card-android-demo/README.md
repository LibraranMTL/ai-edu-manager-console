# 今日提分卡 Android 竖屏 Demo

更新日期：2026-08-02
性质：学生端高保真交互原型，不是 Android APK，也未接入正式数据。

## 打开方式

直接打开本目录的 `index.html`，或通过本地静态服务器访问。

## 设计定位

- 目标设备：Android 手机 / 平板竖屏，基准视口 390 × 844。
- 使用对象：当前已登录学生。
- 学生端只负责接收、练习、查看依据和提交反馈，不暴露主机端的任务调度、Agent、目录或权限设置。
- 只展示当前学生的卡片、教育档案和有效关联项目，不显示其他学生或未关联项目。
- 今日卡支持选择“高清图片（PNG）”或“PDF 文件”下载，并可切换彩色 / 黑白高对比输出；Demo 仅模拟生成和保存反馈。

## 继承最新版桌面 Demo 的规则

- 学情更新、定时兜底、手动生成共用同一个任务。
- 同一学生、同一自然日只保留一个有效任务，避免重复卡片。
- 支持今日 / 本周 / 本月 / 自动判断四类学情依据；本 Demo 展示“本周要点复习”。
- 科目可覆盖语文、数学、英语、物理、化学、生物、历史、地理；本 Demo 展示数学。
- 生成依据可追溯，完成练习后明确提交并回写教育档案。

## 建议演示路径

1. 首页查看学生专属范围、今日卡与生成策略状态。
2. 点击“为什么练这个”，查看学情报告、教育档案和证据编号。
3. 点击今日卡右侧“下载”，开启“黑白打印”，检查卡片预览、格式说明和当前输出状态同步变化。
4. 分别选择高清图片和 PDF，检查反馈是否明确标出彩色或黑白版本。
5. 点击“开始今天的练习”。
6. 先选择错误答案，查看提示；再选择正确答案并确认。
7. 在完成页选择难度反馈，返回首页。
8. 使用底部导航查看教育档案和本人关联项目的范围说明。
