Windows 0.15.9 教育内容智能出版正式发布

Windows 主机端已完成真机验收；学生端版本保持不变。报告与档案的可信数据可转换为适合阅读、打印和分享的表达文件。

  • 多格式：PDF、PNG、Markdown 共用同一份可编辑出版草稿
  • 可信提炼：Agent 每条结论必须附原文摘录和来源章节，校验失败自动回退忠实原文
  • 移动卡片：9:16 手机比例、彩色/黑白模板、长内容紧凑单栏完整输出
  • 安全边界：只读当前学生来源，不修改原报告、教育档案、成长模型或知识资产

正式验收：Windows 真机测试通过，全量自动测试 640/640；EXE SHA-256：B6ECD8F58B7296832F564F456893C362C8C4E13425645DE2E00293B48F65682B；ZIP SHA-256：D157816B2C22B6E9C4BCE7230EF7E340C26BAC48228ACAC8A93A5BD2D2DEA28C。

签名说明：发行者元数据为 Robogala；当前 Windows 安装包尚未配置 Authenticode 公开代码签名，请仅从官方或已知可信交付渠道下载。

Windows 0.15.6 平台课程权限与签名发布

不增加独立平台端口或安装包；同一 Windows 主机端由 License v2 的版本与身份决定平台课程编辑、发布和恢复能力。

  • 平台草稿：编辑完整课程字段和版权审核信息，不直接影响学生端
  • 签名发布：生成 .edu-coursepkg，校验 RSA 签名、哈希、图片和版本后应用
  • 权限隔离：专业版、机构版继续管理机构自选课程，平台课程保持只读

Windows 0.15.5 课程编辑与资料确认修复

专业版和机构版可编辑已有机构自选课程；各学习项目共用的资料确认流程已修复初筛状态映射，并保护真实终态资料。

  • 课程编辑：更新名称、简介、HTTPS 链接和封面
  • 状态修复：AI 初筛结果进入人工确认候选
  • 终态保护：已晋升、已分析资料不再重复审核或覆盖

Windows 0.15.4 课程上传与换机恢复

专业版和机构版可直接新增一门机构自选课程；同时正式并入跨 Windows 主机备份路径重映射与接管知识库重新定位，批量 Excel 导入继续保留。

  • 课程填写：名称、简介、HTTPS 链接和最大 5 MB 图片
  • 课程保存：相同课程链接更新原课程，再设置启用和学生分配
  • 换机恢复：受管路径转到当前资料根目录，外部知识库不误改

Windows 0.15.3 档案与报告导出更新

教育档案导出会自动避开不可写或被占用的目录；当前学情报告可直接导出为 Markdown 或 A4 PDF。三类导出已完成 Windows 真机验证。

  • 完整档案：自动选择可写目录并显示实际保存位置
  • Markdown：保留报告原始可编辑内容
  • PDF：保留中文标题、列表、表格、分页和页码

Windows 0.15.2 课程菜单更新

主机端已经把精选课程拆分为两个清晰入口，详细步骤和导入规格已同步到最新版操作手册。

  • 课程学习：所有版本均可打开已分配课程
  • 课程管理：仅已激活的专业版和机构版可用
  • Excel 导入：四个字段，最多 200 门课程

知识协作与跨主机知识

Windows 主机端手册已补齐 D 阶段用户流程，普通使用不需要配置额外技能包或理解内部传输协议。

  • 本地优先：本机未命中后才按需查询协作主机
  • 团队范围：本机团队与远程团队分别长期授权
  • 对话投递：只有用户明确要求时才保存当前或选定对话
  • 同步边界：原始资料不自动双向同步，使用上传、投递或项目发布

当前验证状态：团队查询和明确对话投递已完成双机真机验证；QClaw 远程路由与自动档案更新仍在受控复测，不作为公开稳定能力承诺。
