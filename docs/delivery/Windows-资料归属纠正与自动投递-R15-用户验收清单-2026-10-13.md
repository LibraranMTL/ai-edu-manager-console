# R15 用户验收清单

先退出旧版、保留应用数据备份，再运行 `smart-material-correction-r15-20261013` 候选；不要同时打开两个版本。无需上传JSON或重建模型配置。

## 请您操作并判断的项目

1. **更正错选学生**：在“待处理”找到误分给赵书源的“参考.docx”，勾选后，在“确认／更正学生，由AI分类”选择包书杨，点击“更正学生并重新智能分类”。应自动切到包书杨，旧学生建议清除，新建议只对应包书杨的有效项目；不改变整个下载目录的学生绑定。
2. **手动纠正及已投递纠正**：也可展开“手动指定位置并投递／纠正”，选择学生和项目，点击带“更正学生”的按钮。投递后到“已投递”再次改项目／学生，或重新智能分类。新位置成功前旧关联不能提前撤销；已有引用的旧资料应显示保留原因。
3. **核对分类质量**：选含图片／公式但正文清楚的资料，检查项目建议是否合理。来源开启“可信资料自动投递”且达标时应自动进入“已投递”；否则应给出待确认理由，不能仅以“图片、公式未完整识别”一律阻断。阈值默认0.95，可在来源设置提高至1.00；分数不是准确率承诺。
4. **切换学生**：在已允许使用同一Agent的两名学生间切换，不应重复要求官方登录。首次给另一学生开启备用，仍需一次同意该学生资料可交给该执行器，这与重新登录不同。
5. **原下载／分享入口一致性**：用一份新测试资料在原入口手动投递，到统一“已投递”核对记录和目标，点击“原件”应定位受管文件。专用中转来源不应再留“已投递”副本；普通“保留原件”来源继续保留原件。

## 只有确需使用时才操作

- **WorkBuddy官方登录**：本机后台真实验证仍返回未认证；可以继续使用已可用且已授权的Codex，无需为测试切换学生重新登录。确需WorkBuddy时，点击“自动准备并授权 WorkBuddy”，在官方页面完成授权，再点“我已完成登录，继续”。不要发送密码、Token或上传JSON。登录后系统自行做受控校验；失败时请保留错误提示，不降低隔离设置。
- **备用许可**：如果某学生尚未允许Codex备用，只需针对该学生一次开启；若已经启用，不要反复关闭／开启。

## 仍待安排的正式验收

- 200份独立标注资料的准确率／自动覆盖率，需要真实业务判断；规则训练样本与验收样本分离。
- 5名代表用户的30份资料操作时间对比，需要用户操作并计入纠正时间。
- 四核／8GB／SSD目标设备的交互P95和四小时混合稳定性，需要目标设备可用；采样、日志分析由开发侧负责，不要求您手工计时或分析日志。

遇到“执行待核对”、原件变化或敏感冲突，不要删除文件或重复派发。提供截图和操作时间即可，开发侧继续核对回执和版本。
