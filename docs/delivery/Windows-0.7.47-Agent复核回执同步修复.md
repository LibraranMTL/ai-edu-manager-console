# Windows 0.7.47 Agent 复核回执同步修复

## 问题

Marvis 已完成二次复核并生成知识摘要，但“同步复核结果”仍显示旧数据。

本次实例中，Agent 在 `digest-receipt.json` 的说明文字里直接写入了未转义的双引号：

```text
标题"三种布局模式"，提供了……
```

这使整份 JSON 回执无法解析。旧版本静默忽略了解析错误，因此界面继续显示同步前的 18%。

## 修复

- 增加 Agent 回执容错解析，自动修复说明文字中的未转义引号和字符串内换行。
- 自动规范化修复后的 `digest-receipt.json`。
- 修复前保留 `digest-receipt.json.invalid-时间.bak` 备份。
- 无法修复时在界面明确显示回执格式错误，不再静默沿用旧数据。
- 保留逐文件 SHA-1、状态、置信度和知识成果路径。

针对本次实际数据验证结果：17 份资料中 8 份完整覆盖、9 份失败，覆盖率为 47%。
