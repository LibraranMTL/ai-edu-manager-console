# Windows 0.9.10 / Android 0.6.2 P0-P2 性能与易用性优化

发布日期：2026-07-22

## 发布版本

- Windows 主机端：0.9.10
- Windows 学生终端：0.9.10
- Android 学生终端：0.6.2

## P0：稳定性与后台执行

- 主机状态目录计数增加五分钟缓存，非实时状态轮询降为 30 秒，上传记录和时间线只在相关页面读取。
- 资料来源扫描、批量导入、资产索引重建、资产治理分析和跨项目知识索引改为异步调用，执行期间可以切换页面。
- 主机接收学生或项目资料时采用限额流式写入、增量 SHA-1 和临时文件原子发布；Android 同步改为分块流式上传，旧版 multipart 终端仍可连接。
- 设置、设备、学生、上传、资产、项目、任务和消化状态等关键 JSON 统一使用原子替换。

阶段门禁：目录缓存、异步 IPC、流式上传、异常清理、原子状态写入和既有业务测试全部通过。

## P1：首页与普通用户操作

- 首页聚合为“今日教育资料闭环”：资料进入、自动消化、成长沉淀、档案与报告。
- 根据真实状态只突出一个主要下一步；Agent、版本和诊断工具收纳在“高级工具与版本”。
- 耗时操作在全局后台状态条持续显示，不再锁住当前资料页面。

阶段门禁：首页主操作唯一性、高级入口默认折叠、后台任务可见性和真实页面跳转均通过。

## P2：首屏资源与发布构建

- 二维码依赖改为按需加载，并拆分 React、图标和二维码缓存块。
- 主入口 JavaScript 从约 702 KB 降至 464,206 字节；二维码模块不在首页预加载。
- 修复 Windows 构建清理命令静默遗留旧哈希资源的问题。最终主机发布包包含 68 个前端资产，68 个均可达，无旧资源残留。
- 当前仍超过 500 KB 的构建提示只涉及按需加载的 Mermaid/Cynefin 图表模块，不进入首页主入口。

阶段门禁：270/270 自动化测试通过；Windows 主机、Windows 学生端和 Android 学生端均构建成功；网页与 PDF 手册已重新生成并检查。

## 升级兼容性

- 不移动或重命名学生知识库、项目目录和既有资料。
