# Windows 0.7.26 学习项目人工消化与 P0 闭环

## 本版完成

- 重排项目详情操作区，按钮自动换行并与项目概览卡片保持独立布局。
- 移除“自动化开/关”和 Codex CLI 自动执行入口。
- 项目可选择 Agent，复制消化命令后人工粘贴到对应工具执行。
- 消化状态升级为文件 SHA-1 清单、提交批次和增量处理记录。
- 归档前检查学生绑定、待消化资料、暂存资料和待审核知识。
- 归档动作增加来源版本幂等键，防止重复执行产生重复内容。
- 审核通过的概念、实体、摘要、问答与综合知识逐项进入学生对应知识目录。
- 归档存在失败项时不再标记完成，项目进入“归档失败”状态并保留审计信息。

## 人工消化流程

1. 将工作空间资料导入暂存层并完成筛选、晋升。
2. 在项目中选择使用的 Agent。
3. 点击“复制消化命令”，粘贴到对应 Agent。
4. 点击“标记已提交”。
5. Agent 完成后写回 `project-digest-state.json`，再点击“同步消化结果”。
6. 审核项目知识，生成归档清单并执行归档。
