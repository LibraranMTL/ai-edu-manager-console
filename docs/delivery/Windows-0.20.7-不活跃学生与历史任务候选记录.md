## 交付范围

- 不活跃学生不再生成新的周期、事件或规划任务卡，任务中心的学生资料消化与知识库维护快捷卡也不再显示该学生。
- 学生变为不活跃后，尚未执行的自动任务退出当前队列；运行、等待结果和审核中的任务安全收尾；手工练习评阅与协作任务保留。
