# Windows 0.7.20 写作项目模板说明

## 本次重点

学习项目的“项目工作空间模板”新增“写作项目”。该模板用于 `项目工作空间` 下的人类写作流程目录，不用于 `项目知识空间`。

## 写作项目目录

默认创建以下工作空间文件夹：

- 参考资料
- 选题策划
- 写作大纲
- 写作规则
- 草稿
- 修改反馈
- 定稿

## 边界说明

- “写作项目”模板只影响 `项目工作空间`。
- `项目知识空间` 仍固定使用 LLM Wiki schema，包括项目原始资料库、概念库、实体库、摘要库、问答精华库、综合汇总库、项目报告和知识贡献。
- 对已有学习项目应用该模板时，只补建缺失的工作空间文件夹，不移动、不删除、不覆盖已有资料。

## 验收要点

- 新建学习项目时可选择“写作项目”。
- 选择后文件夹清单显示参考资料、选题策划、写作大纲、写作规则、草稿、修改反馈、定稿。
- 已有项目可在详情页应用“写作项目”模板。
- `项目工作空间/工作空间结构.md` 继续说明工作空间与知识空间的边界。
