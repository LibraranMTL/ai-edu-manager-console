# Windows 0.21.2 自动会话资料统一处理 R25 候选验收

本次将自动会话采集与资料分类投递彻底分开：采集端只产生不可变对话资产；资料收件箱统一承担分类、自动投递、人工改投和异常恢复。

## 实现结果

- 全局 Agent 配置升级到 v4，新增 `capturedConversationRouting.enabled/authorizedAt`，采用原子保存、版本检查、迁移备份和变更记录。
- 已启用全局授权的旧用户以升级时间作为自动处理边界，不回溯旧会话；重新启用全局授权或会话路由时生成新的边界。
- 自动会话来源默认启用、阈值 `0.95`、允许高可信自动投递；手工对话历史仅生成分类建议。
- 项目已归属会话、已有回执或内容哈希已处理会话不会进入重复分类和派发。
- 全局停用会阻止主机 Hook、Windows 学生终端和外部接口的新会话，并安全结束当前已到达的授权会话。
- 学生暂停／不活跃／归档在分类前和投递前均重新检查；暂停可排队恢复，不活跃或归档停止新工作但保留已有资产。
- 自动采集页与对话分享页删除重复投递主操作，统一跳转资料收件箱；旧 `deliverConversationMaterials` 保留给内部投递和历史回执恢复。
