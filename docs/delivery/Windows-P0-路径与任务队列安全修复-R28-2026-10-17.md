## 修复内容

1. 路径扫描不再将 `edu://` 内部片段误判为 Windows 盘符路径。引号、UNC 路径、文件名与子目录均按精确范围处理，不再跨正文进行宽泛字符串替换。
2. 路径替换只依据本学生已确认的映射；不再按“原始资料”等模糊词猜测目的目录。未确认的历史根目录、未闭合引号不自动改写；当前知识库内真正缺失的文件也不能通过改写成逻辑路径隐藏问题。
3. 增加版本化、幂等的队列治理。归档需同时验证从未执行、无关联执行文件、无资料回链及其他条件；读取失败不能当作空数据。通过主机 Worker 持久保存，迁移前自动备份。
4. 修复执行准备期间候选刷新覆盖已批准状态的竞争问题，保持合法状态转换，不放宽 blocked 直接变 running 的协议限制。
5. 统一结果未知的识别与保护，候选刷新不会再冲掉恢复标记、安全重试计划或归档记录。未来计划不计入当前催办，并在到期时失效读模型缓存。
