# Windows 0.7.39 与平板终端 0.5.2：屏幕资料采集

## 功能位置

`资料收集与处理` -> `屏幕资料采集`

## Windows

- 可选择整个屏幕或指定应用窗口。
- 支持智能混合、内容变化、固定间隔三种采集策略。
- 支持 15 至 120 分钟的限时连续采集。
- 支持暂停、继续、重点截取和手动结束。
- 支持全局快捷键：`Ctrl+Shift+1` 立即截取，`Ctrl+Shift+2` 暂停/继续，`Ctrl+Shift+3` 标记重点。
- 采集期间显示桌面悬浮控制条，并可从系统托盘暂停、继续、重点截取、结束或打开采集箱。
- 采集画面先进入候选收件箱，并登记为 `candidate` 文件资产。
- 只有点击“晋升资料”后，截图才进入学生原始资料库和待消化队列。
- 可在创建采集会话时关联学习项目，但不会未经审核直接写入项目知识空间。

## Android

- 用户主动授权后启动连续屏幕采集。
- 支持智能混合、内容变化、固定间隔三种策略。
- 采集期间通过前台通知显示状态，并提供重点、暂停/继续和结束操作。
- 支持在 Android 顶部快捷设置中添加“屏幕资料采集”磁贴。
- 采集图片先保存在应用本机采集箱，结束后由用户点击“上传采集资料”进入当前学生原始资料库。
- 已上传图片会在本机登记，避免重复上传。

## 数据流程

```text
屏幕帧
  -> 低频检测
  -> 画面差异判断
  -> 自动去重
  -> CaptureSession / CaptureItem
  -> 候选文件资产
  -> 人工晋升或上传
  -> 学生原始资料库
  -> Agent 资料消化
  -> 知识空间
```

## 隐私与平台边界

- 不提供全天候、无提示的后台截屏。
- Android 每个采集会话都由用户通过系统界面授权。
- Android 连续采集运行期间保持可见的前台通知。
- 银行、考试、视频版权等使用安全窗口的应用可能禁止截屏或返回黑屏。
