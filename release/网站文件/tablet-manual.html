AI教育管家平板终端家长版操作手册

适用版本：Android 平板终端 0.5.7

配套主机：Windows 0.7.50

1. 安装与首次连接

  1. 安装 AI教育管家平板终端 APK。
  2. 确保 Windows 主机已切换到主机-平板模式并启动主机服务。
  3. 确保平板与 Windows 电脑连接同一 Wi-Fi。
  4. 在平板“连接设置”中点击“查找附近主机”，从列表中选择当前电脑。
  5. 查看 Windows 端显示的 6 位平板配对码，将其输入平板并点击连接。
  6. 首次登记成功后，平板显示“已连接，等待 Windows 授权”。
  7. 请管理员在 Windows 设备列表中核对该平板，并授权全部或指定学生。
  8. 授权后平板每 5 秒自动检查一次，通常会在数秒内载入学生，最长自动等待约 60 秒。

如果无法使用附近主机发现，仍可选择以下方式：

  • 扫码绑定主机：扫描 Windows 端连接二维码；
  • 粘贴连接信息：粘贴完整连接文本后连接；
  • 导入并连接：从以前导出的连接备份恢复。

“网络可达”不等于“设备已授权”。只有设备身份验证和学生授权均通过后，平板才能读取档案和上传资料。

2. 选择学生

已授权设备可以查看允许访问的学生。选择学生后，上传资料、查看档案和屏幕采集上传都会归入该学生。

如果学生列表为空：

  1. 检查页面是否提示等待 Windows 授权；
  2. 请管理员检查设备授权范围；
  3. 等待自动检查，或点击刷新学生；
  4. 约 60 秒后仍为空时，检查该设备是否授权了有效学生；
  5. 仍失败时重新连接主机。

3. 上传学习资料

平板支持拍照、选择图片、选择文件、扫描下载目录，以及从其他应用“分享至 AI教育管家”。

上传前确认学生；上传成功后，资料进入 Windows 主机上的学生原始资料库和待消化队列。资料的 AI 消化、覆盖审计和知识审核由 Windows 主机端完成。

4. 连续屏幕资料采集

位置：资料收集与处理 → 屏幕资料采集。

  1. 选择当前学生和可选学习项目。
  2. 选择智能混合、内容变化或固定间隔策略。
  3. 设置采集时长。
  4. 通过 Android 系统界面授权屏幕捕获。
  5. 采集中使用前台通知或悬浮控制进行重点截取、暂停、继续和结束。
  6. 结束后检查本机采集箱并点击“上传采集资料”。

Android 每次采集会话都需要用户主动授权，采集期间保持可见通知。系统不会在后台无提示地持续截屏。银行、考试和版权视频应用可能禁止截屏或返回黑屏。

5. 顶部快捷设置与系统分享

可在 Android 顶部快捷设置中添加“屏幕资料采集”磁贴，快速开始、暂停或继续采集。

浏览器、相册、PDF 阅读器或文件管理器中的资料，可使用系统“分享”功能发送到 AI教育管家。分享原始文件通常比截图保留更多标题和来源信息。

6. 查看教育档案

选择学生后打开“查看教育档案”或“学情报告”。平板从 Windows 主机读取已授权学生的 Markdown 档案，并可缓存最近文档。

若报告为空，通常表示资料尚未完成 Agent 消化、知识贡献尚未审核发布，或 Windows 主机未刷新报告索引。请在主机端检查完整工作流。

7. 连接备份

Android 0.5.7 在连接设置中提供：

  • 导出连接备份：保存主机地址、远程地址、连接模式、设备身份和设备授权令牌；
  • 导入并连接：读取备份，保存配置并立即验证主机连接。

若备份来自不同安装身份，系统会要求确认后才恢复原设备身份。

连接备份包含授权令牌，属于敏感文件。只应用于同一平板重装或恢复，不要转发给他人、上传公开网盘或作为普通资料分享。

8. 局域网与远程连接

在同一 Wi-Fi 下，优先点击“查找附近主机”。平板会发现 Windows 0.7.50 主机服务，用户只需选择电脑并输入一次性 6 位配对码，不需要手工输入 IP 地址。

局域网也可使用 Windows 主机显示的本地地址。远程使用需由管理员配置 Tailscale 或其他可信网络地址；附近主机发现仅用于当前局域网，不负责跨互联网搜索电脑。

连接失败时检查：

  1. 主机服务是否运行；
  2. 平板与主机是否在同一网络；
  3. 主机地址和端口是否变化；
  4. Windows 防火墙是否允许主机服务；
  5. 设备是否被撤销；
  6. 连接备份是否属于当前主机和当前设备。

如果“查找附近主机”没有结果，还应检查路由器是否启用了访客网络或客户端隔离，以及 Windows 防火墙是否允许 AI教育管家访问专用网络。此时可改用扫码、粘贴连接信息或连接备份。

9. 隐私与安全

  • 仅上传用户主动选择或主动采集的资料；
  • 连续屏幕采集始终显示系统通知；
  • 设备只能访问 Windows 授权的学生；
  • 设备被撤销后，原令牌不能继续访问；
  • 不要在截图中保留密码、支付信息、私人聊天或其他学生的敏感资料；
  • 不要公开连接二维码、配对码或连接备份。

附近主机发现不会广播 API Token、设备授权令牌或 6 位配对码。6 位配对码成功使用后即失效。

10. 常见问题

显示已连接但学生未授权

这是正常的首次连接状态。请在 Windows 设备列表中找到该平板并授权学生。授权后 Android 0.5.7 会自动检查并载入学生；超时后可手动刷新。

Windows 看不到新设备

确认平板使用 0.5.7、Windows 使用 0.7.50，并重新完成“查找附近主机 → 输入 6 位配对码”；不要只检查网络健康状态。Windows 主机服务需要保持运行。

查找不到附近主机

确认电脑和平板处于同一 Wi-Fi，主机服务已启动，Windows 防火墙允许专用网络访问，并关闭路由器的访客网络或客户端隔离。仍找不到时使用扫码、粘贴连接信息或导入连接备份。

已撤销设备无法连接

管理员可在 Windows 端恢复该设备；若设备记录已删除，则平板需要重新完成连接和授权。

重装后如何恢复

在旧安装可用时导出连接备份。重装后选择“导入并连接”，确认设备身份恢复，再验证 Windows 授权状态。

截图上传后没有知识内容

平板上传只完成资料采集。管理员还需在 Windows 端执行 Agent 消化、同步回执，必要时完成覆盖审计和知识审核。
