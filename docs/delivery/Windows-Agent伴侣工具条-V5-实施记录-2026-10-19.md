## 已实施

- 常驻工具条由旧 `820×54/96px` 两行结构改为约 `340×34px` 单行微型结构；
- 第一行顺序为：学生 ID、采集、整理、学习、AI设置、关闭；
- 删除“目标 Agent”和三个点省略号常驻入口；
- AI设置复制当前学生配置 Agent 的完整连接指令；没有已生成连接指令时使用明确标注能力边界的通用协作指令；
- 采集菜单提供快速截屏/连续采集、录音、拍照和 AI 会话；
- 整理菜单提供资料选择、消化资料、资料收件箱和学习归档；
- 学习卡片调整为学习、互动、测验、核验、计划五组；
- 新增知识闪卡、思维导图、信息图、图表总结、游戏化学习、动画视频学习、目标设置、学习计划、每周行动等详细提示词；
- 所有提示词加入当前学生档案快照、资料范围、执行协议、输出要求、成功标准与教育证据边界；
- 动画视频学习明确要求实际调用工具/技能并输出可播放视频，不接受文案、脚本或分镜冒充成品。

## 能力边界

- 剪贴板复制不会自动向 Codex、WorkBuddy 或其他外部窗口粘贴和发送；
- 资料查询和归档仍以真实注册、授权、学生范围与回执为准；
- Agent 生成成果不等同于学生已经掌握；
- 没有视频/动画生成工具时，动画视频任务必须如实失败。

## V5 R3 视觉学习配置修订

- 知识闪卡、思维导图、信息图、图表总结不再显示难度和时长，改为数量（1张、2张、自动、自定义）和风格（简洁、标准、动漫）。
- 自定义数量仅在选择“自定义”时出现，范围为 1–50 张；默认采用“自动＋标准”。
- 核验和计划页不再显示难度、时长，仅保留可选的本次目标；互动和测验继续保留难度、时长。
- 知识闪卡提示词要求 Agent 调用可用的排版、图像、文档或 PDF 工具，实际交付 PNG 预览和 A4 PDF 打印文件；文本、Markdown、代码或制作建议不能冒充成品。
- 多卡双面打印要求背面镜像排列，且检查中文字体、分页、裁切线、清晰度和正反对应；无生成文件能力时必须明确失败。
