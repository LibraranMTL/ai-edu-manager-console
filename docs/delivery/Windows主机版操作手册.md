# AI教育管家 Windows 主机版操作手册

适用版本：Windows 主机控制台 0.4.5  
适用对象：运营人员、教育顾问、装机人员、管理员  
默认学生资料根目录：`D:\学生资料`

## 1. 产品定位

Windows 主机版是 AI教育管家的管理员端和本地服务端，负责：

- 创建和管理学生知识库
- 生成 QClaw 教育管家 Agent 初始化内容
- 启动主机服务，供平板终端连接
- 接收平板上传的学习资料
- 查看和管理学情 Markdown 档案
- 维护平板设备授权、上传记录和消化状态

普通家长或学生日常只需要使用“AI教育管家平板终端”，不需要操作 Windows 主机版。

## 2. 安装与启动

1. 下载 Windows 包：`AI-edu-manager-console-Windows-0.4.5.exe`
2. 放到本机固定目录，例如：
   - `D:\AI教育管家\主机控制台`
   - `C:\AI教育管家\主机控制台`
3. 双击运行：
   - `AI-edu-manager-console-Windows-0.4.5.exe`
4. 首次启动后，建议在“系统设置”确认学生资料根目录为：
   - `D:\学生资料`

如果启动后界面为空白，请确认使用的是 `0.4.5` 或更新版本。

## 3. 首次配置流程

推荐流程：

1. 打开 Windows 主机控制台
2. 在首页选择“本机独立模式”或“主机-平板模式”
3. 新建或初始化学生教育管家
4. 按向导生成学生知识库
5. 在 QClaw 中创建对应 Agent
6. 设置 Agent 的 Soul 角色内容
7. 设置资料消化任务
8. 如需要平板上传资料，切换到“主机-平板模式”并启动主机服务

## 4. 初始化学生教育管家

进入“初始化教育管家”或“新建教育智能体”。

填写：

- 学生姓名
- 年级
- 学校
- 当前目标
- Agent 工具，正式交付建议使用 QClaw

系统会创建学生知识库，例如：

```text
D:\学生资料\张三知识库
```

知识库内主要目录和文件：

```text
D:\学生资料\张三知识库\AGENT.md
D:\学生资料\张三知识库\张三原始资料库
D:\学生资料\张三知识库\张三学情分析汇总
D:\学生资料\张三知识库\输出结果
```

0.4.4 起，生成的 Soul 角色内容会包含工作规则：

```md
## 工作规则

该 Agent 的工作协议使用：D:\学生资料\张三知识库\AGENT.md
后续所有学习资料消化都围绕该学生知识库执行。
```

不同学生会自动替换为对应学生知识库路径。

0.4.5 起，初始化和新建教育智能体支持两种创建方式：

- 创建标准新知识库：按 `D:\学生资料\学生名知识库` 创建新目录
- 接管已有知识库：登记已有 QClaw、Hohu、Marvis 或 OpenClaw 知识库目录，不移动、不复制、不删除原文件

接管已有知识库时，控制台会记录该学生真实的 `AGENT.md`、原始资料库、学情分析汇总和输出结果路径。后续上传资料、查看档案和复制消化指令都会使用这些真实路径。

## 5. 配置 QClaw Agent

推荐设置方式：

1. 打开 QClaw
2. 创建新 Agent，名称建议：
   - `张三 AI教育管家`
3. 从控制台复制“角色 Soul”内容，粘贴到 QClaw 的角色、人设或系统提示词位置
4. 从控制台复制长期记忆内容，粘贴到 QClaw 的记忆或长期背景位置
5. 让 QClaw 读取并执行：
   - `D:\学生资料\张三知识库\AGENT.md`
6. 检查是否已创建原始资料库、学情分析汇总等目录

## 6. 启动主机服务

如需让平板终端上传资料和查看档案：

1. 回到首页
2. 选择“主机-平板模式”
3. 找到“主机服务”
4. 点击“启动主机服务”
5. 确认显示：
   - 局域网地址
   - Tailscale 地址，如已安装配置
   - 配对二维码
   - 配对码

平板端扫码后会自动保存连接地址和设备 token。

## 7. 平板设备管理

进入主机服务区域后，可以查看“已绑定设备”。

每台设备会显示：

- 设备名称
- 在线 / 离线状态
- 最近访问时间
- 最近访问 IP
- 客户端信息
- 上传文件数量
- 授权学生范围

可执行操作：

- 重命名设备
- 撤销设备
- 允许访问全部学生
- 默认授权新学生
- 为设备勾选可访问的具体学生

如果平板丢失、客户更换设备或误绑定，应立即点击“撤销设备”。

## 8. 上传资料与待消化状态

平板上传的资料会进入对应学生的原始资料库，例如：

```text
D:\学生资料\张三知识库\张三原始资料库
```

Windows 主机端会记录：

- 上传时间
- 学生
- 设备
- 文件名
- 文件大小
- 文件路径
- 待消化状态

资料消化状态通常包括：

- 待消化
- 已提交消化
- 已处理完成

## 9. QClaw 消化资料

推荐流程：

1. 进入“教育管家问答”或相关学生操作区
2. 复制资料消化指令
3. 粘贴到该学生的 QClaw Agent 中执行
4. QClaw 消化完成后，应更新：
   - `index.md`
   - `log.md`
   - 对应摘要、汇总、问答精华等 Markdown 文件
5. 在 Windows 控制台同步消化结果

如果原始资料库没有新增资料，QClaw 应在 `log.md` 中记录“无新增资料”，不要重复生成摘要。

## 10. 查看教育档案

进入“查看教育档案”。

可按分类查看：

- 资料摘要
- 综合汇总
- 问答精华
- 其他
- 全部文件

系统会隐藏部分技术文件，如：

- `AGENT.md`
- `log.md`
- 配置类文件

如果看不到新档案，请先确认 QClaw 已完成资料消化，并刷新档案列表。

## 11. 备份与恢复

建议在以下时间点做备份：

- 装机完成后
- 新增多个学生后
- 大量资料上传后
- 版本升级前

备份内容包括：

- 学生索引
- 设备授权
- 上传记录
- 主机事件

恢复备份会覆盖当前主机数据，请谨慎操作。

## 12. 更新版本

进入“系统设置”或版本更新区域：

1. 点击“检查更新”
2. 如发现新版本，下载 Windows zip 包
3. 关闭当前控制台
4. 解压新版
5. 启动新版 exe

更新清单地址：

```text
https://www.greatbg.com/download/edu-manager-version.json
```

## 13. 常见问题

### Windows 启动后空白

请确认使用 `0.4.5` 或更新版本。旧版曾出现启动渲染异常。

### 平板无法连接主机

检查：

- Windows 主机服务是否已启动
- 平板和电脑是否在同一局域网
- Windows 防火墙是否允许当前端口
- 平板是否使用了正确二维码或连接信息
- 设备 token 是否被撤销

### 平板已连接但看不到学生

检查：

- Windows 是否已创建学生
- 设备是否有学生访问权限
- 是否勾选“允许访问全部学生”

### 上传成功但 QClaw 没有看到资料

检查：

- 上传文件是否进入对应学生的原始资料库
- QClaw Agent 是否使用正确的 `AGENT.md`
- Soul 中的工作协议路径是否对应当前学生知识库
