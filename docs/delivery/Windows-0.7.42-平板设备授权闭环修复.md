# Windows 0.7.42 / 平板 0.5.3 - 设备授权闭环修复

## 问题

旧版平板只要能够访问主机健康接口，就会显示“已连接”。当刷入的是管理员连接信息或无效设备令牌时，平板随后无法读取学生，Windows 端也没有对应设备可供授权。

## 修复

- 平板显示“已连接”前必须通过设备身份验证。
- 刷入管理员连接信息后，平板自动换取独立设备令牌并登记到 Windows。
- 新登记设备默认处于“待授权”状态，不会直接访问任何学生。
- Windows 设备列表实时显示待授权设备，并提供“授权全部学生”按钮。
- 平板明确显示“已连接，待 Windows 授权”或“授权验证失败”，不再把网络可达误报为连接成功。
- 学生列表接口返回授权状态，避免把“未授权”误报成“主机没有学生”。

## 操作流程

1. Windows 启动主机服务并复制平板连接信息。
2. 平板粘贴或刷入连接设置，点击“连接主机”。
3. Windows 打开主机服务设备列表，找到标记为“待授权”的平板。
4. 点击“授权全部学生”，或逐个勾选允许访问的学生。
5. 平板点击“刷新学生”，即可读取已授权学生。
