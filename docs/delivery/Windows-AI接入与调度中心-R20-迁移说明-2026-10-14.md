# R20：AI 接入与调度中心迁移说明

候选标识：`0.21.1-ai-control-r20-agent-settings-20261014`。本包是候选，不是正式发布，也不会自动替换正在运行的旧便携版程序。

## 开始使用

1. 正常退出旧版教育管家后，启动文件名含 `ai-control-r20-agent-settings-20261014` 的 EXE。进入“系统设置 → Agent设置管理 → AI 接入与调度中心”，页面标题下应显示“R20 · Windows 候选”。无学生档案也能管理连接。
2. 阅读“全局授权”说明后启用一次。覆盖所有现有、以后新增的有效学生，以及已支持的任务执行、知识查询、受控草稿写入和新消息采集。停用后阻止新请求；业务内容写入审核仍保留。
3. 在执行器列表连接官方账号，或直接填写独立显示的 LLM API 地址、模型及密钥并测试。官方账号登录不是教育管家的数据授权，两者不会混为一个状态。
4. 调整全局顺序。系统过滤不支持当前合同、被停用或未就绪的执行器，API 固定作为自动 Agent 后备。联网研究目前仍由已接入该合同的 Codex 通道承担，API 不冒充联网研究。
5. 在“收集与整理 → AI对话采集 → Agent会话自动采集”明确选择采集对象。仅切换左侧查看的学生不会改绑当前会话。没有归属时等待选择；已有活动会话阻止跨学生切换。厂商 Hook 的本机信任仍按官方机制完成。

## 页面变化

- “Agent设置管理”仅保留 3 个顶层入口：“AI 接入与调度中心”“Agent 数据管理”“Agent连接管理”。
- “Agent 数据管理”包含“记忆管理”“规则管理”“人设管理”；“Agent连接管理”包含“外部写入审核”“Agent问答设置”。旧入口自动转到对应分页面。
- 中心包含全局授权、执行器与连接设置、默认调度顺序、最近执行及异常四部分。
- 原“Agent 工具控制”内置／自定义工具并入中心统一执行器列表，不再维护第二份安装状态和默认工具。
- 记忆文件扫描／备份／合并保留在“Agent 数据管理 → 记忆管理”的高级功能中；已有文件未删除。
- 外部 Agent 待审核事项及能力范围保留在“Agent连接管理 → 外部写入审核”，与连接授权分开。
- “收集与整理”中的“对话收集”和“会话自动采集”合并为一个“AI对话采集”入口，下设“对话分享资料箱”和“Agent会话自动采集”两个分页面；旧快捷采集路由继续兼容。

## 能力与安全边界

统一登记 14 个内置工具、LLM API 和最多 40 个自定义工具。Codex、WorkBuddy 复用已有受控适配，具体支持项以中心显示为准。其余没有通过相应自动任务合同的内置工具及自定义 HTTPS／EXE 入口标为手工交接，不因“已安装”就宣称能自动执行。

资料消化后台明确失败且可安全重试时，按顺序继续其他通道；全部不可用时只保留一条等待选择目标的任务。点击“复制任务并打开所选工具”后才打开一个目标。检查并手工发送后，在原任务导入结果。结果仍由宿主校验，不把 Agent 自报成功当作完成。

请求结果未知、取消或授权变化时不自动回退；升级与重启不重新派发旧的未知／等待结果身份。已有知识产物从宿主提交检查点恢复，不再调用模型生成同一批结果。恢复期间依然检查当前数据范围。

“全局授权”不等于“一个 token 可以访问所有学生”。宿主仍签发单学生凭据，每次执行绑定学生／项目／操作。查看另一学生不修改外部会话身份；团队知识等另有业务政策的范围不被本次改造绕过。

## 标准 CLI 接入

仅选择本机绝对路径的可信 `.exe`，不允许网络共享路径、命令脚本或拼接 shell 命令。参数为独立 JSON 字符串数组，例如 `[]` 或 `["--json"]`，不要在参数中放密钥。

进程以 `shell:false` 运行；stdin 接收一个 JSON 对象并换行，stdout 只返回协议 JSON；日志应输出到 stderr。CLI 是用户信任的本机程序，不提供操作系统沙箱保证。

输入示例：

```json
{"protocol":"edu-manager.standard-cli.v1","requestId":"固定请求标识","type":"generate","prompt":"合成任务指令","schema":{"type":"object","required":["answer"],"properties":{"answer":{"type":"integer"}}}}
```

输出示例：

```json
{"protocol":"edu-manager.standard-cli.v1","requestId":"固定请求标识","ok":true,"result":{"answer":42}}
```

连接测试先发送 `type:probe` 和 `input.nonce`，程序须返回 `result.nonce`；随后测试资料分类、资料消化和学习卡片三个合成合同。验证绑定可执行文件 SHA-256 和参数；文件／参数变化后须重新验证。实际任务继续校验结构和业务来源。CLI 暂不接受图像输入。超时／异常退出不能证明远端未执行，保留未知状态，不自动重复发送。

## 迁移、文件保留与回退

全局设置存于当前 Windows 用户数据目录的 `agent-control/policies.json`，schema 为 `edu-manager.agent-control.v2`，使用原子替换、版本检查和变更记录。

首次保存全局设置前，已有策略备份为 `policies.json.pre-global.bak`；原逐学生／项目策略同时归档到 `legacyPolicies`。已有外部访问授权文件备份为 `agent-access-grants.json.pre-global.bak`。厂商登录和 API 密钥未迁移至新存储，也不会重新索取每位学生的登录。

首次启用前兼容旧策略；首次保存全局设置后，旧策略不再参与运行时决策。升级本身不改写任务队列执行身份、原始资料或记忆文件。

需要回退时先全局停用并正常退出，备份整个当前用户数据目录。由管理员在确认无运行中／未知任务后恢复上述两个备份，再使用 R19 候选。不要在运行时覆盖配置，不要仅删除任务记录来“解除”未知状态。授权期间新增内容与任务需保留；回退旧程序不代表这些数据应被删除。

## 待真实连接验收

本轮没有配置或读取用户 LLM API 密钥，没有向真实模型发送学生数据。真实 API 连接、费用、模型兼容性须使用用户在本页配置的连接继续验收。厂商真实账号的登录、桌面发送以及第三方服务返回结果也不能由合成测试替代。
