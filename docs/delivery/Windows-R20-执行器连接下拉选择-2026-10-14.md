# R20 执行器连接布局优化验收记录

日期：2026-10-14。候选标识：`0.21.1-ai-control-r20-executor-selector-20261014`。本候选在 R20 Agent 设置管理候选基础上继续优化“执行器与连接设置”，不覆盖此前候选，也未发布到正式下载渠道。

## 改动

- 将同时铺开的全部 Agent 卡片改为一个“选择 Agent／执行器”下拉框；页面一次只展开一个执行器。
- 下拉选项按“内置 Agent”“LLM API”“自定义 Agent 工具”分组，并在名称后显示当前连接状态。
- 保留原有连接／授权、连接验证、CLI 协议验证、打开工具、官网／下载、移除工具等操作，不改变任何执行器设置数据。
- 选择 LLM API 时仍在当前区域直接显示地址、模型、密钥和连接测试；自定义工具编辑区保持不变。
- 切换下拉项只改变当前展示，不修改执行器启用状态、连接状态或全局调度顺序。
- 桌面与窄屏均显示总数、启用数和可自动执行数；窄屏改为单列，不产生文档级横向溢出。
