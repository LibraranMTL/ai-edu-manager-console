# Windows 0.8.3 学习项目安全删除

## 功能说明

已有学习项目的详情工具栏新增“删除项目”。该操作采用安全删除，只从教育管家的学习项目索引中移除记录，不删除项目根目录、项目工作空间、项目知识空间、文件资产或审计记录。

删除前会显示二次确认，并明确说明物理文件仍会保留。删除完成后，项目从当前列表消失，同时写入 `.edu-manager/项目记录已移除.json` 恢复快照。

## 恢复项目

在学习项目页面点击“已删除项目”，可以查看已删除项目、删除时间和文件保留位置。点击“恢复项目”后，系统重新将项目写入索引，原工作空间和知识空间保持原位。

## 兼容性

- 支持读取旧版“移除项目记录”生成的 v1 快照。
- 保留旧版 IPC 接口，直接升级时不会因新旧渲染进程短暂并存而失效。
- 不提供从该入口彻底删除项目物理目录的能力。
