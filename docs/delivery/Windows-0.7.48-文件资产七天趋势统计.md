# Windows 0.7.48 文件资产七天趋势统计

## 更新内容

- 文件资产中心新增“最近 7 天资产变化”双曲线图。
- 紫色曲线按资产首次登记时间统计每日新增资产数量。
- 绿色曲线按引用首次建立时间统计每日新增引用次数。
- 图表显示最近 7 个自然日、两项 7 天合计和缺少历史日期的数据提示。
- 修复扫描并补建资产索引时，同一引用关系可能被重新写入当天时间的问题；重复扫描不再改变引用首次建立日期。

## 统计口径

- 统计周期包含今天及此前 6 个本地自然日。
- 同一资产可在同一天建立多条不同引用，每条唯一引用计数一次。
- 旧记录缺少资产登记时间或引用建立时间时，不猜测日期，也不计入曲线，并在图表下方提示数量。

## 验证

- 资产与引用跨日聚合测试。
- 无日期历史记录兼容测试。
- 索引重建保留引用首次时间测试。
- Windows 前端生产构建验证。
