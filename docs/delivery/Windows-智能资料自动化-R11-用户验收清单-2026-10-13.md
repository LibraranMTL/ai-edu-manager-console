# Windows 智能资料自动化 R11 用户验收清单

请使用候选 `smart-material-automation-r11-20261013`。下列项目涉及真实账号、真实学生资料、业务判断或指定低配设备，需要您参与；开发侧合成验证不能代替。

## A. 目标机与 Agent

- [ ] 在验收机运行候选，确认旧资料、任务、卡片、课程和发布记录仍可查看。
- [ ] 若该机 WorkBuddy 后台 CLI 尚未授权，按官方页面完成一次独立授权；不要发送密码、Token 或复制其他机器凭据。
- [ ] 主动执行一次受控检测，确认分类与消化任务档分别显示可用；关闭并重启教育管家，确认有效期内不再反复要求检测。
- [ ] 更新或替换 WorkBuddy 后再次检查，确认 CLI 哈希变化会使旧资格失效，而不是继续自动发送资料。

## B. 分类、投递与纠正

- [ ] 用正文含唯一有效项目编号的非敏感资料验证可信自动投递。
- [ ] 用只有相似主题、两个项目编号、虚构敏感文字和跨学生提示注入分别验证：进入人工确认且不跨学生投递。
- [ ] 批量只确认学生，确认系统随后推荐项目；可信项自动投递，其余项仍可人工选择项目。
- [ ] 删除一份尚未投递的源文件，确认可移除待处理记录；分析失败不能让记录无回执消失。
- [ ] 对已投递资料执行项目纠正，确认新目标核验成功后才撤销旧关联；已被引用的旧资料仍保留并标记变化。

## C. 学生资料消化与 OCR 复用

- [ ] 为一个非敏感测试学生选择 WorkBuddy，导入一份可核对的文档或图片并完成分类、投递、消化。
- [ ] 检查生成内容只引用该学生固定资料，没有跨学生内容或无来源结论；原件仍在原位置且字节未变。
- [ ] 对图片检查任务诊断：相同版本应显示完整提取复用，分类和消化合计只做一次 OCR；修改图片或 OCR 参数后允许重新提取。
- [ ] 在消化过程中修改原件，确认任务拒绝结算；恢复后重新执行不会重复登记资料。
- [ ] 抽查学生摘要索引、日志和正式知识目录，确认内容质量可接受后再批准面向真实资料长期自动运行。

## D. 业务质量样本

- [ ] 准备与规则构建集分离的 200 份标注资料，覆盖本机、下载、分享、对话历史和自动会话，以及歧义、无关、敏感、重复样本。
- [ ] 记录首选建议准确率、自动投递准确率、自动覆盖率、待确认率和跨学生错误数；不能用全部转人工达到准确率。
- [ ] 至少 5 名代表用户分别处理同等难度的 30 份资料，记录原流程和 R11 的总人工时间，包括纠正时间。

## E. 低配目标机性能

- [ ] 在四核／8GB／SSD 机器准备 10,000 个测试文件和 10,000 条测试任务，先记录关闭自动化时的交互基线。
- [ ] 开启扫描和后台分析，测量收件箱翻页、切学生、打开卡片的 P95；目标不高于 300 ms，且相对劣化不超过 20%。
- [ ] 连续运行四小时，混合立即扫描、计划扫描、分类、消化、课程／卡片发布和暂停恢复；结束后队列清空。
- [ ] 记录宿主、提取进程和 WorkBuddy 的内存、句柄和进程数；确认无任务时无 Agent 调用、无持续增长。

反馈时请提供时间、任务 ID、来源类型、资料版本、界面提示和是否发生真实文件变化；不要发送真实正文、密码、Token 或登录配置。
