日期：2026-10-09。范围：卡片草稿、OCR、历史作答与卡片、原版文件导入、学生周期任务暂停。沿用现有三入口和原生模块，不引入新的顶级导航、插件系统或模型配置。

## 修复与使用路径

| 问题 | 修改 | 用户操作 |
|---|---|---|
| 草稿无法删除 | 权限校验、版本校验、软删除和撤销；迟到的自动保存不能复活已删除草稿 | 卡片资源 → 卡片管理 → 删除草稿；当前页面可撤销最近一次删除 |
| 本机 OCR 失败 | 优先匹配所选语言，再匹配同语种，必要时回退至已安装语言；显示语言缺失或图片限制说明 | 作答与反馈 → 选择记录 → 重新识别与评阅；识别不可靠时改为文字或提交清晰修改稿 |
| 历史提交无处理路径 | 增加下一步说明、开始评阅、重试、取消和修改稿入口；升级不批量调用 Agent | 选择“历史提交”筛选，打开记录后点击“开始评阅” |
| 历史卡片不可查看 | 今日卡片显式提供历史选择，包括已替换的只读卡片；作答详情显示原题版本 | 今日卡片 → 查看已有／历史卡片；或作答详情 → 本次练习原题 |
| 草稿不能直接上传文件 | 编辑草稿始终显示上传按钮；支持 PDF、PNG、JPG/JPEG，最大 10 MiB；自动切换原版模式并预览 | 卡片资源 → 制作我的卡片 → 直接上传卡片文件 |
| 非活跃学生继续周期任务 | 独立参与状态与可选暂停开关，保存后在调度与实际启动时再次检查 | 学生档案 → 编辑 → 学生参与状态选“暂停／不活跃” → 保持勾选“暂停该学生的周期自动任务” → 保存 |

上传原版文件不会自动构造答案。需要启用评阅时仍须补齐题目对应关系、参考答案或量规；知识讲解与空白卡不强行评分。

历史记录若已经丢失题目或评分依据，不根据作答猜题；显示补建原题入口，允许保留、预览和另存作答。已保留的固定快照仍可查看。原稿和修改稿不互相覆盖，既有成长模型流程不变。

删除草稿不删除已发布卡片、历史作答或其引用文件。撤销按钮针对当前页面最近一次删除，不是新增完整回收站。

## OCR 根因与边界

对截图对应任务进行了只读定位：题目识别语言为 `en`，Windows 实际仅安装 `zh-Hans-CN` OCR。旧脚本只尝试所选语言，失败后给出了过于笼统的提示。

修复后的本地脚本对同一原件提取出 214 个字符，未修改原文件、未上传至外部服务、未安装系统语言包。这只证明识别通道恢复，不证明全文准确；特别是英文手写、数学公式仍需要核对。提取缓存版本已更新，用户重试时不会继续复用旧的卡片提取缓存。

没有任何 OCR 语言包时明确引导安装 Windows 文字识别组件或改为文字作答。超大图片引导裁剪／缩小；一般失败引导查看原件或上传清晰修改稿。

## 自动任务暂停语义

- “不活跃”是保存的学生参与状态，不是当前页面没有选中该学生。
- 默认原有学生保持活跃；暂停／不活跃时默认停止新的本机周期报告、自动重试、资料续批及相关周期研究调度，用户可取消勾选。
- 正在执行的批次安全完成，不强行终止；手动执行仍可用，已提交的卡片评阅不因该设置被搁置。
- 不停止其他学生、共享项目任务或外部 Agent 自建的定时任务。
- 旧客户端未提供这两个新字段时保留现有设置，避免同步档案意外恢复自动任务。
- 本轮没有替用户改变任何真实学生的参与状态。

## 真机验收清单

1. 先备份卡片数据和学生索引，退出旧版，再运行新候选。不要同时打开两个版本写入同一档案。
2. 在赵书源的失败提交中点击“重新识别与评阅”，核对实际识别正文；若不清晰，选择文字修改稿。
3. 打开旧提交，确认显示原题、下一步说明；缺失原题时只提示补建，不伪造反馈。
4. 上传自己的 PDF 和 JPG 卡片，关闭并重新打开草稿，检查原文件预览与保存。
5. 新建测试草稿，取消一次删除、确认一次删除，再撤销恢复；已有发布资源应保持可用。
6. 将测试学生设为暂停并保存，等待原来周期到期，确认不启动新周期任务；手动执行和其他活跃学生不受影响。恢复活跃后按现有调度继续。

候选不等于正式发布：本轮未安装到生产环境，未更新官网、阿里云或推送 Git。真实 Agent 评阅和完整终端链路仍需要用户验收。
