## 升级步骤

Windows：

1. 关闭旧版 Windows 主机控制台
2. 下载新版 zip
3. 解压新版
4. 启动新版 exe
5. 检查版本号
6. 如涉及主机服务，重新启动主机服务

平板：

1. 下载新版 APK
2. 安装覆盖
3. 打开平板终端
4. 检查版本号
5. 检查是否仍能连接主机

## 回滚方案

如新版出现严重问题：

1. 关闭新版
2. 恢复上一版安装包
3. 如涉及数据结构变更，先恢复备份
4. 暂停将新版上传到正式下载目录

回滚注意事项：

- 不要删除 `D:\学生资料`
- 不要删除 app data 下的学生和设备记录
- 不要覆盖 QClaw Agent 设置

## 测试清单

Windows：

- 启动不空白
- 首页可显示
- 系统设置可打开
- 创建学生成功
- QClaw 指令生成正确
- 主机服务可启动
- 设备列表可显示
- 上传记录可显示
- 档案可浏览
- 检查更新可用

平板：

- APK 可安装
- 首页可显示
- 可扫码绑定主机
- 可粘贴连接信息
- 可刷新学生
- 可上传资料
- 可查看学情档案
- 可联系教育管家
- 离线缓存表现符合预期
- 检查更新可用

联调：

- 平板上传文件进入正确学生原始资料库
- Windows 待消化数量变化
- QClaw 消化后档案可刷新
- 设备撤销后平板访问失败
- 重新绑定后恢复访问
