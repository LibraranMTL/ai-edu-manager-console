# 推荐比赛、分模块规划与云端摘要分享

实施版本：Windows 0.18.8 / 238 本地候选。对应三项补充任务，不代表完整采集／学习卡片开发计划验收。

## 问题与处理

原规划页面只按标签筛选 findings，其他学生依据、限制、行动和来源四页共用。现在采用独立生成合同，并将通用研究能力介绍留在规划总览，使各子页直接进入自己的决策内容。

| 页面 | 专属决策 | 验证行动 |
| --- | --- | --- |
| 升学路径 | 路线比较、阶段节点 | 条件、时间与备选路线核对 |
| 择校建议 | 院校梯度、准入资格与缺口 | 对应招生规则与材料核对 |
| 专业探索 | 核心学科、专业匹配推断 | 低成本试学与新证据积累 |
| 职业发展 | 岗位职责、能力差距 | 实践验证任务，不保证就业匹配 |

四套结果各有学生依据、事实、推断、缺失、条件、限制、备选、行动和来源 URL。原始历史版本保留；升级结构需手动更新。输入及来源不变不生成纯措辞新版本。

推荐比赛使用独立研究目的 competition_recommendation，不复用升学规划文本。依据由主机生成、去标识后交给已接通研究接口；每个候选必须引用真实打开记录中的官方来源。未知报名时间明确待核实，往届截止不当作当前开放报名。主机开启自动模式时按月及证据变化调度；禁用、未激活或执行器不可调用不启动后台研究。任务中心有受控调用、取消和回执，失败保留历史。

分享走「保存版本 → 主机生成摘要 → 人工预览确认 → 校验同一版本及学生绑定 → 签名上传 documents → 云端其他文档」。不自动创建云端学生、改变授权、公开发布或上传原始资料。接收端须有同学生的 cloud_document.read 许可。

## 主要实现位置

- electron/research-content.cjs：独立合同、重复结果／引用／资格日期校验、摘要导出。
- electron/planning-guidance.cjs：学生专属版本、检查回执、比赛更新与取消、月度及节点候选、分享摘要。
- electron/planning-research.cjs：研究目的分流与真实网页访问证据校验。
- electron/cloud-report-runtime.cjs：设备签名、学生绑定、重复及不确定上传结果校对。
- electron/main.cjs / preload.cjs：异步接口、受控任务调度与能力检查。
- src/PlanningResearchPanels.tsx：按需加载的新页面、独立规划展示、预览确认与比赛筛选；弹窗离开裁切祖先但保留应用主题。
- tests/planning-supplement.test.cjs / cloud-report-runtime.test.cjs：个性化／隔离、结构迁移、引用与时间、调度、并发、取消、重启、离线、摘要范围与签名集成。
