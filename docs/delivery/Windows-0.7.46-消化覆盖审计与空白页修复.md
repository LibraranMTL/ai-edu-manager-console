# Windows 0.7.46 消化覆盖审计与空白页修复

## 修复

- 修复 0.7.45 中点击“资料收集与处理”后页面空白的问题。
- 将页面时钟图标统一为已正确导入的组件，并增加防回归检查。

## 新增：消化覆盖审计

资料消化完成后，可以按文件核对 Agent 是否真正读取并沉淀内容：

1. 点击“生成覆盖审计”，建立当前批次逐文件清单。
2. 系统显示已覆盖、部分识别、失败、待回执、源文件缺失和缺少逐文件回执等状态。
3. 默认选择需要复核的资料，点击“复制二次核对指令”。
4. 将指令粘贴给 QClaw、OpenClaw、Codex CLI 或其他可访问知识库的 Agent。
5. Agent 对图片执行独立视觉识别与 OCR，并将逐文件结果写入 `digest-receipt.json`。
6. 点击“同步复核结果”，查看覆盖率、低置信度资料和补充生成的知识文件。

审计使用 `.edu-manager/digest-manifest.json`、`digest-receipt.json` 和 `digest-audit.json`，不会移动或删除原始资料。
