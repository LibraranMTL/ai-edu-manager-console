# 学情一期 1A 实施记录

日期：2026-11-02  
基线：Windows 0.22.8 源码基线上的 0.23.0 独立 worktree  
状态：源码实现与定向验证完成；尚未生成内部候选，未正式发布

## 已实现

- `learning-state.sqlite3` 从 v1 前向升级到 v2；升级前使用 SQLite 一致性快照生成 `pre-schema-v2` 可恢复备份，保留阶段 3 的知识点首次登记数据。
- 增加首次基线、本周反馈、目标、问题、证据、结论和追加式更正/撤回记录。
- 五项反馈分别保存目标清晰度、当前信心、主观难度、受挫后恢复和主观负荷；允许跳过，不合成总分。
- 写接口绑定单一学生可信范围，并使用稳定提交键或期望修订号；重复提交不增加数据代次。
- 证据显式区分学生自述、外部观察、系统观察和系统推断。直接事实与学生自述可发布；单一系统推断保持待观察；相互冲突的直接证据标记为存在冲突。
- Windows 成长模型增加“学习状态”管理页，可录入反馈、目标和问题，并更正或撤回目标/问题。
- 学生会话增加经认证的学习状态读取和五项反馈提交；教师端增加单学生只读状态入口，不开放写入。
- 一期自动行动固定关闭；本阶段不创建任务、学习卡或人工审批队列。

## 接口

- Windows IPC：`learningStateAction(action, studentId, input)`，主进程重新解析学生索引，不信任渲染层提供的路径或主体。
- 学生端：`GET/POST /api/student-session/learning-state`。
- 教师端：`GET /api/teacher/students/:studentId/learning-state`。
