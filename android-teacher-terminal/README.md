# AI教育管家教师端

这是与学生端并存安装的独立 Android 教师终端。

- 应用名称：AI教育管家教师端
- 包名：com.qxmatrix.eduteacher
- 当前源码候选版本：0.1.5（code 6）
- 当前协同功能候选 APK：AI-edu-manager-teacher-terminal-0.1.5.apk
- 候选 APK SHA-256：构建验收后记录

## 功能

- 以教师终端角色连接 Windows 主机，一次读取全部学生并按姓名、ID 或年级检索。
- 从文件、图片、相机、Downloads、系统分享或自动投递文件夹收集资料。
- 从智能体应用分享当前对话，或粘贴对话正文；选择学生后默认存入教育档案，关联项目可选。
- 上传到所选学生的原始资料库，或该学生关联项目的原始资料库。
- 查看所选学生教育档案、学情报告、成长模型、关联项目和项目知识。
- 保留按学生及项目隔离的本地档案缓存，断网时仍可查看已缓存内容。
- 保留连接设置、系统设置、连接备份与应用内更新。
- 不包含精选课程、学生空间登录和教育管家对话模块。

教师端使用独立紫红色图标、独立包名、独立偏好与缓存空间，以及独立更新清单字段 `teacherTerminal*`。

0.1.1 的对话导入只接收教师主动分享或粘贴的正文，不读取其他应用私有聊天记录、不抓取分享链接、不推断附件；失败时保留一份本地草稿供重试。

0.1.2 候选版新增已授权屏幕采集会话的自动投递。教师必须先明确选择学生、可选的关联项目与“自动投递”选项，再完成 Android 系统录屏授权；采集结束后，后台网络任务只投递该学生、该会话目录中的截图，断网时由系统调度重试。教师可从通知栏暂停、查看高亮或停止，主机仍会复核学生和项目范围。

0.1.3 源码候选接入主机项目资料统一存储协议：上传队列固定学生、项目与主机范围；授权教师可查看项目四视图并按主机能力进行分类、整理重试和证据确认；主机迁移期间保持只读。0.1.4 新增按所选学生查看规划、选题和比赛的只读入口，并先核验主机能力；可分页查看全部学生的练习进展。仍需最终真机、真实网络和覆盖安装验收，不能视为线上正式版。

0.1.5 本地测试候选增加耐久“导入对话”草稿、启动更新确认、学习状态谈话代填、项目综合报告和每周知识增长图。教师代填与学生自填使用完全相同的业务字段，主机仅在审计元数据中区分真实提交者；既有教师设备授权、学生目录检索和项目选择流程不变。

面向教师的安装和操作说明见 `docs/delivery/Android教师终端操作手册.md`；Windows 主机配套要求和交付证据见 `docs/delivery/Windows-0.15.10-教师终端支持升级验收.md`。
