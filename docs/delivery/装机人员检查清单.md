# AI教育管家装机人员检查清单

适用版本：

- Windows 主机控制台：0.4.5
- 平板终端：0.4.3

适用对象：装机人员、售后人员、内部测试人员

## 1. 文件准备

确认已准备以下文件：

- `AI-edu-manager-console-Windows-0.4.5.exe`
- `AI-edu-manager-tablet-terminal-0.4.3.apk`
- `edu-manager-version.json`
- QClaw 下载地址：`https://qclaw.qq.com/`
- 如需要远程连接，准备 Tailscale 安装和账号方案

## 2. Windows 主机基础检查

- Windows 可正常开机
- 当前用户有写入 `D:\` 权限
- 已创建或可创建目录：`D:\学生资料`
- 网络可用
- 防火墙允许主机服务端口，默认 `18777`
- 系统时间正确
- 磁盘剩余空间充足

## 3. 安装 Windows 主机控制台

- 启动 `AI-edu-manager-console-Windows-0.4.5.exe`
- 确认界面不空白
- 确认首页显示当前版本 `v0.4.5`
- 进入系统设置，确认默认根目录为 `D:\学生资料`

## 4. 安装 QClaw

- 检查本机是否已安装 QClaw
- 如未安装，打开 `https://qclaw.qq.com/`
- 安装并登录 QClaw
- 确认 QClaw 可正常创建或打开 Agent

如使用 Hohu、Marvis 或 OpenClaw，也应在首页或系统设置中确认对应工具的安装检测、打开按钮和打开状态正常。

## 5. 创建测试学生

建议创建测试学生：

```text
张三
```

检查是否生成：

```text
D:\学生资料\张三知识库
D:\学生资料\张三知识库\AGENT.md
D:\学生资料\张三知识库\张三原始资料库
D:\学生资料\张三知识库\张三学情分析汇总
D:\学生资料\张三知识库\输出结果
```

确认没有误写到：

- Downloads
- App 临时目录
- Marvis workspace
- 其他用户目录

## 6. 检查 Soul 工作规则

在初始化或新建教育智能体页面，复制 Soul 内容。

确认包含：

```md
## 工作规则

该 Agent 的工作协议使用：D:\学生资料\张三知识库\AGENT.md
后续所有学习资料消化都围绕该学生知识库执行。
```

不同学生必须显示不同学生的知识库路径。

## 7. 配置 QClaw Agent

- 创建 Agent：`张三 AI教育管家`
- 粘贴 Soul 角色内容
- 粘贴 Memory 长期记忆内容
- 让 QClaw 执行：
  - `D:\学生资料\张三知识库\AGENT.md`
- 确认 QClaw 后续读写目录和控制台目录一致

如接管已有知识库，应额外检查：

- 学生列表显示“接管知识库”
- 知识库根目录、原始资料库、学情分析汇总、AGENT.md 均指向已有真实路径
- 接管完成后复制的 Soul 工作规则使用已有知识库的 `AGENT.md` 路径
- 上传资料进入接管目录下的原始资料库
- 查看教育档案读取接管目录下的学情分析汇总

## 8. 启动主机服务

- 首页选择“主机-平板模式”
- 点击“启动主机服务”
- 确认显示局域网地址
- 确认显示二维码和配对码
- 如使用 Tailscale，确认显示 Tailscale 地址

## 9. 安装平板终端

- 安装 `AI-edu-manager-tablet-terminal-0.4.3.apk`
- 打开后确认名称为“AI教育管家平板终端”
- 确认不出现初始化、Agent、QClaw、Obsidian 等管理员功能

## 10. 平板绑定主机

- 在 Windows 主机端显示二维码
- 平板点击“扫码绑定主机”
- 扫码成功后确认读取学生列表
- 如果扫码失败，测试“粘贴连接信息”
- Windows 设备列表应出现该平板

## 11. 设备授权检查

在 Windows 主机端检查设备列表：

- 设备显示在线
- 显示最近访问 IP
- 显示客户端信息
- 授权学生范围正确
- 勾选或取消某学生后，平板学生列表变化符合预期
- 撤销设备后，平板请求应失败并提示重新绑定

## 12. 上传资料测试

至少测试：

- 拍照上传
- 选择图片上传
- 选择文档上传
- Downloads 最近文件上传
- 从文件管理器分享上传

确认文件进入：

```text
D:\学生资料\张三知识库\张三原始资料库
```

Windows 上传记录中应显示：

- 学生
- 设备
- 文件名
- 时间
- 状态

## 13. 消化闭环测试

- Windows 待消化数量增加
- 复制 QClaw 消化指令
- 在 QClaw Agent 中执行
- QClaw 更新学情分析汇总
- Windows 同步消化结果
- 平板刷新后能看到新档案

## 14. 档案浏览测试

Windows 和平板均检查：

- 资料摘要
- 综合汇总
- 问答精华
- 其他
- 全部文件

确认技术文件不暴露给家长端：

- `AGENT.md`
- `log.md`
- 配置类文件

## 15. 更新检查测试

Windows：

- 当前版本 `0.4.5` 应显示已是最新版
- 旧版应提示升级到 `0.4.5`

平板：

- 当前版本 `0.4.3` 应显示已是最新版
- 旧版应提示升级到 `0.4.3`

确认清单地址：

```text
https://www.greatbg.com/download/edu-manager-version.json
```

## 16. 交付前清理

- 删除测试学生，或明确标注测试学生
- 清理测试上传文件
- 确认正式学生资料路径
- 确认 QClaw 登录状态
- 确认 Windows 主机服务是否需要开机后手动启动
- 将主机服务连接说明交给客户或售后

## 17. 必须交付给客户的信息

- Windows 主机控制台安装目录
- 学生资料根目录
- 平板终端安装包
- 平板绑定方式
- 售后联系方式
- 常见问题说明

## 18. 装机验收签字项

- Windows 主机控制台可启动
- QClaw 可启动
- 学生知识库路径正确
- 平板可绑定主机
- 平板可上传资料
- Windows 可看到上传记录
- 平板可查看学情档案
- 设备授权可管理
- 更新检查可用
