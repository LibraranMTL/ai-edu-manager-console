# Windows 0.8.7 学习项目完成闭环

**Windows 主机版本：0.8.7**  
**Android 平板版本：0.5.8（未变更）**

## 本版交付

- Agent 初筛结果可直接粘贴，应用前预览匹配与状态变化，并保存完整原始回执。
- 知识审核默认只显示风险内容；高置信且有来源的记录可以批量确认，仍须通过归档任务才能发布。
- 单学生项目自动生成个人成长证据草稿；多学生项目只核对个人差异。没有来源的证据无法确认或发布。
- 完成项目只运行一次统一闸门检查，阻塞项可定位到暂存、消化、知识审核、个人证据或归档区域。
- 高风险归档和成长模型发布继续由任务中心审批；最终审核通过后自动返回原学习项目并刷新状态。
