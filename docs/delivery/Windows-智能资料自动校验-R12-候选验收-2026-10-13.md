# Windows 智能资料自动校验 R12 候选验收

日期：2026-10-13。版本：Windows 0.21.1 开发候选。候选标签：`smart-material-auto-qualification-r12-20261013`。

## 结论

已取消资料收件箱和任务中心中需要用户主动点击的“Agent 受控检测／检测当前学生 Agent 授权”步骤。用户开始或重试分类、项目资料消化、学生资料整理任务时，宿主先自动使用不含学生资料的合成请求完成安全校验；校验通过后才读取并发送本任务已授权范围内的资料。

本次取消的是单独的用户操作，不是安全校验：

- 仍校验所选 Provider、任务档、CLI 文件 SHA-256、资格有效期和熔断状态。
- 合成校验不带学生正文、画像、项目原件或真实目录；失败时不进入真实资料调用。
- 网络／资源冷却仍然阻止盲目重派；结果未知、敏感资料、跨学生冲突和业务歧义仍保留人工安全处理。
- 页面读取、列表刷新和普通状态查看不会触发 Agent 调用；仅在用户明确开始、重试任务或已到期后台任务实际执行时检查。
- 保留旧检测 IPC 作为旧页面兼容入口，但当前界面不再展示检测按钮，也不再把它作为任务前置步骤。

## 用户操作变化

正常情况下无需进行任何 Agent 检测。若官方 Agent 确实退出登录，界面只提示在对应官方 Agent 中登录；登录后重新开始原任务即可，系统会自动复检。不需要复制 Token、修改安全设置或重新配置学生。

旧失败记录不会因为通道恢复而自动重派。用户勾选原记录并点击“重新分析”后，系统先自动校验，再继续该记录，避免恢复登录后重复发送历史任务。

## 仍需用户参与的验收

本次“去掉检测环节”本身不需要用户额外操作。正式发布前仍建议在目标电脑做一次界面确认：

1. 打开资料收件箱和任务中心，确认不再出现“检测当前学生 Agent 授权”“检测 WorkBuddy/Codex 后台授权”按钮。
2. 对一份保留的失败资料点击“重新分析”，确认系统直接进入自动校验／分析，不要求先去设置页检测。
3. 若 Agent 已退出登录，只在官方 Agent 中登录，然后重新点击原任务；确认无需额外检测。
4. 抽查真实资料的学生、项目和分类结果。敏感、冲突或证据不足资料应继续进入人工确认。
