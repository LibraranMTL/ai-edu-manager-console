AI教育管家 Android 教师端操作手册

适用版本：Android 教师端 0.1.0

配套主机：Windows 主机端 0.16.1 或更高版本

1. 产品定位

Android 教师端用于教师集中收集资料、选择学生及其关联项目并上传到 Windows 主机资料库，同时随时查看学生的学情报告、成长模型、教育档案和项目知识。

这里的“上传”是把资料写入 Windows 主机中选定学生的原始资料库，或该学生关联项目的原始资料库；不是把文件发送到学生设备，也不产生学生通知或已读任务。

教师端与 Android 学生端可以同时安装：应用名称、包名、偏好、缓存和更新通道相互独立，教师端使用紫红色图标。教师端不包含精选课程、学生空间登录或教育管家对话模块；基础设置、连接设置和系统设置继续保留。

2. 安装与首次连接

  1. 在 Android 设备安装 AI-edu-manager-teacher-terminal-0.1.0.apk。
  2. 确认应用名称为“AI教育管家教师端”，图标为紫红色，不要误装学生端 APK。
  3. Windows 主机升级到 0.16.1 或更高版本，在“系统设置 → 基础设置 → 使用模式”选择“主机-终端模式”，并在“主机连接”中启动终端协作服务。
  4. 教师端选择局域网或 Tailscale 连接；可扫描附近主机、按固定主机码筛选，也可使用扫码、粘贴连接信息或连接备份。
  5. 在主机核对设备名称和终端码并接受连接。教师端会声明教师终端角色，不需要选择个人/共享学生终端，也不需要绑定一名学生。
  6. 连接成功后刷新学生列表，确认能够看到主机中的全部学生。

旧学生端设备授权不会自动转成教师终端角色。如果教师端只能看到一名学生或要求学生登录，请在主机撤销旧设备记录，再从教师端重新申请配对。

3. 查找和选择学生

首页以全部学生列表替代学生空间。可以按以下内容检索：

  • 学生姓名；
  • 学生 ID；
  • 年级。

点击学生后，页面加载该学生的资料状态与关联项目。切换学生时，上传目标、项目列表和查看内容会随之切换；较早发出的异步请求不会覆盖当前学生的页面。

4. 选择资料归属

上传前必须先选择一名学生，再选择以下目标之一：

  • 学生原始资料库：适合日常作业、教师反馈、学习记录和不属于特定项目的资料；
  • 关联项目原始资料库：适合项目研究、作品、过程记录和项目参考资料。

项目列表只显示当前学生关联且可接收资料的项目。切换学生后应重新确认目标，避免沿用上一名学生的资料归属。

5. 收集并上传资料

教师端支持以下入口：

  • 拍照；
  • 选择图片；
  • 选择普通文件；
  • 扫描 Downloads；
  • 从浏览器、相册、PDF 阅读器或文件管理器分享至教师端；
  • 自动投递文件夹。

操作步骤：

  1. 选择学生。
  2. 选择学生原始资料库或关联项目原始资料库。
  3. 选择文件、图片或拍照，也可以接收其他应用分享的资料。
  4. 核对学生和项目名称后确认上传。
  5. 等待“上传完成”反馈；失败文件保留在本地，可重新上传。

上传不会删除或移动 Android 设备中的原文件。主机收到资料后会把对应资料库标记为待处理，后续知识消化、成长模型和报告更新仍由 Windows 主机端完成。

6. 自动投递文件夹

  1. 在资料收集区选择学生和资料目标。
  2. 点击“选择文件夹”，在 Android 系统文件选择器中授权目录。
  3. 启用自动投递；需要立即核对时点击“立即检查”。
  4. 新文件稳定后上传；同一文件版本和同一目标不会重复入库，失败文件稍后重试，本地文件不会删除。

更换学生或项目后，应重新确认自动投递目标。停止使用某个收集目录时可关闭自动投递，不需要删除已经缓存的学生档案。

7. 查看学生资料

选择学生后可以查看：

  • 学情报告：主机已经发布的整体画像、行动建议、历史变化和阶段总结；
  • 成长模型：能力画像、项目贡献与近期成长证据；
  • 教育档案：该学生可访问的 Markdown 档案；
  • 关联项目：项目状态及项目中的公开 Markdown 知识。

这些内容为只读查看，不在教师端触发重新分析、审核或报告发布。项目知识必须属于当前学生的关联项目。

8. 档案缓存

教师端保留按学生及项目隔离的本地档案缓存。成功打开过的报告、成长模型、教育档案和项目知识，在主机暂时不可连接时仍可从缓存查看。

缓存不会因为切换学生或断开主机而自动关闭。重新连接主机并刷新后，以主机返回的最新内容更新缓存；没有成功读取过的内容不能在离线状态凭空显示。

9. 基础、连接与系统设置

  • 基础设置：保留资料收集与常用操作设置；
  • 连接设置：保留局域网、Tailscale、扫码、粘贴连接信息、连接备份及重连；
  • 系统设置：保留应用信息、更新检查和诊断能力。

教师端使用独立的 teacherTerminal* 更新清单字段，不会误下载 Android 学生端 APK。

10. 常见问题

只能看到一名学生或要求学生登录

确认主机为 0.16.1 或更高版本。撤销旧学生端设备记录，从教师端重新申请配对，并确认主机设备记录显示教师终端角色。

找不到某名学生

清除检索文字并刷新学生列表；仍不存在时，到 Windows 主机确认学生档案是否已经创建并出现在学生索引中。

看不到某个项目

确认已经选择正确学生，并在 Windows 主机核对该项目是否与学生关联、是否仍允许接收资料。

上传后学生设备没有收到通知

这是预期行为。教师端上传目标是 Windows 主机资料库，不是学生设备通知或文件收件箱。

断网后无法查看某份档案

只有此前成功打开并缓存过的内容可以离线查看。重新连接主机，打开该内容并等待加载完成后再测试离线缓存。

更换设备或重装后如何恢复连接

可导入同一教师端导出的连接备份。若恢复后设备角色不正确，应撤销记录并重新配对；不要导入学生端连接备份替代教师端配对。
