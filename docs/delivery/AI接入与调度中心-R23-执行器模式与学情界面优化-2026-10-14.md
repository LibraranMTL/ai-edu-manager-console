### P1：执行方式由用户可控

- 每个执行器均可设置为“自动优先”“仅手工交接”或“停用”。

- 自定义工具可直接编辑接入类型、路径、参数、超时和合同，不再要求删除后重新添加。
- 自定义网页／普通 EXE 默认手工交接；通过合同验证的标准 JSON CLI 才可进入自动调度。

### P2：适配器扩展边界

- 新增版本化执行器适配清单 `edu-manager.executor-adapter.v1`，统一内置 Agent、LLM API 与自定义 CLI 的能力声明。
- 厂商私有适配与标准 CLI 分离，后续新增执行器可通过适配清单和合同验证接入，不再改多份硬编码名单。
- Marvis 当前保留手工交接；在具备稳定、可验证的 CLI/API 或本机 IPC 合同前，不允许仅凭用户开关进入自动执行。
