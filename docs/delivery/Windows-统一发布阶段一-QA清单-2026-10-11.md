# 统一发布阶段一 QA 清单

本清单用于候选包验收，不代表已完成真机验收。UI 数据为隔离的虚构学生，不调用真实模型。

| 验收对象 | 操作与状态 | 证据 |
|---|---|---|
| 卡片直接发布 | 机构草稿，默认当前学生；发布无需导出对话框 | UI 发布、学生甲可见、学生乙不可见；自动化事务测试 |
| 统一管理 | 课程/卡片筛选，发布范围切换，停止新使用 | UI 页面与状态；范围与版本测试 |
| 学生练习 | 预览、开始、提示、选填自评、提交、反馈、修改稿、历史 | UI 完整链路、规则评阅结果、历史版本测试 |
| 文件卡片 | 无正文图片保存、重新打开、发布、学生预览 | UI 预览；内容哈希和权限测试 |
| 阅读 | 离线公式、题目与答案分开、窄窗口不横溢 | 桌面与窄窗口截图、构建字体文件 |
| 恢复与权限 | 重复发布/重复提交、冲突编号、跨学生请求、失效资源 | 单元测试 |
| 课程版本 | 老学生固定旧版本，新学生拿新版，撤下保留历史 | 单元测试；外部网站自身内容不在快照范围 |
| 平台发布 | 后台包校验、同事务恢复、冲突阻断 | 工作进程集成测试 |
| 原系统 | 全测试集、主机/学生端构建、候选启动 | 日志与构建报告 |

探索场景：发布给空范围时应拒绝且保留草稿；停止新使用后刷新学生资源消失但原作答仍能查看；切换学生不残留上一位反馈；重复提交不重复计数。

首次视口：桌面 1440×1000、窄窗口 600×900；主操作和当前身份可见，页面允许纵向滚动，不允许正文或公式导致整页横向溢出。另行检查原生候选初始窗口。

边界：Android 端及云端商家目录、订单、支付、服务履约不在本阶段；跨机器真实配对、真实 Agent 评阅、打印机输出仍需人工真机检查。
