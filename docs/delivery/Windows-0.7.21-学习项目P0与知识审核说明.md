# Windows 0.7.21 学习项目 P0 与知识审核说明

## 本轮完成

- 新建学习项目可新建工作空间，或原地绑定已有项目文件夹。
- 新建工作空间支持目录预览、非法名称校验、恢复模板默认目录和保存个人目录方案。
- 项目详情提供“打开项目工作空间”“打开项目知识空间”和“扫描工作空间资料”。
- 工作空间扫描登记新增与修改文件，并标记已经移除的来源；扫描结果先进入研究暂存，不自动成为正式资产。
- 项目资料增加人工接受、拒绝和审核说明，支持完整副本、关键快照、仅来源记录三种保存策略。
- 只有人工接受的资料才能晋升为正式资产。
- 项目知识空间中的概念、实体、摘要、问答和综合文件增加 AI 生成、待审核、已确认、已发布、已驳回、已失效状态。
- 项目生命周期增加待审核状态、状态转换约束、封存快照和封存只读保护。

## 双空间边界

- 原地绑定已有项目文件夹时，教育管家不在原目录中创建 LLM Wiki 知识目录。
- 研究暂存、项目知识空间、审核索引和封存快照保存在教育管家管理的项目目录中。
- “仅来源记录”会登记原文件资产，并在项目原始资料库生成来源记录 Markdown，不复制原文件。

## 封存规则

封存后禁止修改工作空间模板、绑定学生、导入或晋升资料、更新审核状态、执行知识贡献和同步消化结果。恢复为“进行中”后可继续编辑。

封存时生成 JSON 快照，记录项目数据、工作空间文件、知识空间文件和未完成暂存事项。
