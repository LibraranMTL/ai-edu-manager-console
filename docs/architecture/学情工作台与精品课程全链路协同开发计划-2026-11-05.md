## 1. 实施目标

项目分成三个可独立放行的业务闭环：

```text
闭环 1：精品课程 MVP
云端发布 → Windows 主机 / Android 单机版同步
→ Windows 主机学生分配 → 双学生端安全学习
→ 撤回、回滚、迁移和对账

闭环 2：学习卡与 Android 学习闭环
公共模板 → 本机实例 → 作答、订正、复测 → 学情证据和行动

闭环 3：Android 学情、项目与私有资料闭环
资料整理消化 → 学情/项目结果 → 自动发布和对账
→ 用户授权上传 → 指定 Windows 主机下载
```

精品课程 MVP 在第一个发布门独立交付，后续学习卡、工作台和私有资料不得成为课程 MVP 的阻塞依赖。

## 2. 已确认基线

首次只读审计结论：

- 最新稳定源码：Windows `0.23.3`，Android 学生端 `0.6.26 / 96`，Android 单机版 `1.3.4 / 38`；Windows 0.23.3 已正式发布但安装包仍未做 Authenticode 签名；
- 当前方案工作树为旧基线 Windows `0.18.1`，只保存方案，不作为实施代码线；
- 本机运行目录有 3 门平台课程、1 门机构课程；两门为旧 `en`，两门语言为空；
- 本机有 2 条按学生分配规则、1 个课程包、1 条发布记录和 15 条课程审计；
- 机构课程资产存在 2 个孤儿候选，本次未删除；
- 云端私有文档候选底座存在，公共课程发布域尚未实现。

完整证据和限制见只读审计报告。第 2 周结束前需核对实际线上云端版本和其他计划迁移主机，随后更新估算。

## 7. 课程 MVP 合同与撤回时限

`WP-003` 以[最小发布合同](./精品课程MVP-最小发布合同与撤回时限-2026-11-05.md)为冻结基线。核心时限：

| 场景 | 时限 |
| --- | ---: |
| 普通撤回到在线客户端同步 | 下一次 15 分钟同步周期内 |
| 紧急撤回到云端签名撤回指针 | 95% ≤ 2 分钟，最大目标 5 分钟 |
| 云端生效到在线主机/单机版获取 | ≤ 2 分钟 |
| 主机获取到在线学生端刷新 | ≤ 60 秒 |
| 在线端到端停止新打开 | 95% ≤ 5 分钟，最大目标 8 分钟 |
| 高风险课程离线打开租约 | ≤ 15 分钟 |
| 普通课程离线打开租约 | 默认 ≤ 6 小时，且不超过清单过期时间 |
| 公共清单生命周期 | ≤ 24 小时 |

离线设备无法保证即时取得新撤回。租约到期后保留只读卡片，禁止新打开；重新联网时先刷新撤回增量。

## 10. 放行门

### GATE-0：实施准备

- 最新稳定代码线、云端实际版本和目标设备清单已记录；
- 公共/私有数据域、11 种语言和受众规则冻结；
- JSON Schema、OpenAPI、签名输入、撤回 SLO 和跨端夹具通过评审；
- 4 门现有课程及其他目标主机产生迁移预览。

### GATE-1：云端课程发布候选

- 草稿、预览、质量门、批准、签名、定时、灰度、撤回和回滚可运行；
- 管理角色和客户端权限隔离；
- 坏签名、失效资源、重复发布和结果未知可恢复。

### GATE-2：四端课程闭环

- Windows 主机和 Android 单机版获得一致课程修订；
- 本机课程设置在云端更新后保持；
- 两个学生端只获得当前学生投影；
- 打开前复核、last-good、tombstone 和缓存隔离通过。

### GATE-3：课程 MVP

- 旧课程 ID、语言、策略、资产和审计迁移可追溯；
- 普通/紧急撤回、离线租约、回滚和覆盖升级真机通过；
- 签名候选、灰度范围、指标、回滚点和制品哈希齐全。

### GATE-4：Android 学习与项目

- 资料触发后自动进入知识、学情、行动或项目流水线；
- 来源冲突、归属不明、敏感内容和质量失败进入需要处理；
- 报告、卡片、行动和成果都有来源、版本、发布和撤回；
- 一次答对或课程打开不直接标记掌握。
- 学情报告首屏的真人专家咨询转化卡在横竖屏清晰可见，点击只进入授权范围预览，不直接上传。
- Android 首页真人专家咨询转化卡位于首屏，和学情报告页共用授权草稿且不会重复上传。

### GATE-5：私有资料授权

- 未授权零上传；授权预览包含学生、类别、字段、用途和有效期；
- 只有指定 Windows 主机可下载；撤权停止后续访问；
- 公共内容与私有学生数据的 API、令牌、存储和索引隔离；
