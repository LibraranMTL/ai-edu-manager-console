# Windows 0.10.2 与 Android 0.6.3：P0-P3 学生终端闭环

本轮按 P0 → P1 → P2 → P3 顺序开发。每一阶段均先完成自动测试和人工评估，再进入下一阶段。

## P0：Windows 学生终端首页闭环

- 个人终端和共享终端均可手动上传普通文件。
- 上传目标可选当前学生原始资料库，或该学生绑定项目的原始资料库。
- 学情报告与学情档案通过当前学生会话读取，不暴露其他学生数据。
- 自动投递文件夹只在个人终端启用；共享终端保留说明，避免沿用上一位学生的投递目标。

阶段门禁：273 项自动测试全部通过；使用模拟学生会话完成浏览器流程与布局人工评估。

## P1：Android 采集资料隔离与清理

- 屏幕采集按学生分别保存，并在会话元数据中保留学生和项目归属。
- 增加“查看与清理采集资料”，只显示当前学生的采集内容。
- 仅允许清理已上传内容或删除已结束会话，不自动删除未上传资料。
- 旧版无法确认归属的采集内容不向当前学生展示。

阶段门禁：277 项自动测试全部通过；完成代码路径、存储边界和界面状态的人工审查，APK 编译与签名通过。

## P2：Android 个人终端自动投递

- 通过 Android 系统文件夹授权选择自动投递目录，并持久保留授权。
- 自动投递绑定一个学生和一个资料目标，支持学生原始资料库或绑定项目原始资料库。
- 新文件稳定后上传；采用幂等记录避免重复；失败可重试；不删除本地文件。
- 后台定期检查、应用恢复检查和手动检查并存。
- 共享终端自动关闭该能力，避免下一位学生继承上一位学生的文件夹和目标。

阶段门禁：281 项自动测试全部通过；完成权限、调度、幂等和模式切换的人工审查，APK 编译与签名通过。

## P3：学生进展与每日轻提醒

- Windows 与 Android 学生首页显示今日提交、近 7 日提交、30 日活跃天数、已消化资料数、较上期变化和最近提交时间。
- 主机按当前学生会话计算并返回版本化进展数据。
- 当日尚未提交时显示“提交本日学习资料”轻提醒，可一次进入上传或选择稍后再说；同一学生当天不重复打扰。
- 指标明确使用“已消化资料数”，不把处理记录夸大为独立知识文件数量。

阶段门禁：285 项自动测试全部通过；使用模拟学生数据完成双端文案、Windows 页面状态和提醒交互人工评估。

当前开发环境没有可用的 Android ADB 设备。本轮已经完成 Android 自动测试、静态人工审查、APK 构建和签名验证；正式分发前仍应在至少一台 Android 设备上检查屏幕采集授权、按学生查看与清理、后台自动投递时序以及上传按钮反馈。
