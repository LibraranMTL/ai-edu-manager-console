## 2. Windows 环境

- [ ] Windows 10/11 可正常运行程序
- [ ] 当前用户可写入学生资料根目录
- [ ] 磁盘空间充足，系统时间正确
- [ ] 防火墙允许主机服务端口，默认 `18777`
- [ ] 同时启动两次时只保留一个主实例
- [ ] 首页显示 `v0.16.8`
- [ ] “系统设置 → 基本设置 → 许可证授权”显示并可复制 `host-...` License v3 设备码，且明确区分 `HOST-...` 连接机器码
- [ ] 正确的设备绑定 License v3 可激活，旧式短码、License v2、跨设备码和跨产品码全部拒绝
- [ ] 升级前存在的本地可信公钥文件被隔离且不参与验签；未换码时已有档案只读、资料不删除

## 3. 学生档案初始化

- [ ] 填写测试学生并点击“保存学生档案并初始化”
- [ ] 一次生成知识库目录、`AGENT.md`、LLM Wiki 目录、索引、日志和基础学情报告
- [ ] 初始化失败时不产生无效学生记录
- [ ] Agent 步骤卡片可直接复制指令
- [ ] 右侧不再出现重复的目录创建与 `AGENT.md` 写入步骤

## 4. 接管与路径迁移

- [ ] 可选择已有知识库并识别真实目录
- [ ] 接管不移动、不复制、不删除原文件
- [ ] `.ai-manager/metadata.json` 和 `pathmap.json` 可生成或读取
- [ ] 路径健康检查可发现旧主机绝对路径
- [ ] “备份后修复旧路径”先生成备份再修改
- [ ] 学生详情只保留“手工选择原始资料库”和“手工选择学生知识库”两个独立入口，分别修改各自路径
- [ ] 更改真实目录路径后重新分析迁移内容，能够创建迁移包并在新电脑恢复学生档案、成长模型、学情报告和项目资料

## 5. 资料消化闭环

- [ ] 导入测试资料后“待提交消化”数量增加
- [ ] 可复制消化指令并选择任意 Agent 工具
- [ ] 点击“标记已提交”后资料进入“等待 Agent 回执”
- [ ] Agent 写回状态后“同步消化结果”更新计数和最近消化时间
- [ ] 没有回执时不会误标为已处理
- [ ] 资料收集与处理页面无空白
- [ ] 201 份以上待处理资料不会因旧 200 条上限少计；`materials.json` 为当前路径和数量权威来源
- [ ] 移动一份资料后，内容 SHA-1 相同且当前学生目录内只有一个候选时可自动修复，并生成修复前备份与历史
- [ ] 缺失/仍在写入/哈希不符/多候选资料被单独隔离，不阻断同批其他可读资料
- [ ] 单批最多 100 份且不超过 512 MB；剩余资料保留到后续批次，不丢记录
- [ ] “资料路径预检”显示本批、自动修复、后续批次和待确认数量；手工选择不能越过当前学生原始资料库或绕过哈希校验

## 6. 消化覆盖复核

- [ ] 可生成逐文件覆盖审计
- [ ] 可查看完整覆盖、部分识别、失败和源文件缺失

## 7. 屏幕资料采集

- [ ] 暂停、继续、重点截取、结束和快捷键有效
- [ ] 截图先进入候选采集箱
