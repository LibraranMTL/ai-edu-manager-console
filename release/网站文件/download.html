按使用者选择正确版本

教师或家长使用 Windows 主机端集中管理；学生根据设备选择 Windows 学生端或 Android 学生端。三个版本均无需额外技能包。

管理端 · Windows

Windows 主机端

v0.10.5

安装在教师或家长电脑，负责学生档案、资料治理、学习项目、成长模型、学情报告和个人/共享学生终端管理。

学生端 · Windows

Windows 学生端

v0.10.5

支持个人和共享终端；可选择局域网或 Tailscale 连接，学生进入本人空间后可上传文件、采集屏幕、查看报告与档案，并看到资料进展和每日轻提醒。

学生端 · Android

Android 学生端

v0.6.3

支持采集资料按学生隔离、当前学生安全清理、个人终端自动投递，以及本人资料进展、报告和档案查看。
