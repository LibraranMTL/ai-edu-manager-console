# Windows 0.7.29 学情报告与教育档案显示修复

## 修复内容

- 修复切换学生并进入学情报告时，报告读取结果被后续状态清理覆盖的问题。
- 进入“学情报告”后自动读取四份报告并打开当前报告正文。
- 进入“查看教育档案”后自动补齐基础报告模板并刷新 Markdown 文件树。
- 教育档案的“综合汇总”分类不再排除“学情报告”目录中的文件。
- 档案列表显示当前学生真实的学情分析汇总目录。

## 验证

- 学情报告页显示整体画像、历史变化、每日行动建议、阶段总结四张报告卡。
- 默认报告正文可读，复制正文按钮可用。
- 教育档案无需手动刷新即可显示四份学情报告，并能打开正文。

基础报告首次补建时为草稿模板；正式教育结论仍需由用户选择的 Agent 根据成长模型、综合汇总和已确认项目贡献生成或更新。
