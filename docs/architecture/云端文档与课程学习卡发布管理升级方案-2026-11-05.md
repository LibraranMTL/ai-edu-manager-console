## 1. 决策摘要

不新建孤立的课程服务器。把现有云端文档管理模块升级为“云端内容与文档管理中心”，在同一服务基础设施上提供两套严格隔离的业务域：

1. **学生私有文档域**：学生基础信息、学情报告、学习资料、选题建议、推荐比赛、个性化学习卡片及单独授权的健康资料；继续按学生、类别、设备和动作授权。
2. **公共内容发布域**：精品课程、课程资源文档、公共学习卡模板和卡片包；由平台管理员统一维护，按国家、地区、语言、年级、年龄、产品和发布通道下发。

两域可复用对象存储、文档版本、内容哈希、预览、搜索、审计、任务和运维能力，但不能共用宽权限、学生身份或发布接口。

```text
云端内容与文档管理中心
├─ 学生私有文档域
│  ├─ 学生资料上传与修订
│  ├─ Windows 主机下载许可
│  ├─ 远程 Agent 授权
│  └─ 私有学习卡片/作答（需单独授权）
└─ 公共内容发布域
   ├─ 资源文档库
   ├─ 精品课程
   ├─ 公共学习卡模板/卡片包
   ├─ 多语言和区域适用范围
   └─ 发布、灰度、撤回、回滚和客户端同步
```

平台课程和机构推荐课程均由平台管理员维护，首期不建设机构自行编辑的多租户后台。但国际化必须保留“受众维度”，因为不同国家、地区、语言和教育阶段看到的内容不同。受众维度不等于租户所有权。

## 2. 现有云端基础

本方案以现有《AI教育管家云端模块升级开发方案（2026-10-17，后续修订至 2026-10-24）》及其候选实现为基线，作为公共内容发布域的增量升级；不改写其中尚未完成的真实异地宿主、生产迁移和正式客户端发布状态，也不把本设计稿视为已经部署。

现有云端模块已经规划或候选实现以下基础：

- 学生基础信息和五类教育资料同步；
- 独立健康资料许可；
- 逻辑资料与不可变修订；
- 当前版本指针和历史版本；
- 来源设备上传、Windows 接收设备下载和远程 Agent 授权；
- 内容哈希、下载缓存、回执、撤回和审计；
- Markdown、PDF、DOCX 和扫描件处理方向；
- 云端成果收件箱与本机幂等接收方向。

本方案在此基础上增加公共内容模型、发布管理、受众匹配和 Windows/Android 统一同步协议。现有学生云端 API 和许可不得因公共内容上线而自动扩权。

```text
│  ├─ 上传、解析、预览和版本

├─ 学习卡片

│  ├─ 题目、答案策略和版本
│  └─ 多语言与受众

   └─ 备份恢复与对账
```

### 3.2 角色

首期角色都是平台内部角色，不是机构租户：

| 角色 | 权限 |
| --- | --- |
| `platform_admin` | 平台配置、角色、紧急撤回和全部审计 |
| `content_editor` | 编辑资源文档、课程和卡片草稿，不可直接生产发布 |
| `content_publisher` | 审核发布清单、定时发布、灰度、回滚 |
| `privacy_operator` | 管理学生私有文档许可，不可编辑公共课程 |
| `auditor` | 只读查看版本、许可、发布和调用日志 |

小团队可由同一平台管理员承担多个角色，但服务端仍记录具体动作和发布者，不把管理员登录态下放给客户端。

## 4. 两个数据域的隔离

| 项目 | 学生私有文档域 | 公共内容发布域 |
| --- | --- | --- |
| 主要对象 | 学生档案、报告、资料、个性化卡片 | 课程、资源文档、公共卡片模板 |
| 是否含学生身份 | 是 | 否 |
| 授权模型 | 学生 + 类别 + 字段 + 设备 + 动作 + 有效期 | 客户端产品 + 受众 + 发布通道 |
| 默认可见性 | 拒绝，需明确授权 | 对匹配受众的已发布客户端可读 |
| 写入者 | 获准来源设备、平台受控流程 | 平台内容编辑/发布角色 |
| API 前缀 | `/v2/private/...` | `/v2/public-content/...` |
| 存储前缀 | `private/{cloudStudentId}/...` | `public/{contentId}/{revisionId}/...` |
| 搜索索引 | 按学生和许可过滤 | 只索引已发布或后台草稿索引 |
| 客户端缓存 | 按学生隔离、可撤权 | 按受众和清单修订隔离 |

公共课程不能引用学生私有资料；公共卡片模板不能包含真实学生姓名、作答或报告摘要。私有学习卡片即使由公共模板实例化，也继续属于学生私有域。

## 5. 公共资源文档

课程和卡片引用的讲义、说明、图片、PDF、视频链接和版权材料统一进入公共资源文档库，复用现有文档版本、哈希、预览和索引能力。

`ContentAsset` 最小字段：

```text
assetId, revisionId, kind, title, locale,
sourceType, sourceUrl, provider, copyrightNotice,
licenseType, fileObjectKey, sha256, mimeType, bytes,
status, createdBy, createdAt, supersedesRevisionId
```

规则：

- 原始文件不可变，修改生成新修订。
- 外部链接必须记录提供方、允许域名、最后检查时间和可用状态。
- 版权、年龄适宜性和敏感内容校验不通过时不得进入公共发布清单。
- 删除被课程或卡片引用的资源前，必须显示引用关系并阻止直接物理删除。
- 资源撤回使用墓碑和替代修订，不让历史发布清单指向不存在的对象。

## 6. 精品课程模型

### 6.1 核心对象

```text
Course
  courseId, sourceCategory, provider, status,
  subjectTags[], gradeBands[], ageRange,
  allowedHosts[], defaultEnabled,
  createdAt, updatedAt, legacyOrigin

CourseLocalization
  courseId, locale, title, summary,
  legalNotice, coverAssetRevisionId,
  launchUrl, resourceRefs[], revision

CourseAudience
  courseId, countries[], regions[], locales[],
  gradeBands[], ageRange, productIds[],
  minClientVersion, maxClientVersion, channels[]

CourseRelease
  releaseId, courseId, courseRevision,
  audienceRevision, state, effectiveAt,
  expiresAt, publishedBy, rollbackOf
```

`sourceCategory` 可区分平台课程、机构推荐、公共公益资源等，但所有内容都由平台管理员维护。首期没有机构作者账号和租户隔离。

### 6.2 多语言和区域

同一 `courseId` 使用多条 `CourseLocalization`，不为每种语言复制课程身份。受众匹配建议顺序：

1. 国家 + 地区 + 完整 locale；
2. 国家 + 语言；
3. 区域 + 语言；
4. 全球 + 语言；
5. 全球默认语言。

没有合适翻译时，平台可配置是否回退到其他语言；客户端不得自行假定英语一定可用。国家、地区和语言由用户确认，IP 仅用于首次建议。

### 6.3 课程质量门

- 必需字段、多语言完整度和封面存在；
- URL 协议和允许域名；
- 链接可用性和重定向安全；
- 版权、提供方和法律说明；
- 年龄、年级和地区适用范围；
- 重复课程和稳定 ID 冲突；
- 最低客户端版本与资源能力；
- 预览环境实际打开和关键路径检查。

机器校验通过不自动等于生产发布。新课程、版权变化、受众扩大和答案策略变化必须由 `content_publisher` 发布；已审核发布单可定时自动生效。

## 7. 公共学习卡模板

### 7.1 对象区分

```text
LearningCardTemplate       公共、无学生数据、平台发布
LearningCardPack           一组模板，可关联课程/主题/年级
LearningCardInstance       客户端本机个性化实例
StudentLearningCard        用户授权后上传的私有学生资料
```

公共发布中心只管理前两类。后两类由客户端和学生私有文档域管理。

### 7.2 模板合同

```text
templateId, revisionId, templateType,
subject, knowledgePointIds[], difficulty,
gradeBands[], ageRange, locale,
prompt, answerPolicy, rubric,
explanation, hintPolicy, sourceRefs[],
courseIds[], tags[], status, generatorVersion
```

首期题型建议：单选、多选、判断、简答、自检步骤、费曼复述提示和任务型卡片。自动评分只对有确定答案或明确 rubric 的题型开放。

### 7.3 发布规则

- 题干、答案和解释不能互相泄露。
- 每张卡只解决一个目标，来源可追溯。
- 答案或评分规则必须可验证。
- 年龄、年级、地区和语言适配。
- 与同一卡片包中的有效模板进行语义去重。
- AI 可辅助生成草稿，但不能绕过确定性校验和发布权限。
- 模板更新生成新修订；已经开始作答的客户端实例固定原修订。
- 模板撤回停止新实例化，不删除学生已经完成的作答记录。

### 7.4 与课程和本地个性化的关系

课程可关联一个或多个卡片包。客户端同步模板后，可根据本地学生年级、学习计划和证据实例化卡片。公共模板只提供通用内容，不携带“该学生薄弱”等个性化结论。

客户端依据本地证据生成的个性化卡片默认只留本机。如用户明确授权 `learning_card` 私有类别，可上传私有云端文档域；它不得反向进入公共模板库。

## 8. 发布清单与同步协议

### 8.1 清单

```text
PublicContentManifest
  contractId, schemaVersion, manifestId, manifestRevision, releaseId,
  audienceKey, audienceRevision, selectionReason,
  issuedAt, effectiveAt, expiresAt, previousRevision,
  minClientVersions, courses[], cardPacks[], assets[], tombstones[],
  keyId, signatureAlgorithm, signature
```

清单不可变。一次发布先生成候选清单和资产索引，完成校验后切换受众通道的 active 指针。回滚是把 active 指针切换到已验证的历史清单或生成明确的回滚发布，不原地修改历史。

### 8.2 API

| 接口 | 用途 |
| --- | --- |
| `GET /v2/public-content/manifest` | 按客户端上下文返回当前适用清单，支持 ETag |
| `GET /v2/public-content/assets/{revisionId}` | 下载短期授权资源，支持 Range |
| `GET /v2/public-content/revocations` | 返回独立签名的紧急撤回增量，支持短缓存和 ETag |
| `GET /v2/public-content/releases/{revision}` | 读取精确发布元数据和撤回状态 |
| `POST /v2/public-content/sync-receipts` | 接收不含学生资料的同步结果、修订和失败代码，幂等分类为已对账、自动刷新、自动重试或需要处理 |
| `POST /v2/admin/content/assets` | 上传公共资源草稿 |
| `POST /v2/admin/courses` | 新建或修订课程草稿 |
| `POST /v2/admin/card-templates` | 新建或修订卡片模板草稿 |
| `POST /v2/admin/releases/validate` | 生成候选清单和质量报告 |
| `POST /v2/admin/releases/publish` | 发布、定时或灰度 |
| `POST /v2/admin/releases/rollback` | 回滚到已验证清单 |
| `POST /v2/admin/releases/emergency-withdraw` | 紧急撤回指定内容 |
| `GET /v2/admin/public-content/operations` | 汇总交付指标、同步回执、智能处置和异常告警 |

管理接口与客户端读取接口使用不同认证、限流和审计策略。客户端没有编辑或发布权限。

### 8.3 签名和资源完整性

- HTTPS 保护传输；清单使用独立内容签名密钥。
- 客户端内置受信公钥集合，支持 `keyId` 轮换和双签过渡。
- 资产按 SHA-256 校验，路径使用内容或修订标识，不信任服务端文件名。
- 签名失败、清单过期或资源哈希错误时继续使用 last-good，并发送不含学生数据的诊断回执。
- 私钥只在受控发布服务或密钥服务中使用，不进入 Windows/Android 安装包和普通管理页面。

### 8.4 撤回时限

课程 MVP 执行统一合同：普通撤回在在线客户端下一次 15 分钟同步周期内传播；紧急撤回从授权操作到云端签名撤回指针生效，95% 不超过 2 分钟、最大目标 5 分钟；云端生效后在线 Windows 主机/Android 单机版在 2 分钟内取得撤回，学生端在主机取得后 60 秒内刷新。在线端到端停止新打开 95% 不超过 5 分钟、最大目标 8 分钟。Windows 主机和 Android 单机版每 2 分钟同步轻量撤回增量，并在应用回到前台和课程打开前复核。

离线设备以签名清单和课程打开租约为边界。高风险课程离线租约不超过 15 分钟，普通课程默认不超过 6 小时，且都不得超过清单过期时间。离线设备重新联网时先刷新撤回增量。

## 9. 发布流程和自动化

### 9.1 工作流

```text
资源/课程/卡片草稿
→ 自动解析、链接检查、版权字段检查、内容和受众校验
→ 生成预览和差异报告
→ 发布者确认发布单
→ 生成不可变清单并签名
→ 可选定时或灰度生效
→ 客户端同步回执和健康监控
→ 自动扩大灰度 / 自动暂停 / 人工回滚或紧急撤回
```

### 9.2 触发矩阵

| 事件 | 自动动作 | 自动结果 | 进入“需要处理”条件 |
| --- | --- | --- | --- |
| 上传公共资源 | 病毒/类型/哈希/解析/预览 | 资源草稿和索引 | 不支持格式、恶意内容、版权字段缺失 |
| 新建课程 | 字段、URL、域名、重复和受众校验 | 课程草稿质量报告 | 链接持续失败、受众冲突、版权不清 |
| 新建卡片模板 | Schema、答案、引用、难度和重复校验 | 卡片草稿质量报告 | 无可靠答案、题面泄露、来源不足 |
| 翻译更新 | 占位符、链接、术语和完整度校验 | 新本地化修订 | 必需字段缺失或关键含义冲突 |
| 发布单提交 | 解析依赖图、生成清单、兼容性检查 | 可发布候选 | 存在阻塞质量门或失效依赖 |
| 到达定时时间 | 重新校验权限和依赖 | 原子切 active | 发布单撤销、依赖变化或签名失败 |
| 灰度健康良好 | 按策略扩大受众比例 | 自动推进灰度 | 错误率、回滚率或打开失败超阈值 |
| 灰度健康异常 | 自动暂停扩量，保持现有受众 | 告警和诊断包 | 需发布者决定回滚或修复 |
| 内容紧急撤回 | 生成 tombstone 清单并签名 | 客户端停止新打开/实例化 | 撤回签名或清单生成失败 |
| 客户端回执缺失 | 按设备群和通道对账 | 识别版本碎片 | 大范围长期未同步 |

### 9.3 自动发布政策

| 变更 | 默认政策 |
| --- | --- |
| 新课程/新卡片包 | 机器校验 + 发布者确认 |
| 版权、适用国家/地区、答案策略变化 | 必须发布者确认 |
| 已批准发布单到达定时时间 | 自动发布 |
| 非语义图片压缩、链接健康时间更新 | 可按规则自动发布补丁 |
| 灰度扩量 | 在错误阈值内自动推进 |
| 灰度异常 | 自动暂停，不自动扩大 |
| 紧急安全撤回 | 授权管理员可立即执行，完整审计 |

公共内容发布不能采用“AI 生成即自动上线”。最大程度自动化应体现在校验、预览、依赖分析、定时、灰度、监控和对账，而不是取消公共内容的发布责任。

## 10. 国际化和受众治理

首期受众字段：

```text
country, region, locale, language,
gradeBand, ageRange, productId,
minClientVersion, maxClientVersion, releaseChannel
```

原则：

- 内容所有权统一属于平台，不建立国家或机构租户。
- 不同国家/地区/语言可以看到不同清单。
- 同一课程优先用本地化修订，不复制稳定课程身份。
- 受众规则在服务端计算，清单记录最终匹配原因，便于客户端解释。
- 客户端用户设置优先于 IP；IP 变化不能静默切换课程。
- 未来确有合作方专属内容时，可增加 `audienceGroup`，但必须单独评审，不能复用学生设备许可冒充机构租户。

## 11. 私有文档模块升级

在保持现有方向的基础上同步完成：

1. 学生基础信息、报告、学习资料、选题、比赛和私有学习卡片继续使用逻辑资料/不可变修订。
2. Android 用户明确授权后上传；平台可为指定 Windows 主机签发下载许可。
3. 接收 Windows 主机刷新授权后发现学生和资料，按现有规则幂等建档和按需下载。
4. 不建设专家咨询单、专家状态或结果回传 API。
5. 授权页说明“平台将派遣专家一对一解读咨询”不产生自动咨询业务状态。
6. 学生私有卡片与公共模板用不同 `category`、对象 ID 前缀和权限检查。
7. 私有搜索、下载、附件、历史和索引均继续按学生/类别/设备许可过滤。

## 12. 失败、对账与可观测性

### 12.1 任务状态

所有后台任务记录：

```text
businessKey, taskType, inputRevision,
attempt, leaseOwner, leaseExpiresAt,
nextRetryAt, lastError, artifactId,
receiptId, state, createdAt, updatedAt
```

### 12.2 对账任务

统一对账 Worker 检查：

1. 卡住的解析、索引、清单生成和签名任务；
2. 已上传对象但数据库回执缺失的孤儿资源；
3. 发布记录成功但 active 指针未切换的半提交；
4. active 清单引用不存在、撤回或哈希不一致的资源；
5. 到期未执行的定时发布；
6. 灰度比例与实际客户端回执不一致；
7. 私有授权已撤销但仍存在可读缓存或待上传任务；
8. 公共模板撤回后仍在新实例化的客户端版本；
9. 签名密钥即将到期但客户端公钥覆盖不足；
10. 备份对象、数据库修订和搜索索引不一致。

修复使用原业务键和修订，不创建无来源的替代版本。单个课程、卡片或学生任务失败不得阻塞其他对象。

### 12.3 指标

- 清单请求成功率、304 命中率和响应延迟；
- 各客户端版本的同步成功率与 last-good 年龄；
- 资产下载失败、哈希失败和签名失败；
- 课程打开失败和允许域名拦截；
- 卡片模板实例化失败；
- 灰度通道错误率、自动暂停次数和回滚时间；
- 私有文档上传、下载、撤权和未知回执；
- 每类内容存储、带宽、索引和保留成本。

日志禁止记录学生正文、卡片答案、访问令牌和签名私钥。

## 13. 兼容与迁移

### 13.1 课程迁移

- 导入现有 `platform_standard`，保留稳定 `courseId` 和旧包版本来源。
- 收集 `tenant_custom` 课程，执行链接、重复、版权和封面校验后进入平台草稿区。
- 本地课程分配策略通过 `legacyCourseId → courseId` 映射保留。
- 旧 `.edu-coursepkg` 在过渡期作为只读迁移源和灾备产物，不再作为日常发布渠道。
- Windows/Android 至少有一个可用云端清单并通过灰度后，才移除普通客户端导入入口。

### 13.2 私有文档兼容

- 保持既有 `/v1` 客户端读取和游标语义，新增公共内容走独立 `/v2/public-content`。
- 私有文档新合同仍使用 `/v2/private` 或兼容映射，不把公共清单混入旧“其他文档”。
- 旧 `learning_card` 明确迁移为私有学生类别；公共模板使用全新的稳定 ID 命名空间。
- 回滚公共发布功能不能覆盖或回滚学生私有文档数据库。

## 14. 安全与合规

- 公共内容发布者和私有资料管理员执行最小权限分离。
- 管理端启用强认证、短时会话、敏感操作再确认和不可篡改审计。
- 公共资源记录来源、版权、许可、地区限制和撤回依据。
- 学生私有资料继续遵循明确授权、范围最小化、有效期、撤销和删除回执。
- 内容签名私钥进入 KMS/HSM 或受控密钥服务；备份加密并演练恢复。
- 短期资源下载 URL 不能被描述为不可转让；服务端仍应校验受众和有效期。
- 不用公共客户端回执携带学生 ID、作答或学情内容。

## 17. 验收矩阵

### 17.1 公共内容

1. 平台管理员可上传资源、编辑课程和卡片草稿，编辑者不能越权生产发布。
2. 同一课程有中文、英文等本地化修订，稳定 `courseId` 不变。
3. 中国中文、加拿大英文及其他回退组合得到预期清单和匹配原因。
4. 清单签名、资产哈希、路径和允许域名任一失败时客户端保持 last-good。
5. 定时发布重启后只执行一次；结果未知可按 releaseId 对账。
6. 灰度健康异常自动暂停，不继续扩大。
7. 回滚恢复上一已验证清单，不删除历史发布和审计。
8. 紧急撤回在合同规定的在线时限内阻止新课程打开或新卡片实例化；离线端按打开租约到期阻止，不删除学生既有记录。
9. 模板升级不改变已开始的卡片实例。
10. Windows 和 Android 对相同受众返回一致课程/模板 ID 和修订。

### 17.2 私有文档

1. Android 未授权时不上传学生基础信息和资料。
2. 用户授权类别以外的内容不进入上传包、索引和日志。
3. 平台只允许指定 Windows 主机在获准范围下载。
4. 接收主机没有本地档案时按稳定 cloudStudentId 幂等建档；同名冲突不自动合并。
5. 私有学习卡片和作答不出现在公共模板搜索或发布清单。
6. 撤权停止后续访问；已经正式导入本机的资料不被云端静默删除。
7. 页面不显示不存在的专家分配、咨询状态或结果回传。

### 17.3 恢复和安全

1. 数据库提交前后崩溃、对象上传后回执丢失、索引失败均可对账恢复。
2. 发布密钥轮换期间新旧客户端均可验证，过渡结束后旧密钥可撤销。
3. 备份恢复后 active 指针、对象哈希、撤回状态和审计一致。
4. 客户端令牌不能调用管理发布接口，私有设备许可不能读取公共草稿。
5. 生产日志和指标不出现学生正文、卡片答案、访问令牌或私钥。

## 18. 实施前冻结项

1. 云端管理端的实际源码入口、数据库和对象存储部署拓扑。
2. 公共内容签名算法、KMS、密钥轮换和客户端公钥更新策略。
3. 国家/地区/语言枚举、教育阶段映射和回退规则。
4. 首批课程和卡片模板的版权、地区限制及内容负责人。
5. 灰度通道、自动暂停阈值、回滚权限和紧急撤回响应时间。
6. 旧平台课程包、机构课程和本地策略的迁移批次。
7. 学生私有资料的保留期、存储地域、监护授权及删除回执。
8. Windows 和 Android 支持公共清单的最低版本与强制升级策略。

本方案的关键原则是：复用云端文档底座，但不混淆私有学生资料与公共教学内容；统一平台维护，但不取消地区和语言受众；最大程度自动化质量校验、发布编排和故障恢复，但公共内容正式发布仍保留明确责任人。
