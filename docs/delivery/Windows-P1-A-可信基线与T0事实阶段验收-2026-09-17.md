## 3. T0 契约与修复

- 既有截图事件继续以 `edu-manager.learner-event.v1` 兼容读取，新增 `edu-manager.temporal-event.v1` 标识及设备 ID、主机接收来源、原始设备时间、时间精度/状态和主机分日时区；协议角色与有证据的实际行为人仍分开。
- 远端上传原来在设备 `capturedAt` 缺失或无效时用主机当前时间填充，容易制造虚假采集时刻。现改为保留原始上报值和缺失/无效/缺时区状态，以主机上传接收时间作为**明确标出的替代时刻**；不把设备无时区时间按主机时区悄悄解释。
- 设备 ID 只取配对请求的认证上下文，不取 URL 自称；同一采集会话若已绑定另一设备则拒绝混入。旧事件 ID、旧 JSONL 和已有报告只读兼容，不回填“已确认时间/行为人”。
- T0 的可信跨设备时钟校准、跨来源去重、结构化任务/概念映射和可续关联索引属于阶段 B 收尾，尚未实现；不因本阶段字段落地就宣称整个 T0 已完成。
