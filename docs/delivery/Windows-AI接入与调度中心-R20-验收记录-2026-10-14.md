日期：2026-10-14。版本：`0.21.1-ai-control-r20-agent-settings-20261014`。基于当前 R19 工作区继续实现；保留工作区其他已有修改，未提交 Git、未上传发布、未替换正在运行的旧程序。

## 实现范围

一个 AI 接入与调度中心管理全局授权、全部执行器／连接、全局顺序和最近异常。Agent设置管理收口为 3 个顶层入口：中心、Agent 数据管理、Agent连接管理；数据管理下分记忆／规则／人设，连接管理下分外部写入审核／Agent问答设置。LLM API 设置直接可见，无学生也能操作。

“收集与整理”将原对话收集与会话自动采集合并为“AI对话采集”，其下仅保留“对话分享资料箱”和“Agent会话自动采集”两个分页面。旧快捷入口仍映射到对应分页面，不产生第二套资料或采集状态。

全局 v2 授权原子保存、版本冲突检查、历史记录和旧策略备份；覆盖现有及新增有效学生，保留内部学生／项目隔离。官方登录、密钥、本机 Hook 信任不被全局授权替代。外部会话必须明确归属，新授权不追溯采集旧消息。

14 个内置工具、LLM API、自定义网页／EXE／标准 CLI 统一注册。无自动合同的通道准确标为手工交接。受控合同按全局顺序过滤；API 作为自动后备；全部失败后在同一任务选择一次交接目标。新增取消／结果接收接口，队列读取同一注册表，自定义工具增删立即同步且页面读取不触发后台探测。
