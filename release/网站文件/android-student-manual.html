AI教育管家 Android 学生端操作手册

适用版本：Android 学生端 0.6.7

配套主机：Windows 主机端 0.14.2

1. 产品定位

Android 学生端用于进入本人空间、上传与采集资料，并只读查看本人成长模型、报告、教育档案和关联项目知识。管理与知识治理仍由 Windows 主机完成。

首页按“基础设置、资料搜集上传、教育管家对话、教育档案”四个默认折叠板块呈现；二级入口也默认折叠，需要时再展开。

2. 安装与首次连接

  1. 安装 AI-edu-manager-tablet-terminal-0.6.7.apk。
  2. 主机启动学生终端服务。
  3. 通过附近主机、固定主机码、扫码、粘贴连接信息或连接备份发起连接。
  4. 主机接受后设置为个人终端或共享终端。

3. 个人终端与共享终端

  • 个人终端固定绑定一名学生，并支持自动投递。
  • 共享终端输入个人 ID 或拍摄学生二维码进入，结束后点击“退出当前学生”。

不需要 PIN。共享终端未进入学生空间前不会显示学生名单。

4. 上传本地资料

支持拍照、选择图片和普通文件、扫描下载目录，以及从其他应用分享资料。可上传到学生原始资料库或当前学生绑定且未封存的项目原始资料库。按钮显示“正在上传…”“上传完成”或“上传失败，点击重试”，本地源文件不会删除。

5. 屏幕资料采集

采集开始时记录并冻结当前学生及可选项目。采集中不能退出学生，结束后也不能把该批截图投递给另一名学生。“查看与清理采集资料”只显示当前学生的会话，并可安全清理已上传图片。

6. 自动投递文件夹

个人终端可通过 Android 系统文件选择器授权一个目录，选择学生或项目资料目标后启用自动投递。文件稳定后幂等上传，失败稍后重试，且不会删除本地文件。共享终端会自动关闭此功能。

7. 资料进展与每日提醒

首页显示已提交资料、已完成知识化、近 7 天新增和近 30 天活跃频率；当天没有新资料时显示一次轻提醒。

8. 成长模型、学情报告、教育档案与项目知识

进入学生空间后，在“我的成长模型”卡片点击“查看成长模型”，可只读查看能力画像、项目贡献和近期成长证据，不会触发评估、审核或重新分析。打开“学情档案与关联项目知识”后，来源列表可在“我的学情档案”和当前学生关联项目之间切换；已封存项目仍可只读查看。主机只返回当前学生会话有权访问的内容，并再次校验学生与项目关联。退出当前学生后成长模型、项目列表、文档列表和正文都会清空。

9. 连接备份

连接备份保存主机地址、连接模式和设备身份，用于同一设备重装后恢复，不会替代共享终端的学生 ID 登录。

10. 常见问题

  • 看不到关联项目知识：确认项目已绑定当前学生，并确认主机端已有公开 Markdown 知识。
  • 上传按钮没有反应：先确认已进入学生空间，再观察按钮背景与文字状态。
  • 截图上传后没有知识内容：学生端只负责采集，知识消化仍由主机完成。
