# Windows 任务异步存储、条件执行与恢复候选

日期：2026-10-12。源码版本：0.21.1。候选标签：`task-async-recovery-20261012`。

本轮接续 2026-10-11 的有界恢复交付。本文记录实际接入、测试结果和未验收边界；不是正式发布公告，也不代表整个三阶段计划全部完成。候选包含当前工作区已有的课程、卡片等修改，不是干净基线上的单一补丁。

## 本轮接入

| 项目 | 实际范围 |
| --- | --- |
| 全局单一异步写入 | **任务中心**账本与审计事件共用一个持久化队列；同步旧接口仅在内存登记变更。派发、取消、回执确认和新版调用等待保存屏障。不是把全应用所有 JSON 存储改为一个队列。 |
| 存储 Worker | 任务 JSON 序列化、物理写入、临时文件同步、原子替换、事件追加和日志轮转在共享 Worker 执行。禁止主进程失败后回退写同一个账本。首次迁移保留不可覆盖备份。 |
| 存储故障保护 | 旧快照拒绝覆盖；外部修改、磁盘失败、Worker 通道故障锁定新派发。未确认保存不报告成功。未保存原始回执不移除，唯一命名的 pending 文件保留供核对，不自动采用。 |
| WorkBuddy 条件式执行 | 先验证最终 READY，再用合成资料验证限定 JSON、来源与目标路径及宿主暂存。无工具、无 MCP、关闭插件与 hooks；通过后**受控项目资料任务**可后台执行。宿主固定输入、验证并提交，Agent 不直接编辑知识目录。 |
| 休眠恢复 | 新派发暂停，恢复时先核对回执及原执行编号，再恢复任务时限与安全重试。暂停时间不记为业务执行时间，不伪造 Agent 心跳。存储 RPC 使用独立可暂停时钟，先恢复存储通道，避免等待持久化形成死锁。 |
| 熔断 | 三次不同执行的可重试故障后冷却 10 分钟；登录错误等待恢复授权，内容校验错误不计入执行器故障。后台串行复检已授权 Codex/WorkBuddy，健康后恢复；不同时检测所有备用工具。 |

### 接口及异常边界

- 旧同步调用保留：IPC 在需要写入时延迟返回直到持久化屏障完成；异步任务启动首先登记为“启动请求”，不能把排队冒充已执行。
- 桌面交接在有效批次落盘后才生成任务包。后续结果按当前批次补丁保存，不用旧快照覆盖其他任务。
- 取消先持久撤销接收，再请求外部停止。进程退出不能证明远端任务停止时仍显示待核对，保留执行编号和写入范围保护。
- 回执按“提交 → 复制归档 → 保存归档引用 → 移除原收件”顺序处理。崩溃后的同内容同批次结果凭摘要补收，不重复应用知识。
- 手工文件/粘贴导入及资料整理的兼容入口等待保存完成，随后才允许协作回传。退出等待受控提交后再次检查写入屏障，不能遗漏第一次等待期间新增的写入。
- 等待手工发送不占后台分析名额；同一资料范围的不明执行仍受保护。任务中心故障不自动删除历史记录或重跑真实学生任务。
- 所有后台写入失败均保持失败可见，不因为捕获异常而宣称成功；执行日志和已生成文件用于后续核对。

### WorkBuddy 的适配范围

本轮启用的是通过检测的**受控项目资料**通道。旧式学生目录消化及不满足固定输入/宿主提交约束的任务仍走桌面交接，不能套用通过的项目探测结果开放任意文件权限。

首次检测仍要求用户确认可能产生的额度消耗；以后仅对已确认、当前任务选中的执行器复检。成功资格缓存 30 分钟，失败缓存 5 分钟，单执行器单在途探测。CLI 路径/版本变化重新检测，真实任务还校验 CLI 内容哈希。

这里的“无工具受控”是 CLI 能力限制与宿主校验，不声称构成操作系统级沙箱。新 CLI 不支持限制参数或不能返回合格结果时不进入后台模式。没有修改外部账号凭据或模拟点击发送。

- 跳过项：当前环境不执行的学生原始资料目录外 symlink 测试；不能计为通过。其他项目来源路径/链接隔离测试照常执行。

- 新增测试覆盖：真实 Worker 连续 40 次账本/40 次事件写入、磁盘故障、旧快照、外部修改、关闭通道、取消保存屏障、归档顺序、重复回执、维护操作互斥、休眠时钟、恢复失败锁定、熔断分类、资格缓存、伪造目标、CLI 变更与停止确认。

## 性能实测及限制

机器：Windows，i5-12400F（12 逻辑核），63.8 GiB 内存，Node 24.13.0。**不是计划要求的四核/8 GB 验收机**。

| 数据 | 数据文件大小 | 指标 | 实测 |
| --- | --- | --- | --- |
| 1,000 条长正文/结果 | 8,069,757 B | 60 次缓存查询 P95 | 2.18 ms |
| 10,000 条长正文/结果 | 80,726,757 B | 60 次缓存查询 P95 / 冷读 | 15.58 / 358.47 ms |
| 1,000 条并发读写 | 2,691,780 B | 查询 P95 / 持久写入 P95 | 32.27 / 38.68 ms |
| 10,000 条并发读写 | 26,937,780 B | 查询 P95 / 持久写入 P95 | 142.71 / 220.77 ms |
| 10,000 条并发读写 | 同上 | 主线程快照登记最大耗时 / 事件循环最大延迟 | 86.38 / 109.38 ms |

读写场景各 12 轮，报告为 `.tmp/task-async-writer-performance.json` 与 `.tmp/task-async-read-performance.json`。存储测试不是屏幕点击 P95，也不是系统总体验验收。

**已知性能余量不足：**兼容旧业务仍保留内存账本快照，复制及归一化未全部改成轻量命令补丁；10,000 条场景事件循环延迟约 109 ms，不能据此宣称严格满足所有“不超过 100 ms”目标。后续如真机验证不达标，应优先将热点更新收敛到单条命令，不增加并行 Worker 来掩盖全量快照成本。

## 真机验收清单

1. 先退出旧程序并备份任务账本、审计日志、资料和已有业务状态；不同时运行两个主机版本。
2. 导入匹配的合成回执，确认有明确成功/失败反馈、原件可查，重复导入不重复入账；错误 executionId 不能强制采用。
3. 在隔离测试目录模拟写入失败，确认未启动 Agent、没有假成功、原收件仍存在；修复磁盘后重启核对，不自动采用 pending 文件。
4. 使用测试账号确认 WorkBuddy 后台授权与结构检测；观察实际 CLI 版本接受限制参数，并验证无工具行为。未登录、错误输出、资格过期均有可操作反馈。
5. 分析期间、持久化期间、桌面待发送期间分别休眠/恢复；不因休眠批量重试，同一批次不会派发两次。
6. 三次网络/繁忙故障触发冷却；十分钟后仅一个探测。登录与内容错误不进入同一种循环。
7. 在四核/8 GB/SSD 测试机执行 1,000/10,000 条数据的界面点击与分页测试、4 小时混合运行，记录内存、进程、时钟数量以及队列公平性。
8. 回归课程/卡片发布、资料、报告、卡片作答及成长模型；卡片单独评阅不得被资料周期暂停阻塞。

未进行真实厂商账号验收、物理休眠真机验收或四小时压力验收。外部停止不可证明时仍需人工核对；其他业务/执行器的专用流程保持原边界，不能把本轮称为“所有 Agent、所有业务均可自动恢复”。
