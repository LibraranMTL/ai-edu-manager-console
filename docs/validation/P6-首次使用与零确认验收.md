# P6 首次使用与零确认验收

## 自动门禁

- 首页只显示一个主操作，技术工具默认折叠。
- 正常资料消化完成后自动登记结果，不弹出候选确认。
- 报告通过确定性来源校验后自动发布，不增加批准步骤。
- 真实异常合并为一个“需要补充”入口，其余任务继续运行。

执行：

```powershell
node --test tests/p6-zero-confirmation-gate.test.cjs tests/home-workflow-contract.test.cjs tests/digest-workflow-contract.test.cjs tests/p5-report-auto-publish-contract.test.cjs
```

## 十分钟人工计时脚本

1. 在一台未初始化的 Windows 主机启动教育管家。
2. 创建一个虚构学生档案。
3. 在首页点击唯一主操作，导入一份虚构学习记录。
4. 等待首页状态从“待处理/处理中”变为“知识更新”。
5. 打开成长模型或学情报告，确认结果可读且能够查看依据。

记录开始时间、首次知识更新时间、总耗时和实际点击次数。目标为十分钟内完成；正常路径不得出现候选、批次、回执、MCP、JSON、哈希、事务或批准提示。
