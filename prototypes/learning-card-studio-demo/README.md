# AI教育管家 · 学习卡片原生模块 Demo

更新日期：2026-09-28

性质：独立、离线、示意性交互原型。所有学生、学情、学校和使用数据均为虚构内容；本原型不连接教育管家正式数据库、任务中心、学生端或任何模型 API。

## 打开方式

双击 `index.html`，或在本目录启动任意静态文件服务器后打开页面。

## 建议演示路径

1. 从教育管家主导航进入“学习卡片”，确认它是原生模块而不是独立应用。
2. 在“今日卡片”查看系统自动选定的一个学习重点和三条可追溯证据。
3. 点击“生成今日卡片”，观察同一任务依次完成证据读取、内容生成、模板匹配与输出检查。
4. 切换“轻量编辑”，直接修改标题或说明；隐藏或恢复选择题和空白表达区。
5. 切换“森林手账、清晰学术、黑白练习”和 A4／学生端预览。
6. 点击“发送到 Maya 学生端”，查看最简学生反馈闭环。
7. 打开“模板”页签，查看三套首版官方模板；页面不出现插件、安装权限或 API 配置。
8. 打开“使用记录”，查看“发现—生成—完成—调整”的学习闭环。

## Demo 表达的产品决策

- 学习卡片是教育管家的原生业务模块，用户无需理解扩展机制。
- 首版只提供三套官方模板，不执行第三方代码，也不建设模板市场。
- 模块复用学生档案、学情证据、任务、授权、发布和打印能力，不建设第二套核心系统。
- 用户的主要路径只有“生成—确认—发送／打印”；风格、难度和证据由系统自动匹配，仍可轻量调整。
- 卡片只发送生成结果，不向学生端或视觉服务发送原始学情资料。
- 学情证据不足时停止生成，不猜测学生薄弱点。
- 附件中的第三方角色仅作为设计研究，本 Demo 使用原创抽象图形，未使用第三方角色、商标或作品画面。

## 非正式能力

本 Demo 中以下操作均为前端模拟：

- 学情证据读取与教师确认；
- AI 内容生成、质量校验和模板推荐；
- 学生身份隔离、任务幂等和定向发送；
- 模板选择、版本识别与黑白降级；
- PDF 输出、打印一致性和学生反馈回传。
