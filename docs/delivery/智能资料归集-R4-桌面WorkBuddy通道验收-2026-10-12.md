# 智能资料归集 R4：桌面 WorkBuddy 通道验收

日期：2026-10-12。版本：Windows 0.21.1 开发候选。**桌面自带 CLI 的本轮合成契约验证已通过；完整产品验收未完成，不是正式发布。**

> 后续稳定性复验：两次四并发全量及八并发项目测试通过，首次并发失败未复现；WorkBuddy 三轮 18 次调用无超时，但有 1 次严格输出格式失败，**多轮稳定性未通过**。详见 [稳定性与性能复验](智能资料归集-R4-稳定性与性能复验-2026-10-12.md) 和 [用户操作清单](智能资料归集-用户验收操作清单-2026-10-12.md)。下文保留此前单轮验收事实；R4 程序包未改变。

## 1. 验证结论

- 用户重新完成独立官方登录后，使用安装在本机的 WorkBuddy 自带 CLI 执行测试，而不是用独立下载的完整 CLI 替代。完整分类 5 类场景及分类专用检测共 6 次调用全部通过。
- 单独的敏感样本复查通过；完整分类组中的敏感样本再次通过，用时 14.145 秒，返回 `sensitive: true`，宿主自动目标为空，未自动投递。
- 桌面自带 CLI 的消化专用检测及实际消化共 2 次调用通过。真实 Windows 图片 OCR → 完整提取结果交接 → 真实 Agent 消化 → 宿主知识提交通过，OCR 调用数为 **1**，原件未变化。
- 最终产品源码的全量串行回归 2043 项：2042 通过、1 项既有跳过、0 失败，407.20 秒；相关定向回归 86 项全部通过，9.61 秒。
- R3 历史超时及本轮认证／诊断失败均保留。**本次敏感场景未复现 120 秒超时，但不能据此声称历史超时的唯一根因已被证明，或长期稳定性已通过。**

这些验证是合成输入下的真实执行契约检查，不是 200 份资料分类质量测试，也不是目标低配机或四小时运行验收。

## 2. 超时处理与安全边界

安装包公开源码显示，敏感内容审批默认等待 120000 毫秒，到期拒绝；此时限与宿主分类任务总上限相同，有可能使审批拒绝尚未返回就触发宿主超时。R3 没有足够阶段证据将这一路径与模型／网络等待区分，本轮不能倒推历史原因。

本轮修订仅针对受控后台子进程：

1. 强制 `CBC_SANDBOX_APPROVAL_TIMEOUT_MS=1000`。没有交互审批人时尽快拒绝，不自动批准，不关闭敏感检测或保护策略，也不放宽分类任务总超时。
2. 厂商的敏感审批超时、拒绝、保护失败明确映射为 `SENSITIVE_REVIEW_REQUIRED`：保留资料待人工处理，不按网络错误自动重试。分段输出及后续超长诊断不会清除已观察到的拒绝状态；只保留布尔标记，不增加正文日志。
3. 仍等待真实进程关闭；停止未确认维持结果未知，不自动重派。收件箱复扫不会重复派发已转人工的资料，原件保持。
4. 保留空工具、strict 空 MCP、空工作目录、`dontAsk`、仅 local 设置、禁用 hooks／插件／记忆／后台任务，以及宿主学生范围、目录、资料版本、证据及结果结构校验。

本轮还发现厂商调试参数会使该路径的 stdout 出现 `serve 0` 等非 JSON 前缀。该诊断调用被严格解析器拒绝，未当作成功。已移除验收脚本追加的厂商调试参数，保留被动字节数、退出信号和白名单阶段计数；没有删去未知前缀、截取 JSON 或修复模型输出来通过测试。

生产分类的本地敏感识别仍先于 Agent 调用；明确匹配敏感规则的文件保留人工处理，不外发。真实通道验收只使用合成内容，未调用真实学生病历等资料。实际返回的 `sensitive: true` 也禁止自动投递。没有把安全拒绝冒充分类成功。

“无工具活动”的证据是强制调用参数、已核对的厂商实现及本轮合法返回事件，不是 OS 级零权限沙箱证明。Agent 只返回结构化数据，真实文件操作和知识提交由宿主执行。

## 4. 真实分类与消化

| 合成分类场景 | 结果 | 耗时 |
|---|---|---:|
| 明确唯一项目标识 | 通过，宿主允许该项目自动目标 | 26.556 秒，含本进程分类资格检测 |
| 只有语义相似 | 通过，无自动目标 | 15.214 秒 |
| 两个项目冲突 | 通过，冲突标记为真，无自动目标 | 52.047 秒 |
| 敏感资料 | 通过，敏感标记为真，无自动目标 | 14.145 秒 |
| 跨学生及调用工具诱导 | 通过，拒绝越界候选，无自动目标，无工具调用 | 12.098 秒 |

完整分类组 6 次进程调用均正常退出并提供合法最终结果。单独敏感复查另有 2 次调用（资格检测与敏感分类），28.015 秒通过，单场景结果没有当成整组结果。

消化验证另行检测能力，不继承分类资格：合成图片的 20、25、30 摄氏度事实经真实 OCR 提取，完整缓存交接到同学生项目，真实 Agent 产物通过固定资料来源校验后提交到合成知识目录。两次 CLI 调用正常退出；OCR 1 次、交接命中、原件一致、事实保留、知识提交全部通过。

分类和消化的关系保持 R3 设计：同学生、同内容版本、同格式、同提取器／OCR 参数下复用完整提取结果，超长分类预览不能冒充完整全文。文件、授权或提取配置变化时不沿用无效缓存。AI 分类判断投递位置，AI 消化形成知识产物，两类理解任务不直接互相替代。

## 7. 需要用户参与的事项

**本轮已完成：** 独立官方登录授权。无需再次发送密码、Token 或增加模型配置。

仍需用户／目标环境参与，不能用开发侧回归替代：

1. 在独立试用环境运行便携候选，确认未来生产使用的账号／通道及授权范围。当前测试认证不自动转为生产授权，也不自动启用资料来源。
2. 固定 200 份独立标注资料：与规则构建集分开，验收建议准确率 ≥90%、自动投递准确率 ≥98%、自动覆盖率 ≥30%、越权或跨学生自动投递为 0。
3. 至少 5 名代表用户，各 30 份等难度资料，对比手工流程，计入确认和纠正时间，验收操作时间中位数下降 ≥50%。
4. 四核／8GB／SSD 目标机：万文件扫描时的前台 P95 与劣化、无变化零正文／OCR／Agent 调用、四小时混合运行；分别记录宿主、提取进程、外部 Agent 资源，包含休眠补扫、权限撤销及恢复。
5. 人工试用来源设置、批量确认、已投递纠正、被引用资料保留；签名和正式发布仍需另行完成。

Android 新采集不在首版范围。本轮不宣称统计分类质量、用户效率、低配机性能、四小时稳定性或完整首版验收已经通过。
