# 每天 10 分钟提分卡片 Demo

更新日期：2026-08-01
性质：高保真交互原型，不是已经接入正式数据的产品功能

## 打开方式

在 Windows 主机上双击本目录中的 `index.html`，即可离线打开 Demo。页面不依赖安装服务、网络或真实学生账号。

入口文件：`index.html`

## Demo 包含的页面

- 今日提分卡：桌面 4:3、手机竖屏、长卡片和 PDF 四种预览。
- 输出设置：支持彩色 / 黑白打印预览，并可下载 PNG、JPG 图片或进入 PDF 打印预览。
- 今日提分卡下的“练习计划”：支持“学情更新并定时兜底 / 固定时间 / 仅手动”三种生成模式，共用一个防重复任务。
- 科目范围：自动选择、语文、数学、英语、物理、化学、生物、历史、地理。
- 复习依据：今日要点、本周要点、本月要点，或根据学情报告和教育档案自动选择。
- 今日提分卡下的“自动记录”：展示练习主题、生成依据、时长、反馈与状态。
- 今日提分卡下的“卡片模板”：内置主题、本地 Agent 生成主题、用户自有图片 API 配置入口。

左侧菜单中，“今日提分卡”是一级菜单；“练习计划、自动记录、卡片模板”是可折叠二级菜单。

## 建议演示路径

1. 打开“今日提分卡”，切换 4:3、手机、长卡片、PDF 四种视图；长卡片约为普通手机卡长度的 1.7 倍。
2. 打开“黑白打印”，确认彩色底图和装饰已简化为高对比线框版式。
3. 在“下载格式”中分别选择 PNG、JPG 和 PDF；PNG/JPG 会直接生成图片，PDF 进入系统打印预览。
4. 选择一个错误答案，查看即时反馈；再选择正确答案并展开解析。
5. 打开“生成依据”，核对报告、成长档案和证据编号。
6. 点击“完成练习”，提交难度感受与信心反馈。
7. 展开“今日提分卡”，打开二级菜单“练习计划”，依次切换三种生成模式，观察时间设置和右侧策略摘要联动。
8. 选择物理、化学、生物、历史或地理，再切换四种复习范围并保存。
9. 打开二级菜单“卡片模板”，切换内置主题；图片 API 继续使用原有配置入口，本版不新增或移动入口。
10. 点击“立即生成”，查看手动触发与自动任务共用的模拟生成流程。

## 已表达的产品规则

- 每张卡只针对一个明确薄弱点，练习目标约为 10 分钟。
- 每张卡必须绑定唯一学生 ID，并且只推送到该学生的 Windows/Android 学生端。
- 生成依据必须可查看、可追溯。
- 学生打开卡片不等于完成练习，必须由学生明确提交。
- 图片服务只接收视觉提示词，不发送学生学情、姓名或练习答案。
- 手动生成、有效学情更新和每日定时是三个触发入口，但共用一个生成任务；同一学生、同一自然日只保留一个有效任务，连续更新会合并处理。
- “资料已消化”不等于必然重做卡片；只有形成可用新知识时才触发，定时任务只负责当天兜底。
- 长卡片是独立输出版式，目标高度为普通手机卡的 1.5—2 倍；当前 Demo 采用约 1.7 倍。
- 黑白打印不是简单灰度转换：需要去除大面积底色、弱对比装饰和阴影，保留清晰边框、文字层级和答题区域。

## 尚未实现

当前 Demo 使用模拟数据和前端交互，以下能力仍需按开发计划落地：

- 读取真实学情报告、成长档案及其证据快照。
- 本地 Agent 生成练习内容并执行结构化校验。
- 主机端持久化、任务中心调度、失败重试和审计记录。
- 消化完成事件、定时调度与手动入口接入同一个真实任务及幂等键。
- Windows/Android 学生端定向投递与提交回传。
- 正式 PDF/PNG/JPG 渲染、黑白与热敏打印一致性和离线缓存。
- 用户图片 API 密钥的系统级安全存储。

## 命名与宣传边界

“提分卡片”是内部产品名称和设计目标，不代表承诺分数必然提高。面向用户的正式说明建议使用“每日 10 分钟针对性练习”“巩固薄弱知识点”等表述，避免“保证提分”一类承诺。
