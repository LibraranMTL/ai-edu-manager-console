# 0.23.0 项目详情双 Tab 内部候选记录

## 结论

- 已按确认 Demo 将已有项目详情拆分为“项目综合报告”和“项目资料中心”两个同级 Tab。
- 打开项目时默认显示综合报告；项目资料、知识空间、治理与归档等原项目管理内容归入资料中心。
