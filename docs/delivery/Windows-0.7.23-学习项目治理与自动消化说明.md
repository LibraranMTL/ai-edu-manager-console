# Windows 0.7.23 学习项目治理与自动消化说明

## 界面调整

- 单项目详情改为紧凑布局，项目列表宽度缩小。
- 路径卡片使用更小字号并允许任意位置换行。
- 操作工具栏可换行，详情区独立纵向滚动。
- 常规窗口和 100% 缩放下不再需要大幅缩小页面。

## 项目管理

- 工作空间重新定位只更新当前主机工作空间绑定，不移动项目知识空间。
- 移除项目记录后，可从 `.edu-manager/项目记录已移除.json` 恢复索引。
- 项目包导入导出使用 `edu-manager-project` v2 JSON，传递项目结构、模板和策略，不复制原始资料、知识产物和历史贡献。

## 项目模板 V2

每个模板同时定义：

1. 工作空间目录预设。
2. 知识加工策略。
3. 成长与报告策略。
4. 预期成果。

自定义模板也保存上述全部内容。

## 自动消化

- “立即执行消化”会真正调用本机 Codex CLI。
- 输出和错误写入项目 `.edu-manager/digest-run-*.log`。
- 同一项目正在消化时不允许重复提交。
- 定时自动化扫描到待消化资料后，会尝试启动 Codex CLI；未安装时保留待处理状态并显示原因。

## 知识归一与仪表盘

- 跨项目知识关联支持中英文常用别名、后缀清理和名称相似度合并。
- 保留原知识文件，只生成归一索引与别名记录。
- 仪表盘增加知识覆盖率、风险原因、贡献状态和指标筛选下钻。
