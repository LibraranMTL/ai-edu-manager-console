# AI教育管家 Windows 学生端操作手册

**适用版本：Windows 学生终端 0.16.1**

**配套主机：Windows 主机 0.16.1**

## 1. 产品定位

Windows 学生终端安装在学生使用的 Windows 电脑上，只承担学生进入、资料采集、资料投递，以及只读查看本人成长模型和档案，不提供学生档案、项目、知识治理或报告发布管理。教师或家长继续使用独立的 Windows 主机端。

## 2. 首次连接

1. 下载并运行 Windows 学生端；不要把 Windows 主机端安装给学生使用。
2. 教师或家长在主机“系统设置 → 使用模式”中选择“主机-终端模式”，启动学生终端协作服务。
3. 在学生端选择“局域网连接”或“Tailscale 远程连接”。
4. 选择局域网连接时，学生端会显示长期固定的终端码。点击“扫描局域网主机”，可输入固定主机码筛选，也可直接查看同一局域网中的全部主机。
5. 选择正确的主机并点击“申请连接”，教师或家长在主机确认终端码后点击“接受”；也可以由主机搜索本终端并发出邀请，再由学生端点击“接受”或“拒绝”。
6. 主机接受连接后，在设备卡片中选择“个人终端”或“共享终端”。

固定主机码和固定终端码只用于识别设备，不是密码，不需要再输入 PIN。连接申请使用程序内部的随机令牌并在两分钟后超时。旧版主机、访客网络、客户端隔离或防火墙阻断广播时，展开“其他连接方式”，继续使用粘贴连接信息、主机地址和六位配对码。

### 可选：通过 Tailscale 远程连接

在连接页选择“Tailscale 远程连接”后，学生端会检测本机是否安装 Tailscale，并显示“已安装”或“未检测到安装”：

1. 已安装时，点击“打开 Tailscale”启动客户端并确认已经登录。
2. 未安装时，点击“下载 Tailscale”打开 Windows 官方下载页；安装完成后返回学生终端点击“重新检测”。
3. 让 Windows 主机和学生终端加入同一个 Tailscale 网络。
4. 粘贴主机复制的学生终端连接信息；系统只选用其中的 Tailscale 地址。也可以手工填写主机提供的 Tailscale 地址和六位配对码。

两种连接方式相互隔离：选择局域网时不会误用 Tailscale 地址，选择 Tailscale 时也不会自动回退到局域网地址。学生终端只检测本机安装状态，不读取 Tailscale 账号、密钥或网络成员信息。连接成功后仍然沿用教育管家的设备确认和学生数据隔离规则。

## 3. 个人终端与共享终端

- 个人终端：在主机绑定一名学生，终端启动后自动进入该学生空间，适合一人长期使用的电脑；支持自动投递文件夹。
- 共享终端：每次由学生输入个人 ID，或使用扫码器扫描主机生成的学生二维码；进入后只加载本人资料，退出后交给下一位学生；不启用持续自动投递文件夹。

学生 ID 在主机创建或升级学生档案时自动生成。它不是内部文件夹 ID，不会改变既有学生目录。Windows 终端可使用普通 USB 扫码器，二维码内容会像键盘输入一样进入 ID 输入框。

## 4. 选择资料归属

进入学生空间后，再选择以下目标之一：

- 学生原始资料库：适合日常作业、学习记录和不属于特定项目的资料。
- 绑定项目原始资料库：适合项目研究、作品、过程截图和项目参考资料。

终端只显示当前学生已经绑定且未封存的项目。主机依据当前学生会话再次校验学生和项目归属。

## 5. 上传本地文件

点击“选择并上传文件”，可一次选择多个图片、PDF、Office、文本、Markdown、CSV 或 ZIP 文件。上传期间显示当前文件和进度；成功后，主机端对应资料库进入待处理状态。

首页会显示四项简要进展：已提交资料、已完成知识化、近 7 天新增和近 30 天活跃频率。“已完成知识化”按已经消化完成的资料数统计，不等同于知识库中的文件数量。当天尚未提交资料时，首页显示“提交本日学习资料”提醒；点击“现在上传”直接进入文件选择，点击“稍后再说”只关闭当天提醒。

## 6. 自动投递文件夹

自动投递只在个人终端可用：

1. 选择资料目标和本地文件夹。
2. 勾选启用并保存设置。
3. 终端定期检查新文件，并以稳定上传编号避免重复入库；不会删除或移动本地文件。

共享终端不会监测自动投递文件夹，避免下一位学生沿用上一位学生的投递目标。

## 7. 屏幕资料采集

1. 进入学生空间并选择屏幕或应用窗口。
2. 选择学生原始资料库或绑定项目原始资料库后开始采集。
3. 结束后上传采集资料。

采集会话在开始时冻结当前学生和目标。共享终端必须先结束采集才能退出，不能把上一位学生的截图改投给下一位学生。

## 8. 精选课程与课程资料采集

进入学生空间后，“精选课程”只显示主机已启用并分配给当前学生的课程。

Windows 学生端没有“课程管理”菜单，也不能导入或修改课程。课程启用、年级限制和学生分配由已激活的专业版、机构版或平台版 Windows 主机在“精选课程 → 课程管理”中设置；平台课程草稿在发布为课程包前不会出现在学生端。

1. 点击课程卡片的“打开课程”。
2. 课程在独立受限浏览器中打开，只允许课程目录明确登记的 HTTP 或 HTTPS 域名；未知域名、新窗口、下载和危险协议会被阻止。HTTP 仅用于确实没有 HTTPS 的课程网站，不会绕过证书错误。
3. 页面顶部采集入口初始为“待开始”，不会自动录屏。
4. 需要保留学习过程时，先选择学生资料库或本人有效关联项目，再点击开始并完成 Windows 系统屏幕授权。
5. 结束后检查采集文件，再点击“确认入库”。同一文件重复提交不会生成重复资料记录。

采集资料会记录当前学生、课程、提供方、页面 URL、采集时间和投递目标。打开课程或采集页面不等于完成课程、答题正确或形成学情结论。课程账号、会员和收费规则以第三方页面为准。

如果看不到应有课程，请先刷新学生空间；仍为空时，让教师或家长在主机端检查课程是否启用、年级是否匹配、当前学生是否被分配，并确认已经点击“保存并下发”。

金榜学霸网站当前应使用 `http://www.jinbangxueba.com/`。如果课程仍保存为 HTTPS，请让主机管理员编辑该机构精选课程并重新“保存并下发”。

## 9. 成长模型、学情报告、教育档案与项目知识

- “查看成长模型”读取当前学生的能力画像、项目贡献和近期成长证据。信息来自主机已经形成的成长索引，只读展示，不在学生端触发评估、审核或重新分析。
- “查看学情报告”读取当前学生已经由主机发布的整体画像、行动建议、历史变化和阶段总结。
- “查看教育档案”读取当前学生可访问的 Markdown 档案。
- “查看关联项目知识”列出当前学生绑定项目中的公开 Markdown。项目即使已经封存也可继续只读查看，但不能从学生端修改或发布项目。
- 主机会按当前学生会话再次核对学生和项目归属；共享终端退出后会清空成长模型、项目、文档列表和正文，终端不能读取其他学生或未关联项目的内容。

## 10. 上传反馈与退出

- 上传中显示文件名、数量和进度；失败文件保留在本地，可重试。
- 共享终端使用结束后点击“退出当前学生”；页面会清空学生、成长模型、项目、档案、报告和待传队列。
- 会话长时间不用会失效，需要重新输入或扫描学生 ID。

## 11. 常见问题

- 无法进入学生：向教师或家长核对主机“学生登录 ID 与二维码”中的 ID。
- 看不到项目：确认项目已绑定当前学生且未封存。
- 共享终端没有自动投递：这是数据隔离规则；需要自动投递时由主机改为个人终端。
- 上传失败是否删除本地文件：不会。
- 扫描不到主机：确认两台电脑位于同一局域网、主机已经进入“主机-终端模式”，并允许 Windows 防火墙专用网络的 UDP 18778。不要在同一台电脑同时运行主机版和学生端。
- 主机发现不到本终端：让 Windows 学生端停留在“连接主机”页面，再由主机点击“查找学生终端”；也可以直接在主机输入本机固定终端码筛选。
- Tailscale 显示未安装：点击“下载 Tailscale”进入官方 Windows 下载页；完成安装后点击“重新检测”。
- Tailscale 已安装但无法打开：从 Windows 开始菜单启动 Tailscale，或重新运行官方安装程序修复启动入口。
