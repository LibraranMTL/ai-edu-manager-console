# Windows 0.7.49 文件资产学生筛选联动修复

## 修复内容

文件资产中心选择学生后，以下区域统一切换到该学生的资产范围：

- 资产总数；
- 重复文件组；
- 治理候选、高风险和失效引用；
- 登记资产、识别引用和治理候选工作流统计；
- 最近 7 天新增资产和新增引用曲线；
- 重复文件分组；
- 资产列表和资产引用详情。

学生资产归属同时检查资产所有者、关联学生列表以及学生引用关系。切换学生后，如果原来选中的资产不属于新筛选范围，详情区自动选择当前范围内的第一项，不再残留其他学生资料。

搜索文本、来源、文件类型和“只看重复文件”继续作为列表级筛选，不改变学生范围看板，避免搜索输入时看板频繁跳动。

## 验证

- 新增看板学生筛选联动契约测试；
- 新增资产详情越界防护测试；
- 全部自动测试通过；
- Windows 生产构建通过；
- 使用本机真实资产索引验证不同学生得到不同资产计数。
