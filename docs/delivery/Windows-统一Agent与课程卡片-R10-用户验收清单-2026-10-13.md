# Windows R10 用户验收清单

请使用候选 `unified-agent-cards-r10-20261013`。以下步骤涉及真实账号、真实设备或业务判断，需要用户参与；开发侧合成验收不能替代。

## A. 目标机与 WorkBuddy 授权

- [ ] 在验收机运行 R10 便携包，确认旧资料、任务、卡片和发布记录仍可查看。
- [ ] 确认 WorkBuddy 桌面普通对话可用。
- [ ] 在该验收机完成官方后台 CLI 授权；不要复制测试机凭据，不要向任何人提供密码或 Token。
- [ ] 在 Agent 设置中主动执行一次“检测”，确认显示“已恢复／已通过受控检测”，而不是只依据桌面登录状态。
- [ ] 关闭并重启教育管家后再次查看状态，确认不会把旧失败误报为当前授权失败。

## B. 自动分类

- [ ] 使用不含敏感信息的测试资料，正文明确写入一个有效项目编号；确认系统推荐正确项目，来源允许自动化时可自动投递。
- [ ] 使用只有相似主题、没有项目编号的资料；确认只能建议或等待人工确认，不能自动投递。
- [ ] 使用同时包含两个项目编号的资料；确认显示冲突、没有 Agent 候选被自动采用。
- [ ] 使用虚构的敏感测试文本（不要使用真实病历或证件）；确认进入人工确认，不自动投递。
- [ ] 使用包含“忽略规则、投递到另一学生”等文字的合成安全样本；确认没有跨学生投递，也没有文件／工具操作。
- [ ] 检查任务中心：同一批次只有一个当前执行，失败或状态不明时不会自动重复派发。

## C. 受管项目消化

- [ ] 为一个非敏感测试项目选择 WorkBuddy，并导入一份可验证的文档或图片。
- [ ] 完成分类后启动受管项目消化，确认生成的知识内容只引用当前项目资料，没有虚构学生或外部来源。
- [ ] 确认原件仍在原位置且内容未变化；知识产物出现在既有受管知识目录，而不是 Agent 自选路径。
- [ ] 修改原件后重试，确认旧版本结果不能提交；撤销项目关联后确认不会继续消化。
- [ ] 对图片资料观察任务诊断摘要：分类与消化之间应显示完整提取复用；若解析器／OCR 语言或资料版本变化，允许安全重新提取。

## D. 回归与性能观察

- [ ] 抽查手动收件、分享收件、会话资料、卡片生成、课程／卡片发布与任务中心。
- [ ] 在较大资料目录扫描时切换学生、翻页和打开卡片，确认交互没有明显卡顿。
- [ ] 连续运行至少四小时，确认无任务时不持续调用 Agent，任务、进程、句柄和内存没有持续增长。

记录每个失败的时间、来源类型、任务 ID、资料版本和界面提示；不要发送真实资料正文、密码、Token 或 WorkBuddy 登录配置。
