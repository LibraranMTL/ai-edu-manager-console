# AI教育管家健康管理模块网页版 Demo

独立交互原型，不接入正式学生、健康或机构数据。

## 设计原则

- 视觉主张：像一份被认真维护的长期健康档案，安静、可信、可追溯，不做“医疗科技霓虹屏”。
- 内容结构：健康总览 → 资料与证据 → 记录与趋势 → 行动 → 健康课程 → 精选服务 → 设置。
- 交互主张：导航切换保持上下文；关键资料打开证据抽屉；导入、课程、转介和AI问答通过轻量弹层完成。
- 产品边界：非诊断；教育与健康分域；跨领域分析默认关闭；健康服务不默认共享档案。

## 运行

```powershell
pnpm install
pnpm dev
```

构建：

```powershell
pnpm build
```
