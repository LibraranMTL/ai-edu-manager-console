# AI教育管家 Android 学生端操作手册

**适用版本：Android 学生端 0.6.7**

**配套主机：Windows 主机端 0.14.10**

## 1. 产品定位

Android 学生端安装在学生使用的平板或手机上，用于进入本人学生空间、上传与采集资料，以及只读查看本人成长模型、学情报告和教育档案。档案初始化、项目管理、知识治理和报告发布仍由 Windows 主机端完成。

首页按“基础设置、资料搜集上传、教育管家对话、教育档案”四个板块呈现。四个板块及其二级入口默认折叠，需要时点击展开，避免把连接、上传、对话和档案操作同时铺满屏幕。

## 2. 安装与首次连接

1. 安装 `AI-edu-manager-tablet-terminal-0.6.7.apk`。
2. 主机在“系统设置 → 使用模式”中选择“主机-终端模式”，启动学生终端协作服务。
3. Android 与主机位于同一局域网时，可查找附近主机并核对固定主机码；也可使用扫码、粘贴连接信息或连接备份。
4. 主机接受连接后，为该设备选择“个人终端”或“共享终端”。

## 3. 个人终端与共享终端

- 个人终端：主机固定绑定一名学生，连接后自动进入本人空间，适合一人长期使用的平板。
- 共享终端：学生在平板上输入个人 ID，或点击“扫码进入”拍摄主机生成的学生二维码；进入后只加载本人项目、报告和档案，使用结束后点击“退出当前学生”。

不需要 PIN 或密码。学生 ID 由主机在创建或升级学生档案时自动生成。共享终端未进入学生空间前不会获取或显示学生名单。

## 4. 上传本地资料

Android 支持拍照、选择图片、选择普通文件、扫描下载目录，以及从浏览器、相册、PDF 阅读器或文件管理器分享资料。

1. 先进入学生空间。
2. 选择文件或拍照。
3. 选择“学生原始资料库”或当前学生绑定且未封存的“项目原始资料库”。
4. 确认上传。终端会分块传输文件，主机端同步执行限额校验和流式落盘，大文件上传不再需要整体加载到内存。

按钮会用文字和背景颜色反馈按下、上传中、成功、失败和禁用状态：开始后显示“正在上传…”，成功时显示“上传完成”，失败时显示“上传失败，点击重试”。本地源文件不会因上传而删除。

## 5. 屏幕资料采集

1. 进入学生空间，并可选择一个绑定学习项目。
2. 选择智能混合、内容变化或固定间隔策略。
3. 设置时长并通过 Android 系统授权屏幕捕获。
4. 采集中可重点截取、暂停、继续和结束。
5. 结束后确认上传到学生资料库或绑定项目资料库。

采集开始时会记录当前学生和可选项目，并保存在该学生的独立采集目录。采集运行中不能退出学生；结束后也不能把该批截图投递给另一名学生。

点击“查看与清理采集资料”可以：

- 只查看当前学生的采集会话和缩略图；
- 清理已经上传成功的图片，同时保留未上传图片；
- 确认后删除整个已结束会话；正在采集的会话不能删除；
- 检测到升级前未标记学生的旧会话时，只显示数量，不展示其中图片，避免串档。

## 6. 自动投递文件夹

自动投递只在个人终端可用：

1. 点击“选择文件夹”，在 Android 系统文件选择器中授权一个目录。
2. 选择投递到当前学生原始资料库或某个绑定项目原始资料库。
3. 点击“启用自动投递”。应用打开时会检查一次，系统联网时通常约每 15 分钟检查一次，也可点击“立即检查”。
4. 新文件稳定后才上传；同一文件版本和同一目标不会重复入库，失败文件稍后重试，本地文件不会删除。

切换为共享终端时会自动关闭自动投递，避免下一位学生沿用上一位学生的文件夹和投递位置。普通文件仍可手动上传。

## 7. 资料进展与每日提醒

首页显示已提交资料、已完成知识化、近 7 天新增和近 30 天活跃频率。“已完成知识化”按已经消化完成的资料数统计，不等同于知识库文件数量。

当天没有新资料时显示“提交本日学习资料”提醒。点击“现在上传”进入普通文件上传；点击“稍后再说”只关闭当天提醒，不会伪造已提交状态。

## 8. 查看成长模型、学情报告、教育档案和项目知识

进入学生空间后，可在“我的成长模型”卡片点击“查看成长模型”，查看能力画像、项目贡献和已确认或观察中的近期成长证据。成长信息来自主机已经形成的成长索引，只读展示，不在学生端触发评估、审核或重新分析。

打开“学情档案与关联项目知识”后，来源列表可在“我的学情档案”和当前学生关联项目之间切换；已封存项目仍可只读查看。终端只从主机读取当前学生会话有权访问的公开 Markdown，并可缓存最近查看内容。主机会再次校验学生与项目关联，退出当前学生时成长模型、页面、项目列表和正文都会清空。

## 9. 连接备份

- 导出连接备份：保存主机地址、连接模式和设备身份；
- 导入并连接：用于同一设备重装后的恢复。

连接备份恢复的是设备连接，不会替代共享终端的学生 ID 登录。

## 10. 常见问题

### 已连接但没有进入学生

共享终端需要扫码或输入个人 ID；个人终端需要教师或家长在主机设备卡片中绑定学生。

### 学生 ID 无效

向教师或家长核对主机“学生登录 ID 与二维码”中的完整 ID；系统会校验 ID 格式和校验位。

### 看不到绑定项目

确认项目已经绑定当前学生且尚未封存，然后重新进入或刷新。

### 上传按钮没有反应

先确认已经进入学生空间，并观察按钮背景和文字状态；失败时检查主机服务和网络后重试。

### 截图上传后没有知识内容

学生端只负责采集和上传。知识消化、成长模型和学情报告更新由 Windows 主机端继续完成。
