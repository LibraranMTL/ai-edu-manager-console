# AI教育管家平板终端

这是独立于旧 Android 控制台 APK 的客户版平板终端，用于“Windows 主机控制台 + Android 平板终端”模式。

- 应用名称：AI教育管家平板终端
- 包名：com.qxmatrix.eduterminal
- 当前源码候选版本：0.6.19（code 89）
- 当前学习与规划候选 APK：AI-edu-manager-tablet-terminal-0.6.19.apk
- 候选 APK SHA-256：435690E3D1E1E85B8EA0E3932E704570085A9E820826FEC0130D468FDA3A59E5
- 本次试构建曾覆盖同目录下的 0.6.18 文件；该旧文件当前哈希与既有记录不一致，不再作为有效历史候选使用。

## 客户版功能

- 拍照识别二维码或粘贴 Windows 主机配对信息，绑定设备 token。
- 导出当前连接备份，并在同一平板重装后导入备份直接恢复连接。
- 读取主机端授权学生列表。
- 上传资料到主机。
- 浏览主机端学情 Markdown 档案。
- 从文件管理器、相册或其他 App 分享资料到平板终端后上传。
- 从智能体应用分享当前对话，或粘贴对话正文，一次确认后存入当前学生教育档案或本人关联项目。

## 上传入口

“上传资料到主机”会提供多个入口：

- 选择文件：优先 ACTION_OPEN_DOCUMENT，失败后回退 ACTION_GET_CONTENT。
- 选择图片/截图：使用图片选择器或 image/* 内容选择器。
- 拍照上传：调用系统相机并直接上传拍照结果。
- 扫描 Downloads 最近文件：列出最近 50 个常见学习资料文件并支持多选上传。
- 上传已分享资料：接收其他 App 分享来的文件后上传。

0.5.5 修复部分 Android 平板上点击上传后系统文件选择窗口无法打开的问题。文件选择器现在直接启动，不再因系统应用可见性预检查误判而提前退出。

0.5.6 增加学情报告按钮选中反馈。切换整体画像、每日行动建议、历史变化或阶段总结时，当前报告按钮会使用主色高亮。

0.5.7 增加“查找附近主机 + 6位短码”连接方式。平板与主机位于同一局域网时可自动发现电脑；连接后仍须在 Windows 端授权学生。扫码、粘贴连接信息和连接备份入口继续保留。

0.6.3 将屏幕采集按学生目录隔离，增加采集预览与安全清理；个人终端支持系统文件夹授权、稳定性等待、幂等且不删除本地文件的自动投递；首页增加资料进展和每日轻提醒。0.6.2 的分块流式上传继续保留。

0.6.5 在 0.6.4 的当前学生关联项目知识只读能力上，增加“我的成长模型”。它只显示当前登录学生的能力画像、项目贡献和已确认或观察中的近期成长证据，不增加审核、编辑或技术配置。

0.6.8 增加当前学生“精选课程”入口：课程由 Windows 主机按签名目录、机构策略和学生范围合并下发，在独立安全 WebView 中打开。课程资料采集必须由学生点击并完成 Android 系统录屏授权，采集记录保留学生、课程、页面与投递目标归属。

0.6.9 修复手机竖屏和自适应布局中的精选课程卡片：不再沿用平板横排的权重参数，课程封面下方不会出现异常大块留白，课程名称、简介、账号说明和打开按钮按内容连续显示。

0.6.10 允许课程目录明确登记域名的 HTTP 课程链接；未知域名、危险协议和 HTTPS 证书绕过仍被阻止。金榜学霸课程应使用 `http://www.jinbangxueba.com/`。

0.6.15 在“资料搜集上传”增加最简智能体对话导入：支持系统纯文本分享和粘贴，默认当前学生教育档案、项目可选；失败时保留单份草稿并允许重试。它不读取其他应用私有聊天记录，不抓取分享链接，也不增加附件、文件解析或后台队列。

0.6.16 将首页升级为更适合中小学生的自适应学习工作台：大横屏显示左侧导航和三列彩色学习卡片，竖屏及中等宽度自动降为两列；设备旋转时即时重排，详细连接和系统功能继续收纳在折叠区域。

0.6.17 候选版把一次已授权的屏幕采集会话扩展为“采集结束后自动投递”：学生先选择自动投递或保留本机，再完成 Android 系统录屏授权；会话结束后仅把该学生、该会话目录中的截图交给后台网络任务投递，断网会按系统调度重试。通知栏持续显示采集状态，随时可停止；对话仍只接受学生主动分享或粘贴的正文，不读取其他应用私有聊天记录。

0.6.18 源码候选接入主机项目资料统一存储协议：项目上传使用持久队列和可核对回执；授权项目支持资料、待整理、知识、贡献四视图；迁移期间保持只读并显示主机状态。0.6.19 新增学习卡片、规划、建议收藏与文字分享收件箱入口，先核验主机能力；练习作答和分享草稿按主机与资料代次隔离暂存，连接恢复后按同一提交编号核对。仍需最终真机、真实网络和覆盖安装验收，不能视为线上正式版。

0.6.7 在连接旧版主机时继续自动读取成长模型 Markdown，但只显示面向学生的成长摘要、能力画像和项目贡献，不再展示 Schema、原始表格或本机路径。
