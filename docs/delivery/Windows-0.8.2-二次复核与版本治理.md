# Windows 0.8.2 二次复核与版本治理

## 修复内容

- 首次消化与二次复核不再共用 `digest-receipt.json`。
- 每次复核生成独立的 `digest-review-request.json`，Agent 将结果写入 `digest-review-receipt.json`。
- 同步前校验复核轮次、消化批次、回执时间、资料 ID 完整性和状态合法性。
- 旧回执、缺失回执或不完整回执不再改变统计，也不再显示虚假的“同步成功”。

## 版本治理

- Windows 版本使用每段 1 至 10 的递增规则：`0.8.1 … 0.8.10 → 0.9.1`。
- 构建脚本拒绝修订号为 0 或大于 10 的版本。
- 新增项目主更新日志 `CHANGELOG.md`，以后每次迭代必须追加记录。

## 验证

- Electron 主进程语法检查通过。
- 自动化测试和 Windows 生产构建通过。
