# Android 单机版：未知结果恢复与网关接入开发记录

日期：2026-10-02。继续执行 Windows 0.19.3 架构对齐计划。版本仍为 1.2.8 / 32，未提交、未推送、未修改线上服务或正式下载清单。

## 本批实现

### 普通消化与云摘要未知结果恢复

- 任务中心新增“核对未知消化／云摘要结果”入口，仅列当前学生的记录；字面前缀查询不把相似学生 ID 当作同一作用域。
- 用户先核对账单、本机产物、云端清单/回收站，填写核对说明后允许下一次手动操作重试。填写说明应只描述核对结果，不填写 API Key 或其他凭据。
- 授权以当前记录内容指纹做事务内比较；记录已变化、作用域不符、记录非未知或任务仍在本进程执行时拒绝授权。
- 原模型回执、文件及历史状态不删除，核对操作保存独立审计记录。授权本身不调用模型、不上传文件，也不立即恢复后台任务。
- 单次授权在下一次实际尝试前变回未知状态；重复调用不能继续使用同一授权。资料消化只允许手动选择资料的入口消费授权，自动消化不能消费。
- 云摘要即使有人工重试授权，也继续先核对远端活动文档及回收站；已撤回摘要不复活。
- 备份恢复后单次重试授权失效，恢复为未知并需重新确认。

### 网关会话客户端与 HTTP 接入点

- 新增 Android 显式会话签发客户端，输入必须包含受控集成提供的许可证/设备证明、确切学生和设备作用域；不能用“本机显示已激活”替代服务端证明。
- 仅允许 HTTPS 或本机回环地址；证明大小受限，短时凭据仅保存在内存中，返回作用域与时效重新校验。
- 拒绝、作用域不符或取消不自动重试，不回退到共享密钥/个人 API Key。客户端不把证明和凭据写入日志、偏好或备份。
- 云服务新增 `/model-gateway/session` 和 `/model-gateway/generate` 的可选接入点，默认未配置返回 404。
- 接入必须显式传入带授权/撤销/供应商适配器的网关对象；生成请求 Bearer 与正文短时凭据必须一致。现有网关继续检查许可证、学生/设备、模型白名单、额度、持久化幂等回执和未知结果保护。
- 服务关闭时关闭网关数据库。普通报告/文档接口及默认启动方式不自动启用网关。

**尚未完成的正式接入：** 本批没有新增正式平台密钥、信任根、真实许可证/设备注册适配器或启用网关的设置 UI，也没有把学习/规划调用切换到网关。真实授权证明来源、正式配置和原生 UI/模型路由仍需后续集成；HTTP 接入点及签发客户端通过测试不等于正式网关已经可用。
