# Windows 统一 Agent 与课程／卡片 R9：用户验收操作清单

以下项目需要真实账号、真实设备、业务判断或人工观察，开发侧不能替代。请使用候选 `unified-agent-cards-r9-20261013`，不要在 R8 上验收本轮修复。

## A. 优先验证：授权恢复

1. 启动 R9，进入“资料收件箱”，选择配置为 Codex 的学生。
2. 对仍保留历史错误的资料，界面应显示“Agent 已登录，等待受控检测”，而不是要求重复登录。
3. 点击“检测当前学生 Agent 授权”，确认合成检测。检测不含学生资料，可能消耗少量额度。
4. 通过后应显示“Agent 已恢复，等待重新分析”；退出该页面再进入，状态仍保持。
5. 勾选一份非敏感测试资料，点击“重新分析”。确认资料不会在检测通过后自动重派。

## B. WorkBuddy 后台授权

当前真实复验仍返回 `AUTHENTICATION_REQUIRED`。如需验收 WorkBuddy 自动分类／受管项目消化，需要您在官方页面完成一次新的独立后台 CLI 登录授权。无需提供密码或 Token，不复制桌面凭据，不修改安全设置。授权完成后再在 R9 内点击该学生的“检测当前学生 Agent 授权”。

通过标准：合成检测通过；明确项目测试资料可生成建议；敏感、冲突或无明确项目资料仍转人工；Agent 不直接写目录。若再次出现“账号不存在”“系统码错误”或登录页异常，只记录厂商认证失败，不反复降低限制重试。

## C. 学生资料整理业务验收

1. 分别为 Codex、WorkBuddy 学生选择一个测试来源目录。
2. 放入明确项目、仅主题相似、两项目冲突、敏感资料和无关资料各一份。
3. 核对可信项自动投递、其余项待确认，且跨学生自动投递为 0。
4. 纠正一项推荐并确认后续不会被 Agent 覆盖；已被引用的旧资料保留并显示关联变化。
5. 以至少 5 名代表用户、每人 30 份等难度资料，对比原手动流程，计入纠正时间。

## D. 课程与卡片阶段一真机验收

1. 使用两台已配对的 Windows 学生端，分别登录不同学生，验证课程／卡片可见范围不串学生。
2. 发布课程与卡片新版本，验证已开始内容固定旧版本，新开始内容使用新版本。
3. 撤回资源后，验证新用户不可开始、历史作答与反馈仍可查。
4. 生成一张真实学习卡片，人工核对题目、提示、公式、答案、解析和学情依据；再进行一次真实打印／PDF 输出。
5. 当前 EXE 未签名；如要正式交付，还需代码签名与安装信誉验收。

## E. 目标机稳定性与业务质量

- 四核／8GB／SSD 目标机：10,000 文件增量扫描、10,000 任务翻页、后台分类／卡片生成并行时，前台交互 P95 和劣化比例。
- 四小时混合运行：队列清空后内存、句柄、计时器和子进程不持续增长；宿主、提取进程、外部 Agent 分开记录。
- 固定 200 份独立标注资料：首选建议准确率、自动投递准确率、自动覆盖率、待确认率及跨学生误投；规则构建集与验收集分离。
- 休眠补扫、权限撤销、源文件写入中、磁盘不足、崩溃恢复、重复回执和未知执行的目标机复核。

除 B 项新的 WorkBuddy 官方后台登录外，目前没有需要您立即操作的开发阻塞。其余可在决定是否把 R9 提升为正式候选时集中验收。
