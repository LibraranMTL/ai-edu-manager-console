# 教育管家档案架构升级说明

版本：Windows 0.6.8

## 升级目标

本次升级采用渐进式方式，把现有学生知识库、资料上传、学情报告和主机 API 保持兼容，同时新增四层能力：

- 文件资产中心：为导入和上传文件建立资产索引、SHA-1 指纹和引用关系。
- 学习项目知识空间：让短期学习项目拥有独立的 LLM Wiki 知识空间。
- 知识贡献申请：项目完成后用 Markdown 贡献报告替代简单文件夹合并。
- Growth Layer：把学情报告升级为成长模型输出，而不是普通摘要文件夹。

## 已实现范围

### 文件资产中心 v1

- Windows 手动导入、平板上传记录、多资料来源导入会同步登记资产。
- 资产记录包含文件名、SHA-1、大小、类型、物理路径、所属学生、引用空间、来源和更新时间。
- Windows 端新增“文件资产中心”高级视图，可按学生、关键词、重复文件筛选。
- 支持扫描历史上传记录和学生原始资料库，为旧文件补建资产索引。

### 学习项目知识空间 v1

- Windows 端新增“学习项目”对象，可绑定学生。
- 创建项目时自动生成用户项目空间和项目知识空间。
- 项目知识空间使用 LLM Wiki schema：项目原始资料库、概念库、实体库、摘要库、问答精华库、综合汇总库、项目报告、知识贡献。
- 可从资产中心选择文件加入项目，建立项目引用并复制到项目原始资料库。
- 项目资料不会自动写入学生主档案。

### 知识贡献申请 v1

- Windows 端可为项目生成 Markdown 形式的“知识贡献申请”。
- 报告包含项目概况、资产清单、建议归档项、成长证据、冲突检查和 Agent 执行指令。
- v1 不自动覆盖学生主档案，由管理员复制给 Agent 或人工确认后执行。

### Growth Layer v1

- Windows 端新增“成长模型”入口。
- 可为学生补建“成长模型”目录，包含 `index.md`、`能力画像.md`、`成长证据.md`、`项目贡献.md`。
- 学情报告模板增加成长证据来源和项目贡献来源字段。
- 后续报告生成优先引用成长模型、综合汇总库和项目贡献记录。

## 兼容策略

- 不改变现有学生 `rootPath`、`rawPath`、`summaryPath`、`agentPath` 含义。
- 不改变平板上传到学生原始资料库的路径。
- 不移动、不删除旧文件。
- 资产中心 v1 使用 JSON 索引，不引入数据库。
- 平板端暂不开放项目管理，只消费学生档案和已发布报告结果。

## 后续增强

- 文件资产中心增加版本管理、引用删除、重复文件处理建议。
- 项目知识贡献从 Markdown 报告升级为可逐项确认的归档界面。
- 支持多学生项目和不同学生的贡献分配。
- 增加 AI 自动识别资产、冲突检测和知识图谱。
- 平板端展示已发布项目贡献和成长报告来源。
