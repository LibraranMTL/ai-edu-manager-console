## 升级步骤

Windows：

1. 关闭旧版 Windows 主机控制台。
2. 备份主机数据。
3. 如涉及目录或数据结构调整，额外备份完整学生资料目录。
4. 下载新版 zip。
5. 解压新版。
6. 启动新版 exe。
7. 检查版本号和主机服务状态。

平板：

1. 下载新版 APK。
2. 安装覆盖。
3. 打开平板终端。
4. 检查版本号。
5. 检查是否仍能连接主机。
6. 测试上传资料和查看档案。

## 回滚方案

如新版出现严重问题：

1. 关闭新版。
2. 恢复上一版安装包。
3. 如涉及数据结构变更，先恢复备份。
4. 暂停将新版上传到正式下载目录。

回滚注意事项：

- 不要删除 `D:\学生资料`。
- 不要删除 app data 下的学生和设备记录，除非已确认有备份。
- 不要覆盖 QClaw / Hohu / Marvis / OpenClaw 的 Agent 设置。
