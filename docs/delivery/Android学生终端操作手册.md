# AI教育管家 Android 学生端操作手册

**适用版本：Android 学生端 0.6.34（versionCode 104）**

**配套主机：Windows 主机端需开启学生终端协作服务；主机缺少新能力时，学生端会明确提示更新主机端。**

## 1. 产品定位与首页

Android 学生端安装在学生使用的平板或手机上，只进入本人学生空间。首页固定提供四个核心入口：

- **搜集上传**：选择文件或图片、拍照、屏幕采集、导入对话和自动投递；
- **主机连接**：发现、扫码或手动连接 Windows 主机，并进入本人学生空间；
- **教育档案**：只读查看主机已经发布的学情报告、成长模型、学情档案、项目资料和规划指导；
- **学习行动**：查看已分配课程、完成学习卡片并查看知识点跟踪。

横屏平板使用侧边导航，竖屏和平板窄屏使用底部导航。顶部状态集中显示当前学生、主机连接状态和待上传数量。点击品牌标题或按返回键，会先回到四项核心操作首页。

档案初始化、项目管理、知识治理、OCR/视觉服务和报告发布仍由 Windows 主机完成。学生端不会自行生成规划结论，也不会把一次作答直接表述为已经掌握。

## 2. 安装、升级与首次连接

1. 安装 `AI-edu-manager-tablet-terminal-0.6.27.apk`。
2. 如果设备已经安装旧版，直接覆盖安装即可；0.6.27 与线上 0.6.26 使用同一证书和包名，会保留连接、学生会话、上传队列和失败原件。
3. Windows 主机进入终端协作或设备管理页面，开启学生终端协作服务。
4. Android 与主机在同一局域网时，可使用“查找附近主机”；也可以扫描连接二维码、粘贴连接信息或手动填写地址。
5. 主机接受连接后，选择个人终端或共享终端。连接失败时可在高级设置中检查手动地址、Tailscale 和连接备份。

学生端保留 LAN → Tailscale 自动回退。首次连接和设备授权完成前，应用不会读取学生档案。

## 3. 个人终端与共享终端

- **个人终端**：首次使用时，在“主机连接”页面下部输入本人学生 ID 或扫码。登录成功后由主机固定绑定；以后启动会自动进入本人空间。
- **共享终端**：每次输入本人学生 ID 或扫码进入。使用结束后点击“退出当前学生”，应用会清除学生会话、页面选择和上一学生缓存。

学生空间始终使用本人学生 ID 或二维码进入，不支持按姓名、年级或学生目录检索。无效 ID、错误校验位和主机中不存在的学生会分别显示提示。

如果个人终端首次绑定时看不到输入框，请先确认主机把设备设为个人终端且尚未绑定学生；已经绑定的个人终端会隐藏输入框并自动进入绑定学生。

## 4. 搜集上传

进入“搜集上传”后，可以使用：

- **选择文件**：支持一次选择多个文件；
- **选择图片**：使用系统多选图片选择器，可以一次选择多张图片；
- **拍照上传**：调用系统相机，拍摄后确认学生和目标；
- **屏幕采集**：经 Android 系统授权后采集学习过程；
- **导入对话**：粘贴对话文字、导入 `.md/.txt/.json` 文件，或导入公开 HTTPS 链接；
- **自动投递文件夹**：个人终端可授权一个长期文件夹，稳定的新文件会进入上传流程。

主动选择或拍照后，先核对当前学生，再选择“学生原始资料库”或当前学生的绑定项目，确认后进入持久上传队列。其他应用分享的文件先进入“分享收件箱”，由学生确认后上传。

### 4.1 导入对话

原“导入智能体对话”功能现在统一显示为“导入对话”：

1. 选择粘贴文字、导入文件或导入公开 HTTPS 链接；
2. 核对原文预览、来源、当前学生和保存目标；
3. 点击确认后发送到主机。

链接预览只允许公开 HTTPS 文本，不访问私网地址，不绕过登录，也不无限重定向。预览本身不会写入档案。提交失败时本机保留同一提交编号，重试不会主动创建重复记录。

### 4.2 分享收件箱

在其他 Android 应用中选中文件，使用系统“分享”并选择 AI教育管家学生端。文件会先复制到设备私有的分享收件箱；如同时附有说明文字，也会保存为文字文件。单次可分享多份文件，保存失败的文件需重新分享。纯文字分享继续进入“导入对话”。

保存完成后，确认当前学生并直接选择学生原始资料库或本人关联项目，点击“确认上传”。如尚未进入学生空间，先输入本人 ID 或扫码；如取消、断网或失败，可在“搜集上传 → 分享收件箱”继续处理。已提交的文件保留本机副本并显示等待或失败状态，主机回执明确确认后才清理副本；可在上传状态中核对结果。删除操作只删除学生端本机副本，不删除来源应用的原文件。

尚未进入学生空间时收到的文件标记为“待确认归属”，登录后需确认属于本人。共享设备上的待确认文件可能被下一位进入学生空间的人看到；使用共享设备时建议先进入本人空间再分享，并及时处理或删除暂存文件。

分享收件箱与自动投递文件夹分开：分享是用户从其他应用主动发送一次；自动投递需要个人终端长期授权文件夹，并按设置持续检查。两者共用可靠暂存和上传机制。

## 5. 上传状态、离线恢复与删除

“搜集上传”下方统一显示等待、上传中、待核对、失败和已确认状态。常见状态包括“正在上传…”“上传完成”和“上传失败，点击重试”。

- 未发送资料可在确认后删除；
- 失败资料保留原件并支持重试；
- 收到主机明确回执后才标记完成；
- 学生 ID、主机代次、上传目标或文件 SHA-256 变化时，会停止自动发送并要求重新确认；
- 断网或重启后，内部暂存和持久上传队列都会恢复，不会因为重复进入页面而重复创建资料。

上传成功不会删除相册、文件管理器或授权文件夹中的原始文件。

## 6. 教育档案

“教育档案”按以下顺序提供只读入口：

1. **学情报告**：在滚动弹窗中查看正文、更新时间、发布状态和离线缓存标记；
2. **成长模型**：点击“查看成长模型”先看摘要，完整成长概览在弹窗中打开，并可查看推荐选题和推荐比赛；
3. **学情档案**：查看主机发布给当前学生的档案资料；
4. **项目资料**：查看当前学生关联项目的公开资料，不混入其他学生或其他项目内容；
5. **规划指导**：只读查看主机返回的升学路径、专业探索和职业发展。

推荐选题、推荐比赛和规划指导全部来自 Windows 主机。学生端不会在本地拼接或生成结论。推荐内容属于候选建议，不代表能力证明、录取保证或比赛结果预测。

未连接、未进入学生空间、无内容、资料变化待刷新和读取失败会分别显示明确状态。项目文件在主机中移动或变化时，学生端会刷新列表，不会继续使用旧条目读取其他来源。

## 7. 学习行动与学习卡片附件

“学习行动”包含：

- **精选课程**：只显示机构启用并分配给当前学生的课程；Android 学生端没有“课程管理”菜单；
- **学习卡片**：查看题目、作答、离线暂存、重试和主机反馈；
- **知识点跟踪**：按学科查看证据数量、最近练习、表现状态、复习优先级和建议复习时间。

在学习卡片中点击“作答”后，可以输入文字，也可以点击“拍照 / 上传图片或文件”：

1. **拍照作答**：调用系统相机拍摄纸面过程；
2. **选择图片**：选择 PNG、JPG 或 JPEG；
3. **选择文件**：选择 PDF、DOCX、TXT 或 Markdown，单个附件最大 10 MiB。

附件会先保存在应用私有草稿目录，并记录大小和 SHA-256。提交前再次核对文件未变化；主机收到后先进行文字提取，图片可进入 OCR 与视觉理解，再与识别文本做一致性核对。识别不清、内容不一致或结果不确定时保留原件并提示核对，不会直接形成掌握结论。

提交失败时保留原件和原提交编号；收到明确回执后才清理本机草稿。退出学生或切换主机后，不会继续展示另一学生或上一主机的作答草稿。

知识点跟踪使用“证据不足、持续练习中、近期证据较稳定、表现波动、建议复习”等边界表述，不把模型分数直接描述为已经掌握或已经遗忘。旧主机没有对应能力时会提示更新主机端。

## 8. 屏幕资料采集

1. 进入学生空间，并可选择一个绑定项目；
2. 选择采集策略和时长；
3. 通过 Android 系统屏幕捕获授权；
4. 采集中可重点截取、暂停、继续和结束；
5. 结束后核对学生和目标，再加入上传队列。

采集开始时固定当前学生和可选项目。采集运行中不能退出学生；结束后也不能把该批截图投递给另一名学生。查看与清理页面只显示当前学生的会话，删除需要确认。

## 9. 自动投递文件夹

自动投递只在个人终端可用：

1. 在系统文件选择器中授权一个目录；
2. 选择当前学生档案或一个绑定项目；
3. 启用自动投递，或点击“立即检查”；
4. 文件稳定后才进入内部暂存和上传确认流程。

同一文件版本和同一目标不会重复入库。失败文件稍后重试，本地原件不删除。切换为共享终端会自动关闭长期文件夹绑定。

## 10. 更多与连接备份

“更多”保留外观、备份、更新、诊断和升级为 Android 单机版等辅助功能。主机连接、终端模式和学生空间入口统一放在“主机连接”页面。

- 导出连接备份：保存主机地址、连接模式和设备身份；
- 导入并连接：用于同一设备重装后的恢复；
- 连接备份不会替代共享终端的学生 ID 登录，也不会包含其他学生资料。

## 11. 学生隔离与隐私边界

- 本地暂存按主机 ID、数据代次和学生 ID 隔离；
- 退出共享学生空间后清除会话和界面选择；
- 学生端不展示完整学生目录，不允许指定其他学生 ID 读取数据；
- 项目资料只读取当前学生已关联项目的公开内容；
- 导入对话只处理用户主动粘贴、选择或分享的内容，不读取其他应用聊天数据库；
- 原始资料、上传失败原件和主机档案不会因升级被覆盖或删除。

## 12. 检查更新

在“更多 → 更新”检查新版本。正式更新清单会提供最新 Android 学生端版本和 APK 地址。覆盖安装前建议保持主机可连接，并确认没有正在进行的屏幕采集或文件上传。

安装完成后核对首页版本号为 `v0.6.27`。如果系统提示签名不一致，请不要卸载旧版；先确认 APK 来自官网，避免因卸载清除本地上传队列和失败草稿。

## 13. 常见问题

### 已连接但没有进入学生

个人终端首次使用时在“主机连接”页面输入本人学生 ID 或扫码；已经绑定的个人终端会自动进入。共享终端每次都需要本人 ID 或二维码。

### 学习行动提示“请更新主机端”

当前 Windows 主机没有提供知识点跟踪、结构化规划或图片视觉评阅等对应能力。更新匹配的 Windows 主机候选或正式版后重新连接。

### 上传按钮没有反应

先确认已经进入学生空间，再检查主机连接、上传目标和系统文件权限。失败资料会保留，可在状态区点击重试。

### 图片或文件作答没有反馈

确认附件不超过 10 MiB、格式受支持且主机具有文字提取或视觉能力。识别不清时主机会保留原件并要求核对，不会伪造答案或学习结论。

### 项目资料显示“资料已变化”

文件可能已经在主机中移动、替换或删除。返回项目资料列表并刷新；不要继续依赖旧缓存条目。

### 截图上传后没有立即出现成长结论

学生端只负责采集和上传。资料仍需由主机完成提取、整理、证据审核和报告发布；上传成功不等于已经掌握。
