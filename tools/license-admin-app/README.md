# AI教育管家授权管理工具

## 0.5.0 自助激活兑换码

新增独立的批量兑换码面板。管理员登录后可生成、登记、查询、暂停批次及作废未兑换码；确认登记成功后可展开交付码、生成二维码或导出 CSV。完整库存先保存在本机加密文件中，服务器只保存摘要。客户输入兑换码即可联网绑定本机并取得 License v3，无需发送设备码。

“生成授权码”和原 License v3 二维码功能继续保留，供离线交付与售后使用。新兑换码的有效期从首次兑换开始计算，兑换截止日另设。Windows 主机绑定数与可连接的学生终端额度分开管理；安卓单机版使用安卓专属码。

本机运维凭据登录仅适用于已经配置 DPAPI 凭据的 Windows 管理用户。管理界面可见备份和监控状态；已签发的离线许可证不会因为暂停批次立即停用。

这是内部 Windows 小应用，用于生成和管理 AI教育管家授权码。该工具不随客户版 Windows 主机控制台发布。

## 功能

- 生成授权码
- 自动保存发码记录
- 复制授权码
- 显示并保存 License v3 二维码，可供 Android 单机版扫码或从相册识别
- 搜索客户、联系方式、订单号、授权码和备注
- 在发码记录中显示并复制目标设备码，可按目标设备码反查授权码
- 发码记录默认折叠完整授权码，点击后展开查看，避免长码占用表格空间
- 修改记录状态：有效、已作废、已过期、已换码
- 导出 CSV
- 导出 JSON
- 打开本机记录目录

## License v3 与二维码

当前工具为 Windows 主机端和 Android 单机版签发设备绑定的 License v3：

```text
AIE3.<Base64URL 授权载荷>.<RSA-SHA256 签名>
```

生成后自动显示二维码，也可以从历史发码记录点击“二维码”。二维码仅编码完整原始 `AIE3...` 激活码；不上传到网络，不包含签发私钥。Android 单机版扫码后仍会校验产品、设备码、数字签名、有效期和学生席位。

## 本地运行

在项目根目录运行：

```powershell
pnpm license-admin:desktop
```

## 打包 Windows 版

在项目根目录运行：

```powershell
pnpm build:license-admin
```

输出位置：

```text
release\license-admin\AI-edu-license-admin-Windows-0.4.3.exe
```

## 记录文件

记录文件保存在当前 Windows 用户的应用数据目录，不保存在项目源码目录。

可在工具右上角点击“打开记录目录”查看。

## 安全注意

- 不要把该工具发给客户。
- 不要把授权记录文件提交到 Git。
- RSA 私钥只保存在受控授权管理电脑，不得复制到客户设备、源码或二维码中。
