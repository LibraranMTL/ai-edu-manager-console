## 2. 本轮已实施

### 2.1 学生索引保护与恢复

`StudentIndexStore` 是新建的可测试索引核心，`StudentIndexRepository` 已实际接入。

- 只有确认索引文件及 AtomicFile 恢复文件均不存在时，才能按首次使用读取空列表。
- JSON 损坏、重复身份、缺失必要身份字段或读取异常均失败关闭；新增、删除和更新不能把异常当成空列表写回。
- 不同仓库实例的读—改—写使用进程内共享锁，避免并发新增丢失其他学生。
- 写入前保存非空、经过校验的上次有效索引快照；恢复必须人工预览和确认。
- 恢复先保存损坏索引原始字节，再替换有效索引。当前索引可读、权限异常、快照为空或快照损坏时拒绝覆盖。
- 启动和页面切换发现异常后进入档案保护界面，不再正常启动本轮后台恢复任务。
- 索引恢复不删除或搬移 SAF 原始资料；快照可能不包含最近一次新增或修改，界面明确提醒。这不是完整资料备份或数据库恢复。

### 2.2 学生规划档案 V2

- 对齐 Windows 字段：出生日期、人工年龄段、当前地区、意向地区、规划路径、目标阶段、规划偏好、兴趣、优势学科、职业方向。
- 从“教育档案 → 更多管理 → 补充规划档案”编辑，全部可选；规划路径使用中文复选项。
- 日期严格校验，按实际生日动态计算年龄，不从年级推断精确年龄。
- 旧字段缺失不自动制造资料；读—改—写保留 Windows 扩展字段和未来未知字段。
- 主动修改规划档案才写入 Schema V2，保留修改前字段快照。没有强制批量升级已有档案。

### 2.3 模型供应商基础与实际业务接入

`ModelProvider`、`CompatibleModelProvider`、`ModelCancellation`、受限 `ModelJsonSchema` 已实现，原有 `OpenAiCompatibleAgentAdapter` 实际委托新供应商层。

- 原有学生消化、对话消化、项目消化、OCR 视觉理解和出版精选已接入回执；学生业务调用固定启动时的学生与任务 ID。项目级和连接测试回执不混入个人学生诊断。
- HTTPS 地址、主机、URL 凭据、查询参数和片段校验；仅本机回环允许 HTTP。
- 接口地址变化必须重新提供密钥，禁止静默沿用旧接口凭据；主动提供新密钥时，不依赖旧密钥能否解密。
- 禁止 HTTP 重定向转发 Authorization；限制响应体大小，使用有界输出和连接/读取超时。
- 记录供应商、模型、区域、思考模式、提示版本、Schema 版本、真实请求 ID、耗时及供应商实际 Token 用量；缺失用量保留未知，不伪装为零或账单。
- 非流式 Qwen 基线显式关闭混合思考；提供 JSON Object 输出及本地 Schema 子集校验。类型、必填、枚举、数组、数值范围和多余字段按声明检查；不支持的 Schema 约束在请求前拒绝。
- 截断、内容过滤、空输出或不符合结构的结果不采用，不自动扩大调用或重试。
- 联网研究只接受供应商 `search_info.search_results` 返回的真实来源；模型正文中的 URL 不构成联网证据。正式研究页面尚未开发。
- 取消会断开连接并阻止提交成功结果；已发送的服务端请求仍可能产生费用，不能承诺取消等于退款。
- 网络异常/超时及跨进程未完成调用标为 `unknown`，不自动重试；目前没有宣称远端幂等查询已经实现。
- 首页有当前学生最近 50 条模型任务诊断。它是诊断入口，不是已经完成整个新任务中心。

采用 JSON Object 加本地校验，是依据当前[百炼结构化输出文档](https://help.aliyun.com/zh/model-studio/qwen-structured-output)的模型支持范围，不能把 Qwen3.6-Flash 一般“支持结构化输出”直接解释为支持原生严格 JSON Schema。搜索来源合同参考[联网搜索文档](https://help.aliyun.com/zh/model-studio/web-search/)，思考参数参考[深度思考文档](https://help.aliyun.com/zh/model-studio/deep-thinking)。文档核对日期：2026-10-01；未据此宣称真实 API 验收通过。

### 2.4 Room 基础

- 新增独立 `education-business-v1.db`，不修改既有协作数据库，不使用破坏性迁移。
- 当前实际使用的是模型调用回执表；已生成并保存 Room Schema V1。
- 文件操作意图表提供准备记录、按学生和旧状态比较后更新、未完成意图查询，供后续跨 SAF/Room 流程使用；尚未把全部文件流程迁移到该表。
- 回执不保存 API Key、完整接口 URL、学生姓名、提示词或回答正文；使用进程会话标识，避免 Activity 重建误把同进程仍运行调用判为中断。
- **旧资料登记、任务 JSON、收藏、作答、云端回执尚未全面迁入 Room；完整备份/恢复也尚未覆盖此新增数据库。不能称存储迁移已经完成。**

### 2.5 项目资料体验与安全整理

- 分类选择读取实际工作空间一级文件夹，排除收件箱、研究暂存、回收站和隐藏控制目录，不再展示固定的全局类别集。
- 自定义目录使用稳定类别 ID；已有默认类别保持兼容 ID；增加其他目录不改变自定义类别身份。
- 扫描到用户已经放入明确目录的文件，登记为 `user_classified / user_directory`，无需再次确认；明确人工选择优先于扫描建议。
- “需整理”和“待消化”独立统计；分类完成但消化未完成，不再因此回到待分类列表。分类目录被删除时保留历史分类并显示异常。
- 项目资料支持文件名和原件路径搜索，保留项目资料、待整理、项目知识、贡献证据四视图。
- 整理先筛出符合安全条件的项目，再截取批次，避免前 50 个不可整理项目导致后续文件一直饥饿。
- 只整理收件箱直属安全普通文件，使用实际类别的目标目录；不覆盖同名文件，不移动代码、网页、CAD 和附件依赖。
- 复制前记录意图，复制后记录检查点；删除源文件前复核源和目标哈希。复制校验异常保留原件与已写入副本。
- 新增“核对中断整理”“撤销最近整理批次”：恢复有歧义时不删除任何副本；撤销只改变物理位置，保留人工分类、知识消化和贡献状态。原位置被占用、字节或登记变化时逐项拒绝。
- 登记写入检查持久化版本，拒绝其他实例更新后的过期覆盖。完整迁移与 SAF 并发运行验收仍待后续和末期真机。
