## 技术实现与复用边界

- `electron/practice-cards.cjs`：沿用原存储与旧客户端接口，扩展默认计划、提交版本、资源引用、索引备份。
- `electron/practice-feedback.cjs`、`practice-files.cjs`、`practice-extract.cjs`：不可变提交/快照/提取/评阅侧文件；原稿保留；校验与知识点应用回执。
- `electron/practice-task-host.cjs`：调用现有任务中心的状态机、取消表和资源准入；卡片评阅并发 1。
- `electron/learning-analytics.cjs`：沿用知识点账本，新增卡片来源与有效版本投影、未知分值、派生缓存及首次写入前备份。
- `electron/practice-rich-text.mjs`、`src/PracticeRichText.tsx`：同一渲染语义，KaTeX 直接依赖且本地打包，不接受卡片中的任意 HTML/脚本。
- `electron/card-resources.cjs`、`card-resource-package.cjs`、`card-package-worker.cjs`：课程能力映射、共享资源和后台资源包处理。复用课程包的 canonicalize、SHA-256 与图片类型判断，而不是引入另一套许可证。
- `src/PracticeCardsPanel.tsx`、`PracticeResourcesPanel.tsx`、`PracticeFilePreview.tsx`：Windows 主机界面，按需加载资源编辑器和 PDF 组件。
- `electron/practice-document.cjs`、`practice-pdf-preview-worker.cjs`：本地 DOCX 预览、原版 PDF/图片输出；大于 20 页或超过渲染限额的原版文件提示另存后使用阅读器打印。

资源包 v1 为有总量、条目数、文件类型和哈希约束的 JSON 容器，扩展名为 `.edu-cardpkg`，不是可执行插件或通用 ZIP。哈希只保证完整性，不能证明“平台官方身份”。机构分配只改变可见范围，开始练习才生成学生实例。下架需通过更新包传播，不能删除别处已导入或已打印的内容。

## 使用边界

1. 目前规范知识点目录仍沿用项目已有数学目录。自动应用要求规范 ID 或明确别名与学科一致；未知显式 ID 不回退猜测，ID/标签矛盾和跨学科别名不入账。没有可靠映射的英语或自定义知识点保留反馈，不伪造映射或掌握度。
2. 常规评阅一次模型调用；质量检查依靠提取覆盖、规则、引用一致性与结构校验，不能消除模型出错。手写复杂公式、图形作品、扫描 PDF 等仍可能转为“需要查看”。
3. 线上推荐目录、网站上传、互联网自动更新、远程教师审核、创作者结算与开放插件社区不在本次版本内。
4. 模板是声明式样式，外部原版是 PDF/图片；不支持上传可执行代码模板或任意 HTML。
5. 修改结构化题干、答案、量规须发布新版本。排版只重新渲染，不新增模型调用。原版文件中的学生姓名需由发布者在发布前去除。

## 备份、降级与数据位置

升级前关闭教育管家，备份真实学生档案目录及应用 userData。userData 使用当前安装实际配置路径，不应盲目套用另一个设备的 AppData 路径。

- 学生卡片：`<学生 AI 管家目录>/practice-cards/`，包含索引、原件、提交、快照、提取及评阅；首次修改保留 `store.before-0.20.1.json`。
- 学习事件：`<学生根目录>/.edu-manager/learning-analytics/`；卡片首次入账前保留 `before-learning-cards-0.20.1/` 及清单。
- 共享卡片：`<应用 userData>/card-resources/`；目录索引首次修改保留 `index/catalog.before-0.20.2.json`，共享内容和资产不覆盖旧版本。

降级先导出要保留的新作答，关闭程序，再恢复与旧版本匹配的整套备份及原版本程序。不要只改版本号或只恢复卡片索引而遗漏知识点账本。自动索引备份不代替整套用户数据备份。
