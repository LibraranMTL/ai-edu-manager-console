# Windows 0.7.19 项目工作空间模板说明

## 本次重点

学习项目新增“项目工作空间模板”。该模板只用于 `项目工作空间` 下的人类项目管理目录，不用于 `项目知识空间`。

## 已完成能力

- 新建学习项目时可选择工作空间模板：
  - 通用学习项目
  - 学科专题
  - 竞赛 / 活动
  - 研究项目
  - 升学申请
- 新建时可手动编辑工作空间文件夹清单。
- 已有学习项目可在详情页重新应用工作空间模板。
- 系统会补建 `项目工作空间` 下缺失的文件夹，并写入 `项目工作空间/工作空间结构.md`。
- `研究暂存` 作为系统级暂存层固定保留，不作为用户模板文件夹覆盖项。

## 重要边界

- 工作空间模板只影响 `项目工作空间`。
- `项目知识空间` 继续固定使用 LLM Wiki schema：
  - 项目原始资料库
  - 概念库
  - 实体库
  - 摘要库
  - 问答精华库
  - 综合汇总库
  - 项目报告
  - 知识贡献
- 应用模板不会移动、删除或覆盖已有项目资料。
- 应用模板不会改变项目知识空间目录结构。

## 验收要点

- 新建项目后，`项目工作空间` 出现所选模板文件夹。
- 新建项目后，`项目知识空间` 仍保持固定 LLM Wiki 目录。
- 已有项目点击“应用到项目工作空间”后，仅补建工作空间目录。
- `项目工作空间/工作空间结构.md` 能清晰说明工作空间与知识空间的边界。
