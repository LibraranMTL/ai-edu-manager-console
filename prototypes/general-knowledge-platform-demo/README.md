# 知域 · 通用知识管家 Demo

更新日期：2026-09-10

性质：方案 C 的独立交互验证版。全部人物、资料、项目、健康和财务记录均为虚构演示数据；本 Demo 不读取 AI 教育管家正式数据，不连接模型 API，也不提供医疗诊断、投资建议或自动交易。

## 运行

在本目录执行：

```powershell
pnpm install
pnpm dev
```

构建静态版本：

```powershell
pnpm build
```

## 推荐演示路径

1. 在“总览”切换教育、项目、健康和财务领域，观察同一份核心档案如何呈现不同领域视图。
2. 打开“用户档案”，查看 `Profile → Student` 的兼容映射和 Agent 授权边界。
3. 在“采集收件箱”导入一种虚构资料，确认资料只进入处理队列，不自动发布结论。
4. 在“Agent 知识”生成一次性上下文，查看明确允许和排除的范围，并生成带引用回答。
5. 在“任务中心”创建要求完成证据的闭环任务。
6. 在“领域扩展”停用、重新启用扩展，验证底层资料不被删除。
7. 在“专家数据工作室”补充授权记录，再导出演示 JSON 数据包。

## Demo 边界

- Agent 连接、资料解析、哈希同步和知识推理均为前端模拟。
- “Codex 已连接”用于表现当前适配器形态，不代表本页面正在调用真实 Codex 会话。
- 教育兼容映射遵循“登记接管、原地兼容、按需迁移”，但本 Demo 不迁移任何真实学生资料。
- 导出的 JSON 只包含虚构对象标识和结构，不包含原始资料内容。
