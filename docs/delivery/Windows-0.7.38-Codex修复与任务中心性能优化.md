# Windows 0.7.38：Codex 修复与任务中心性能优化

## Codex CLI 修复

- 移除本机 `config.toml` 中新版 Codex CLI 已不支持的 `service_tier = "default"`。
- Codex 授权检测继续同时核对退出状态和错误文本，避免 CLI 输出配置错误但返回成功退出码时产生误判。

## 性能优化

- Agent 能力检测由 Electron 主线程同步串行调用改为后台异步并行刷新，缓存有效期延长至五分钟。
- OpenClaw Cron 同步改为异步单飞，十分钟内不重复读取；自动化关闭时不执行外部探测。
- 可执行文件、安装目录和卸载注册表结果采用十分钟缓存，并优先检查版本目录，避免深度递归扫描。
- 任务中心刷新周期由五秒调整为十五秒；候选任务内容未变化时不再重写任务仓库。
- Agent 安装状态改为进入新建智能体或设置页面时按需读取。

## 全局执行模式

任务中心新增 `自动运行 / 仅手动` 开关。

- 自动运行：按原有计划执行扫描、增量任务、Cron 同步和 Agent 调度。
- 仅手动：停止后续自动扫描、调度、Cron 同步和后台 Agent 探测；已经启动的任务不会被强制中断，用户仍可手动执行、审核和导入结果。

## 验证

- Codex CLI：`Logged in using ChatGPT`。
- 自动化测试覆盖非阻塞能力检测、Cron 节流和全局仅手动模式。
- Electron 实测任务中心刷新响应约 32–79 ms，无横向溢出。
