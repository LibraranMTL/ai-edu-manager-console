AI教育管家隐私政策

特别提示：AI教育管家主要采用 Windows 主机本地部署 + 平板终端连接主机的方式运行。默认情况下，学生学习资料和学情档案保存在用户本机或用户指定目录。请您在使用前仔细阅读本政策，了解我们如何处理与保护您的个人信息和学生学习资料。

一、适用范围

本隐私政策适用于 AI教育管家主机控制台、AI教育管家平板终端、主机服务、设备配对、资料上传、档案浏览、软件更新、客户支持以及相关配套服务。

本政策与《AI教育管家用户协议》共同适用。用户协议页面：https://www.greatbg.com/download/agreement.html。

三、信息保存位置

Windows 主机控制台默认将学生资料保存在用户本机目录，例如用户配置的学生资料根目录。平板终端通过用户授权连接 Windows 主机服务，上传资料会写入对应学生的原始资料库。

除用户主动配置远程连接、授权服务、在线支付、客户支持或云端功能外，学习资料和学情档案默认不上传到服务提供方服务器。

四、我们如何使用信息

我们会在实现以下目的所需范围内处理信息：

  • 创建、接管和管理学生知识库；
  • 完成平板终端与 Windows 主机配对；
  • 上传学习资料、查看学情档案、复制咨询或消化提示；
  • 记录设备授权范围、撤销设备访问权限；
  • 完成软件授权、版本更新、故障排查和客户支持；
  • 履行法律法规、监管要求或争议解决所需义务。

五、我们如何共享或委托处理信息

我们不会出售您的个人信息。为实现支付、软件更新、客户服务、消息联系或远程连接等功能，可能需要使用支付宝、微信支付、企业微信、QQ、Tailscale、浏览器、文件管理器、相机、QClaw、Hohu、OpenClaw、Marvis 等第三方服务。

第三方服务由相应主体提供，并适用其隐私政策和服务条款。您在使用第三方服务前，应自行阅读并确认相关规则。

六、未成年人信息保护

本软件面向家庭教育和学习资料管理场景，可能处理未成年学生学习资料。监护人或教育服务人员应仅上传实现学习管理目的所需资料，并避免上传身份证件、精确住址、医疗记录、无关照片、无关聊天记录等与学习管理无关的敏感信息。

如您是未成年人，请在监护人指导下使用本软件。监护人有权要求查询、更正、删除或限制处理与未成年人有关的信息。

七、信息安全

我们会采取合理的技术和管理措施保护软件运行所涉及的信息安全，包括本地目录隔离、设备 token、访问范围控制、撤销设备授权、错误提示和诊断机制等。

由于本软件包含本机部署和局域网连接能力，用户也应妥善维护电脑、平板、网络、防火墙、远程访问工具、第三方账号和备份介质的安全。

八、您的权利

在法律法规允许范围内，您可以对自己的个人信息行使查询、复制、更正、补充、删除、撤回同意、注销授权、限制处理和解释说明等权利。

对于本地保存的学生资料，您可以通过 Windows 主机控制台、文件系统、设备管理或联系我们协助处理。请注意，删除本机资料可能影响学情档案展示、资料消化和历史记录。

九、信息保存期限

学生资料、学情档案、设备授权和上传记录默认由用户在本机或指定目录自行管理。我们仅在实现本政策所述目的所必需的期限内保存由我们实际收集的信息，法律法规另有规定或为处理争议所必需的除外。

十、政策更新

我们可能根据功能变化、商业模式、法律法规或安全要求更新本隐私政策。更新后的政策将在软件、官网或下载目录中公布。若您在政策更新后继续使用本软件，即表示您接受更新内容。
