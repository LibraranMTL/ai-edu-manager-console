# AI教育管家平板终端家长版操作手册

适用版本：AI教育管家平板终端 0.5.1  
配套版本：Windows 主机控制台 0.6.6  
适用对象：家长、学生  
应用包名：`com.qxmatrix.eduterminal`

## 1. 平板终端能做什么

AI教育管家平板终端是面向家长和学生的客户版应用，主要用于：

- 连接 Windows 主机
- 上传学习资料到主机
- 查看学情档案
- 联系教育管家
- 查看连接状态
- 检查版本更新

平板终端不会显示初始化、Agent 创建、QClaw 配置、目录管理、许可证发码等管理员功能。

平板终端跟随 Windows 主机授权状态，不单独收费。Windows 主机未激活或许可证过期时，平板端可能无法刷新学生、上传资料或读取主机档案；请联系教育顾问或装机人员在 Windows 主机端完成许可证激活。

## 2. 安装

使用 APK：

```text
AI-edu-manager-tablet-terminal-0.5.1.apk
```

安装步骤：

1. 在平板或手机上打开 APK。
2. 如系统提示“允许安装未知来源应用”，请选择允许。
3. 安装完成后打开“AI教育管家平板终端”。

平板终端和旧 Android 控制台是不同应用，可同时安装，不会互相覆盖。

## 3. 首次连接主机

首次使用需要连接 Windows 主机。

请先确认：

- Windows 主机控制台已打开。
- Windows 端选择“主机-平板模式”。
- Windows 主机服务已启动。
- 平板和 Windows 电脑在同一网络下，或已配置 Tailscale 远程连接。

连接方式：

1. 在平板首页点击“扫码绑定主机”。
2. 扫描 Windows 主机控制台显示的二维码。
3. 如扫码不方便，可点击“粘贴连接信息”，粘贴 Windows 端复制的配对内容。
4. 绑定成功后，平板会读取可访问学生列表。

技术连接区域默认折叠。如需查看主机服务地址、连接主机、扫码绑定主机等信息，可点击展开。

## 4. 选择学生

绑定主机后，平板会显示当前设备可访问的学生。

如果有多个学生，请先选择当前要上传资料或查看档案的学生。

如果学生列表为空，请联系装机人员或教育顾问，在 Windows 主机端为该平板授权学生范围。

## 5. 上传资料到主机

进入“上传资料到主机”。

支持上传：

- 拍照上传
- 图片
- PDF
- Word
- Excel
- PPT
- TXT
- Markdown
- Downloads 最近文件
- 从文件管理器分享来的资料

上传后，资料会进入该学生在 Windows 主机上的原始资料库，并显示在上传记录和待消化状态中。

## 6. 拍照上传

适合上传：

- 作业
- 试卷
- 错题
- 课堂笔记
- 证书
- 老师评语

建议拍摄时：

- 光线充足
- 保持纸张完整
- 避免反光
- 一页一张图

如果某些平板无法直接调起相机，可先用系统相机拍照，再从相册或文件管理器分享给平板终端。

## 7. 文件管理器分享上传

这是兼容性最好的上传方式之一。

操作步骤：

1. 打开系统文件管理器。
2. 找到图片、PDF 或文档。
3. 点击“分享”。
4. 选择“AI教育管家平板终端”。
5. 回到平板终端选择学生并上传。

## 8. 查看学情档案

进入“查看学情档案”。

档案按分类展示：

- 资料摘要
- 综合汇总
- 问答精华
- 其他
- 全部文件

文档列表采用可滚动下拉方式，适合文档数量较多的场景。选择文档后，可以在内置 Markdown 阅读器中查看正文。

阅读器支持：

- 阅读模式
- 原文模式
- 字号调节
- 标题、列表、引用、代码和基础表格渲染
- 已缓存文档的离线阅读

如果离线时能看到文件列表但正文为空，请联网刷新一次目标文档，缓存成功后即可离线查看。

## 9. 打开 Obsidian

“学情档案”模块提供“打开 Obsidian”入口。

点击后会优先尝试打开本机 Obsidian App。若未安装，会提示并提供下载入口：

```text
https://obsidian.md/download
```

Obsidian 是高级查看工具，不影响平板终端内置 Markdown 阅读器。

## 10. 联系教育管家

进入“联系教育管家”后，平板会根据 Windows 主机端设置显示联系入口，例如：

- 打开企业微信
- 打开 QQ
- 打开 QClaw
- 打开 Marvis
- 复制咨询提示
- 复制消化提示

如绑定渠道为 QQ，下方提示应显示“请在 QQ 中联系 AI教育管家”；如绑定渠道为企业微信，应显示“请在企业微信中联系 AI教育管家”。

## 11. 连接状态

“连接状态”中可查看：

- 当前主机地址
- 当前连接模式
- 授权学生数量
- 最近连接成功时间
- 设备诊断信息

连接模式包括：

- 仅局域网
- 局域网 + Tailscale
- 手动输入远程主机地址

平板扫码后会优先尝试局域网地址，失败后再按设置尝试 Tailscale 地址或手动地址。

## 12. Tailscale

如果需要跨网络访问 Windows 主机，可使用 Tailscale。

系统设置中提供：

- 下载 Tailscale
- 打开 Tailscale
- 检查是否安装 Tailscale

Android 版 Tailscale 下载地址：

```text
https://www.greatbg.com/download/tailscalev1.88.1_nbwe_7273.com.apk
```

## 13. 版本检查与更新

进入“系统设置”，点击“检查更新”。

平板终端会读取：

```text
https://www.greatbg.com/download/edu-manager-version.json
```

如发现新版本，会下载或打开对应 APK 下载地址。平板终端只会升级为平板终端版，不会升级成装机人员使用的旧 Android 控制台。

## 14. 用户协议与隐私政策

系统设置中提供：

- 用户协议：https://www.greatbg.com/download/agreement.html
- 隐私政策：https://www.greatbg.com/download/privacy.html

## 15. 常见问题

### 看不到学生

请联系教育顾问或装机人员，在 Windows 主机端为该平板授权学生范围。

### 上传失败

请检查：

- 是否已选择学生
- Windows 主机是否开机
- 主机服务是否启动
- Windows 主机许可证是否已激活
- 平板网络是否正常
- 文件是否过大或格式异常

### 扫码失败

可改用“粘贴连接信息”：

1. Windows 主机端复制扫码配对内容。
2. 发送到平板。
3. 平板点击“粘贴连接信息”。

### 打不开企业微信、QQ、QClaw 或 Marvis

请确认平板已安装对应 App，并且可以从桌面正常打开。
