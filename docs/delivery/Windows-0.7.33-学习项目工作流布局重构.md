# Windows 0.7.33 学习项目工作流布局重构

## 本次调整

- 将单个项目详情重排为“项目概况 → 资料入口 → 暂存治理 → Agent 消化 → 知识审核 → 贡献归档”的线性工作流。
- 增加五步工作流导航，点击步骤可定位到对应操作板块。
- 精简项目顶部工具栏，只保留编辑、复制、重新定位、导出和移除记录等项目管理操作。
- 将项目根目录、工作空间和原始资料库合并到紧凑的项目概况区，并继续支持点击打开目录。
- 将组合仪表盘和跨项目知识审计放到单个项目工作流之后，避免打断当前项目操作。
- 将元数据、参与学生和独立成长证据移到主流程之后，让五步导航紧跟项目概况显示。
- 为窄窗口增加两列和单列工作流布局，减少横向拥挤和缩放需求。

## 工作流顺序

1. 工作空间与资料入口
2. 研究暂存、治理与资产晋升
3. 人工 Agent 消化
4. 项目知识资产审核
5. 知识贡献与项目归档

## 验证重点

- 五步导航能够定位并滚动到对应板块。
- 项目详情在桌面和窄窗口下均可完整阅读。
- 项目组合仪表盘不会遮挡或打断单个项目主流程。
- 首页版本显示为 `0.7.33`。
