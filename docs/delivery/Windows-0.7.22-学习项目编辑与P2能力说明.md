# Windows 0.7.22 学习项目编辑与 P2 能力说明

## 本次交付

- 项目编辑：修改名称、类型、说明、目标、知识策略和成长策略；不重命名、不移动任何物理目录。
- 移除项目记录：只从教育管家项目索引移除，并在项目管理目录写入移除快照；工作空间、知识空间、资产和审计文件全部保留。
- 项目复制：复用工作空间模板、绑定学生和知识/成长策略；不复制资料、资产、知识内容、成长证据或历史贡献。
- 多学生项目：共享同一项目知识空间，为每位学生单独维护能力维度和观察；同时登记到该学生 Growth Layer 的成长证据候选。
- 跨项目知识关联：对多个项目中的概念、实体和能力证据建立统一索引，不改写原知识文件。
- 增量消化自动化：支持工作空间新增资料、项目阶段变化和定时检查三类触发。
- 项目仪表盘：汇总待治理资料、待审核知识、待发布贡献、自动化状态和风险提醒。

## 安全边界

1. 项目显示名称与物理存储名称分离，编辑项目不会改变 `projectRootPath`、`workspacePath` 或 `knowledgeRootPath`。
2. “移除项目记录”不是彻底删除。系统不提供从该入口递归删除项目目录的能力。
3. 项目复制只复制结构和策略，新项目以草稿状态创建，自动化默认关闭。
4. 跨项目关联只生成索引，不合并或覆盖概念、实体和证据原件。
5. 自动化只扫描并标记待增量消化，不绕过人工知识审核和贡献发布确认。

## 验收要点

- 编辑项目名称后，三个项目物理路径保持原值。
- 移除项目记录后，项目不再显示于列表，但项目根目录及其全部文件仍存在。
- 复制项目后，新项目资料数、资产数、成长证据和贡献历史均为零。
- 多学生项目可分别保存不同能力观察，并可在对应学生成长证据审核中看到候选项。
- 仪表盘数据可随项目扫描、知识审核和贡献状态刷新。
- 自动化规则启用后，可显示下次检查时间；资料新增、阶段变化或定时到期会产生待消化状态。
