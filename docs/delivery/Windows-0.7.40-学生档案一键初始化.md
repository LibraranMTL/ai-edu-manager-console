# Windows 0.7.40：学生档案一键初始化

## 主要调整

- “保存学生档案”升级为“保存学生档案并初始化”，作为新建教育管家的唯一初始化入口。
- 单次操作自动创建知识库目录、`AGENT.md`、知识目录、索引、日志和基础学情报告。
- 初始化失败时不再保存一条无法使用的学生档案记录，并在当前页面显示失败原因。
- 移除右侧重复的“创建知识库目录、写入 AGENT.md、执行 AGENT.md”操作。
- 右侧调整为“Agent 工具连接（可选）”，仅保留创建 Agent、角色、记忆及任务方式配置。
- 完整连接指令明确禁止重新创建目录、覆盖 `AGENT.md` 或移动已有资料。

## 验证

- 自动化测试：28 项通过。
- Windows 生产构建：通过。
- 页面验证：重复步骤不可见，可选步骤从 1 开始编号，高级连接指令可正常展开。

Android 平板终端版本保持 `0.5.2`。
