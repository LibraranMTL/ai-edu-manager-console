# Windows 0.7.30 首页版本与研究暂存滚动修复

## 修复内容

- 首页当前版本由构建配置从 `package.json` 自动注入，不再在界面代码中硬编码。
- Windows 更新检查使用的当前版本码由发布清单自动注入。
- 研究暂存层增加独立纵向滚动区域和右侧滚动条。
- 修复项目详情 Flex 子面板被压缩、后续面板覆盖暂存操作区的问题。
- 暂存操作按钮根据面板宽度自动换行，窄窗口下仍可完整查看和点击。

## 验证要求

- 首页显示 `v0.7.30`。
- 研究暂存层高度受控，右侧滚动条可见。
- 鼠标滚轮可在暂存层内上下滚动。
- 暂存层与项目知识资产审核面板不重叠。
