# Windows 0.7.45 资料消化同步修复

## 修复内容

- 修复同步上传记录时覆盖 Agent `digest-state.json` 完成回执的问题。
- 修复执行消化并标记提交后，“待消化资料”数量保持不变的问题。
- 将资料状态拆分为“待提交消化”和“等待 Agent 回执”，避免混淆。
- 同步消化结果后立即刷新学生资料计数、最近消化时间和状态说明。
- 标记已提交时只处理真正处于待消化状态的资料，不再误改失败、忽略或历史资料。

## 正确操作流程

1. 复制并在所选 Agent 工具中执行资料消化指令。
2. 在控制台点击“标记已提交”，资料从“待提交消化”转入“等待 Agent 回执”。
3. Agent 完成后更新知识库中的 `.edu-manager/digest-state.json`。
4. 点击“同步消化结果”，完成回执匹配的资料转为已处理。

若 Agent 尚未写回完成回执，控制台会保留“等待 Agent 回执”状态并显示检查提示，不会错误地把资料标记为已处理。
