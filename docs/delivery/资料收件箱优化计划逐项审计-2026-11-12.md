# 资料收件箱优化计划逐项审计

审计范围：`release/20261107-clients-cloud` 工作树和 R15 包；源码存在未提交修改。以下“已实现”表示发现相应代码，不等于全部真实场景已验收。真实资料处理、正式发布均不在本次审计内。

| 计划项 | 实现与证据 | 尚需验证或缺口 |
| --- | --- | --- |
| 会话来源 Agent、类型、工作区、仓库及学生范围 | `smart-inbox-conversation.cjs` 读取结构化字段并保留冲突；相关会话测试存在 | 各 Agent 实际采集字段的覆盖率尚未评估；未知字段仍需保持未知 |
| 系统、混合会话识别及可恢复忽略 | 会话识别与用户规则入口存在；`smart-inbox.test.cjs` 覆盖系统会话和恢复 | 独立标注集上的识别准确率未测 |
| 按资料核验学生及冲突 | 会话学生冲突和确认、跨学生隔离测试存在 | 真实多学生混合资料仍需经授权样本验收 |
| 项目轻量召回、详细上下文最多五项 | `selectRoutingCandidates`、两级上下文和大上下文测试存在 | 全授权项目覆盖、长文和实际项目相似度需更多独立样本验证 |
| 学生原始库独立候选 | `automaticTarget` 包含学生目标策略及正文证据检查 | 面向真实学习资料的准确率尚未评测 |
| 高可信投递、冲突保留确认 | 版本化策略、证据、指纹和冲突检查；R14 IPC 验收与 R15 合成 Agent 评测 | R15 多样本正式 IPC 验收另行记录；模型弱候选仍可能出现 |
| 去除产品敏感字段阻断 | 旧字段兼容测试、关键词普通路由测试、外部拒绝不伪造成功测试存在 | 外部 Agent 的拒绝仍由其自身决定 |
| 规则管理、版本、命中、试算 | 规则条件与审计、只读试算和分页确认入口已实现并有测试 | 条件组合覆盖、真实场景规则管理可用性待更大范围验收 |
| 规则建议和反馈 | `ruleSuggestions` 按人工反馈构造默认停用建议，界面提供查看与试算 | 学生更正与来源效果统计的完整闭环及各项覆盖需专项核查，不能认定全部已完成 |
| 同学生同目标指纹去重 | SQLite 指纹索引与回执复用、来源关联测试存在 | 真实数据迁移及长期运行需验收 |
| 执行意图、回执核对与恢复 | 持久化执行阶段、未知执行隔离、回执核验与恢复测试存在 | 历史未知执行需要逐条核对；不能盲目重发 |
| 原因分组和可操作界面 | 原因码与分组、候选和核对入口存在；自动化测试覆盖 | 并非所有历史中文报错均已证明转换为稳定原因码 |
| SQLite 索引及迁移 | SQLite 查询/指纹索引，JSON 账本保留；旧设置和特定数据迁移有备份及测试 | 不应宣称完整可校验、可回退迁移已经覆盖所有历史版本，需专项故障注入 |
| 有界批次、来源轮转 | `smart-inbox.cjs` 包含来源轮转和有界处理 | 大规模真实混合负载交互延迟仍需测量 |
| 历史积压试算 | 只读试算和确认后重新核验代码、测试存在 | 本次未重新读取真实积压；正式处理必须先展示当前试算并由用户确认 |
| 准确率与性能 | R15 对 24 条合成资料进行真实 Agent 分类；10,000 条基准脚本存在 | 合成样本非独立标注集；独立 Top-5、误投率、纠正率及当前候选完整性能报告未核实 |
| 候选打包和发布 | R15 包内探针、真实 Agent 单项投递和 125 项定向回归通过 | R15 尚未签名、安装或发布；完整主机和真实资料验收不能由合成测试替代 |

主要依据：`electron/smart-inbox*.cjs`、`src/SmartInboxPanel.tsx`、`tests/smart-inbox*.test.cjs`、`scripts/benchmark-smart-inbox.cjs`、R13–R15 候选验收记录。此审计未对工作树进行清理或提交。
