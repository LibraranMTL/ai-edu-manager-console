# Android 单机版：人工审核与行动跟踪开发记录

继续执行 Windows 0.19.3 架构对齐修订计划。日期：2026-10-02。Android 版本保持 1.2.8 / 32。本批为源码开发，不将原计划整体标为完成。

## 本批补齐

1. 学习与规划入口新增审核、行动、进度、忽略列表。各类型列表支持文字筛选，查询在数据库分页前执行；每页最多50项，学生作用域固定。
2. 文字或文件作答可人工审核，记录本次基本正确、部分正确、需要修改或无法判断，以及审核人和具体依据。原作答与题目快照不覆盖；更正追加新审核。审核身份是本机填写，未经认证，不自动产生掌握结论或正式成长证据。
3. 人工审核可回流到下一次练习生成。默认不发送，只有用户主动勾选才加入实际发送预览；仅选取与当前所选资料 ID 和内容哈希相符的审核，取最近100条中的最多10次作答观察，各次采用最新审核。摘要不包含审核人、原作答或附件，继续执行去标识；具体备注仍需用户检查，不能保证自动去标识完全覆盖。
4. 回流只用于练习，不自动用于规划诊断。输入快照包含审核摘要，生成前重新计算指纹；预览后审核或资料变化会要求重新预览。自动练习仍默认不发送审核记录。
5. 非练习建议可以采纳为行动，保持原候选完整快照。支持待开展、进行中、自报完成、暂停；每次进度和结果说明保存独立事件，不覆盖历史。完成只是本机自报，不自动报名、创建项目、确认正式成果或成长证据。
6. 已忽略建议可查看、恢复，并可在原版本中重新采纳。恢复不删除原建议或选择记录；目前不是逐次忽略/恢复的完整事件审计。
7. 审核、行动快照和进度事件纳入现有 Room V3 备份；恢复验证指纹，设备路径重映射不会改写历史快照。未新增第二套业务数据库。

## 数据与风险边界

- 审核以原作答指纹校验，学生不符或作答变化拒绝保存。操作键相同且内容相同复用，内容冲突拒绝。
- 行动推进在事务中比较旧状态，再写独立事件与新状态；旧界面不能覆盖已变化进度，同一操作重放不生成重复事件。
- 审核和行动没有真实身份认证、正式证据核验或自动掌握计算。未来正式成长证据仍需走已有审核流程。
- 本批没有完成全采集入口 Room 权威状态迁移、正式许可证/设备证明网关、全系统权益与额度、能力检测及性能/无障碍收尾。
