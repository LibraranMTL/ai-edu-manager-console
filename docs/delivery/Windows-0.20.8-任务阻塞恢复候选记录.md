# Windows 0.20.8 任务阻塞恢复候选记录

日期：2026-10-10。

## 修复范围

- 候选任务刷新不再覆盖运行中、等待结果或已经绑定执行批次的运行态，避免任务被重新显示为未开始。
- 启动恢复会清除尚未真正启动任务中的陈旧执行标识；手工等待不再按 Agent 心跳误判超时，已取消任务归入完成历史。
- Codex 学情报告改为无工具、只读生成，宿主校验固定标记、学生身份、输入指纹和必需章节后再写入；Codex 任务串行执行，避免多个窗口/会话争用。
- WorkBuddy 桌面交接明确区分“已预填、待用户发送”和“已领取执行”。WorkBuddy 任务不需要人工复制粘贴，但当前桌面通道仍需要用户在 WorkBuddy 中确认发送。
- 规划研究调度会在每轮调度前刷新当前 Agent 能力；只恢复明确由研究能力缺失造成的阻塞，不重试普通终态失败。
- 受控工作区的遗留 QClaw 项目资料任务迁移到 Codex；普通项目继续尊重任务已经选择的 Codex 或 WorkBuddy。QClaw 只保留历史读取和兼容入口。
