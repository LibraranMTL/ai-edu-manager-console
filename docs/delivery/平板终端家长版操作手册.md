# AI教育管家平板终端家长版操作手册

适用版本：平板终端 0.4.3  
适用对象：家长、学生  
配套主机：Windows 主机控制台 0.4.5 或更新版本

## 1. 平板终端能做什么

AI教育管家平板终端用于日常使用，主要功能是：

- 连接 Windows 主机
- 上传学习资料到主机
- 查看已经整理好的学情档案
- 联系 AI教育管家
- 查看连接状态
- 检查版本更新

平板终端不会显示初始化、Agent、QClaw、Obsidian、目录设置等管理员功能。

## 2. 安装平板终端

1. 下载 APK：
   - `AI-edu-manager-tablet-terminal-0.4.3.apk`
2. 在平板上打开 APK
3. 如系统提示“是否允许安装未知来源应用”，选择允许
4. 安装完成后打开：
   - `AI教育管家平板终端`

## 3. 首次连接主机

首次使用需要连接 Windows 主机。

请确认：

- Windows 主机控制台已打开
- Windows 主机已切换到“主机-平板模式”
- Windows 主机服务已启动
- 平板和 Windows 电脑在同一个网络下，或已配置 Tailscale 远程连接

连接方式：

1. 在平板首页点击“扫码绑定主机”
2. 扫描 Windows 主机控制台显示的二维码
3. 如扫码不方便，可点击“粘贴连接信息”，粘贴 Windows 端复制的扫码内容
4. 绑定成功后，平板会自动读取可访问学生列表

绑定成功后，平板会保存主机地址和设备 token，日常使用不需要重复扫码。

## 4. 选择学生

绑定主机后，平板会显示可访问学生。

如果有多个学生，请先选择当前要操作的学生。

如果列表为空，请联系装机人员或教育顾问在 Windows 主机端授权学生访问范围。

## 5. 上传资料到主机

进入“上传学习资料”或点击首页“上传资料到主机”。

可上传的资料包括：

- 拍照上传
- 图片
- PDF
- Word
- Excel
- PPT
- TXT
- Markdown
- Downloads 最近文件
- 从文件管理器分享来的资料

上传后，资料会进入该学生的原始资料库，由 AI教育管家后续整理。

## 6. 拍照上传

适合上传：

- 作业
- 试卷
- 课堂笔记
- 证书
- 评语
- 错题

操作：

1. 选择学生
2. 点击“上传资料到主机”
3. 选择“拍照上传”
4. 拍摄资料
5. 确认上传

拍照时建议：

- 光线充足
- 纸张边缘完整
- 避免反光
- 一页一张图

## 7. 从文件管理器分享资料

如果平板系统文件选择器不可用，可以使用分享方式：

1. 打开平板文件管理器
2. 找到图片、PDF 或文档
3. 点击“分享”
4. 选择“AI教育管家平板终端”
5. 回到平板终端选择学生并上传

这是兼容性最好的上传方式之一。

## 8. 查看学情档案

进入“查看学情档案”。

档案按分类显示：

- 资料摘要
- 综合汇总
- 问答精华
- 其他
- 全部文件

点击文件名即可查看 Markdown 正文。

如果离线，平板会尽量显示最近缓存的文件列表和正文；如果正文没有缓存，请联网后刷新。

## 9. 联系教育管家

进入“联系教育管家”。

根据 Windows 主机端绑定信息，平板可能显示：

- 打开企业微信
- 打开 QQ
- 复制咨询提示
- 复制消化提示

咨询前可点击“复制咨询提示”，再粘贴到企业微信或 QQ 中。

## 10. 连接状态

进入“连接状态”可查看：

- 当前主机地址
- 当前连接模式
- 授权学生数量
- 最近连接成功时间
- 设备诊断信息

如果连接失败，请优先检查：

- Windows 主机服务是否启动
- 平板和电脑是否在同一网络
- 主机 IP 是否变化
- 是否需要重新扫码绑定

## 11. 远程连接模式

平板支持：

- 仅局域网
- 局域网 + Tailscale
- 手动输入远程主机地址

一般家庭或学校同一 Wi-Fi 下，使用“仅局域网”即可。

如果需要外网访问，请由装机人员配置 Tailscale 或远程主机地址。

## 12. 检查更新

进入“系统设置”，点击“检查更新”。

如发现新版，平板会打开下载地址。下载安装后即可覆盖升级。

注意：

- 平板终端只会升级为平板终端版
- 不会升级成装机人员使用的旧 Android 控制台

## 13. 常见问题

### 看不到学生

请联系教育顾问检查 Windows 主机端设备授权。

### 上传失败

检查：

- 是否已选择学生
- Windows 主机是否开机
- 主机服务是否启动
- 平板网络是否正常
- 文件是否过大或格式异常

### 扫码失败

可以改用“粘贴连接信息”：

1. Windows 主机端复制扫码内容
2. 发到平板
3. 平板点击“粘贴连接信息”

### 打不开企业微信或 QQ

请确认平板已安装对应 App，并且可以从桌面正常打开。

## 14. 家长使用建议

建议上传以下资料：

- 每周作业
- 阶段测验
- 错题
- 老师评语
- 竞赛证书
- 课堂笔记
- 家校沟通记录
- 家长观察记录

资料越连续，AI教育管家越容易形成稳定的学情判断。
