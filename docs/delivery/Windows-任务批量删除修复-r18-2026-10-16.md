# Windows 统一任务队列批量治理 R18 候选验收

## 交付结论

R18 已修复“看似无法批量删除任务”的问题，并把处理方式扩展为适用于后续积压的一般性治理能力：用户可以选择当前筛选条件命中的全部任务，由主机一次预检并只删除可安全清理的记录；执行中、等待结果、审核中和外部结果未知的任务会被自动跳过。

本次没有对现有任务账本执行删除。2026-10-16 只读复核时共 227 项，其中 220 项满足新版删除条件，7 项因执行中或结果未知而受保护；实际安装后数量可能随任务运行变化。

## 主要修改

- 支持“选择当前筛选全部”，不再局限于当前分页显示的 20 项。
- 草稿、待处理、已批准、排队中且从未开始执行的任务，可以直接批量删除，无需先逐项取消或归档。
- 已完成、失败、取消、阻止和已归档任务继续支持安全删除。
- 执行中、等待结果、等待审核以及外部结果未知的任务禁止批量删除，防止重复派发或丢失回执。
- 批量预检和提交绑定同一份任务资格签名；期间任务状态发生变化时拒绝提交并要求重新预检。
- 操作结果和跳过原因显示在批量工具栏附近，不再只显示在页面底部。
- 删除继续保留墓碑和审计记录；归档仍是可恢复的非破坏性选项。
- 同批纳入了无 ID 的 `workspace-v1` 新建项目修复，并增加生成项目 ID 后首次资料状态读取的回归测试。

## 建议人工验收

1. 打开“统一任务队列”，保留“待处理”筛选。
2. 点击“选择当前筛选全部 N 项”。
3. 点击“删除可安全清理的任务”，先核对预检中的可删除数和跳过原因。
4. 确认后检查成功提示；受保护任务应继续保留。
5. 新建一个 `workspace-v1` 学习项目，确认不再出现“项目 ID 无效”。

候选验收通过后，再决定是否进行代码签名和正式发布。
