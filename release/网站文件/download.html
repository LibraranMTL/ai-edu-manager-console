完整功能 · 主机与多终端

Windows 主机端

v0.21.6 · 自动执行与大型项目性能优化

完整功能，支持主机—多终端部署。大型项目资料改为 Worker 分批处理，后台任务会避让前台操作并自动错峰；未锁定执行器的任务会自动尝试其他可用 Agent，暂停学生不会继续生成周期任务。

新增知识点近 7 天活动趋势，并修复练习附件与作答反馈回归问题。安装版适合长期使用，便携 EXE 可直接运行，ZIP 便于保存和迁移。程序仍未进行 Authenticode 签名；升级前请退出旧版并备份资料。

资料采集与学习 · Windows / Android

学生端

Windows v0.18.6 · Android v0.6.27

Android 版以“搜集上传、主机连接、教育档案、学习行动”为四个核心入口。资料确认学生或项目后在线立即发送，网络中断时安全保留并自动重试；项目资料、项目综合报告和学情档案均从 Windows 主机读取并以只读 Markdown 弹窗显示。学习卡片作答可附加拍照图片或文件，由主机继续执行文字提取、OCR／视觉理解和反馈。

教师移动端 · Android

Android 教师端

v0.1.5

主要用于选择学生后采集、拍照和上传学习资料，导入主动分享或粘贴的智能体对话，以及查看主机已发布的学情报告。教师可按与学生端完全一致的表单谈话代填学习状态，并只读查看项目资料、项目综合报告和每周知识增长图；资料写入 Windows 主机中的对应学生或项目资料库。

完整功能 · 家庭平板单机

Android 单机版

v1.3.4 · 正式签名版

不依赖 Windows 主机，在手机或平板本机完成学生档案、资料收集整理、学情报告、学习行动、项目成果和加密备份。新资料会自动完成识别、理解和归档，只有学生或项目归属冲突才需要帮助；拍照时可选择保存到学生原始资料库或关联项目库。

“智能参考建议”统一提供学习卡片、项目灵感、升学路径、择校、专业、职业和比赛参考。可在建议设置中按学生开启或关闭联网参考建议、自动学习提醒和立即更新；建议用于启发与安排下一步，不替用户作决定。

本版使用产品长期证书，包名、递增版本号、v1/v2 签名和文件哈希已验证。覆盖升级前仍应先制作加密备份；早期测试版或 Debug 版签名不同，不可直接覆盖正式版。
