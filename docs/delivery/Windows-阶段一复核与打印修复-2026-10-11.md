## 3. 打印修复说明

- `electron/practice-card-export.cjs`：打印专用子窗口关联主机并显示/聚焦，字体与图片准备后才调用系统打印；仅打印需要可见窗口，PDF/PNG 导出仍后台完成。
- 无可用打印机时明确提示 Windows 添加设备或导出 PDF；取消、关闭窗口、同步异常、失败和迟到回调只结算一次，清理监听和临时文件。系统已接收不等于纸张已打印。
- `superseded` 历史卡片可输出；草稿、生成失败等状态仍禁止。结构化输出继续排除参考答案和个人依据；PDF/图片原件中已有答案不能自动移除。
- 主机“今日卡片”和“卡片资源”输出按钮增加准备中提示及准确回执文案。
- PDF 技能要求的逐页视觉检查发现横向固定书写区把页脚挤到第二页，已调整横向作答区高度和分页约束。样例横向结构化卡从 2 页变为 1 页；长卡仍允许正常分页。
- 按 React 性能规范将状态提示保持在用户点击事件内，不增加渲染期间的模型、网络或导出工作。

技术语义参考：[Electron webContents.print 文档](https://www.electronjs.org/docs/latest/api/web-contents#contentsprintoptions-callback)。打印回调的成功表示打印请求被系统处理，不证明物理输出。

## 6. print3 与优化项继续开发（取代上文首轮状态）

### 本轮变化

- 打印：先显示准备窗口，再等待卡片转换、字体和打印机；准备过程与打印机查询有超时及关闭处理。不再依赖出现故障的 Windows 原生打印弹窗，改为预览内显式选择本机打印机和份数。没有主动选择设备不会提交打印。支持保存 PDF 并调用本机阅读器；打印回执不明确时提示核对队列，不能显示已出纸。
- 学生端：增加本机打印、结构化卡片 PDF 导出。请求主机只读取有权查看的教学内容，不在主机触发打印；答案不混入普通打印文件。
- 离线草稿：文字、附件和练习快照按主机、数据代次、学生和固定卡片保存；重开可恢复。只有收到匹配提交编号的主机回执才清理。未提交草稿不自动作为正式作答或证据。
- 发布安全：课程单项发布核对预览时内容哈希；平台课程批次记录逐项结果，支持重启后继续未完成发布、只重试失败项。早期成功包重放不回滚后续成功课程。
- 管理体验：复用原编辑器提供编辑跳转，显示版本及受众摘要，不增加一级导航。
- 长内容：打印表格允许分页、重复表头，代码块换行；较宽公式提示横向纸张和 PDF 核对。未承诺任意超宽公式自动适配单页。
