## 2. 本批源码收尾

### 资料与来源

- 学生资料登记严格首次迁移到 Room，迁移错误回滚，不将损坏索引当空库覆盖。后续 Room 为权威状态，原 SAF JSON 是兼容清单副本。
- 清单副本写入失败保留已提交登记及修复标记；任务中心新增按当前学生修复副本的入口，不移动原件。
- 显式对话登记、消化/回收状态和删除记录迁入 Room；旧私有清单保留为兼容副本。缺少学生、重复身份或损坏旧清单拒绝迁移。
- 文件、拍照/分享导入、录音、屏幕/课程截图、显式对话共用来源事件登记合同，记录学生、内容哈希、来源事件、原件路径和项目。项目归属重新校验；重复事件内容冲突拒绝。
- 不同来源的相同内容保留独立来源事件，原件导入继续复用已验证内容；重复截图登记与中断导入恢复不把已处理状态改回待消化。
- 项目资料保留原有实际工作空间分类、人工优先、批量操作、固定版本和可回滚迁移基础，不改写为另一套用户目录。

### 模型与网关

- 任务 Agent、视觉、知识消化、学习卡片、规划和自动研究共用模型路由；原生设置可显式选择受控网关或个人 API 接口。
- 网关客户端通过非导出 Keystore EC 私钥签名，发送现有签名许可证、准确学生/设备、时间及 nonce；短时凭据仅在内存。
- 服务端新增实际密码学校验、管理员登记、学生席位、期限、设备公钥签名、nonce 重放保护、撤销检查、日/月安全限额和每许可证最多2个并发请求，默认关闭。
- 供应商适配器只在服务器读取 API Key，限定 HTTPS、不追随重定向、有界响应、来源回执、实际 Token 和供应商请求 ID；不接受任意远端图片或客户端自定义工具操作。
- 网关拒绝不回退个人 Key；明确的400/401/403/429拒绝与409/502或传输异常的未知结果分开记录，不自动重试。
- 文本、视觉、结构化输出、联网来源分别可用无学生资料的诊断检查并记录时间。视觉检查改为读取随机图形数量，不能只照提示回复固定字符串。当前没有宣称通用 Function Calling 已通过实际模型验收，也不开放任意工具执行。
- 本机按家庭设备限制月度文本/视觉/研究/ASR安全调用次数，任务中心可查看；权益失效阻止新模型请求，保留历史资料的只读浏览和原件分享/导出入口。这些次数不是费用报价或正式付费权益，仍需实际账单确定。

### 恢复、效率与体验

- 项目消化成功响应在 Room 缓存后再写 SAF 知识文件；相同固定版本、规则、模型和策略重放使用稳定操作 ID 和缓存 Markdown，失败后不会再次调用模型。未知调用仍阻止自动重复。
- 项目队列捕获启动时的确切学生，执行时重新校验项目成员；旧多学生任务不为网关猜测学生。
- 搜索索引复用未变化的大小/修改时间和既有摘要，仍限制5000文件、深度24和正文预算；打开原文/模型生成前继续核验实际哈希，不把文件时间当安全证明。
- 审核、行动、忽略和类型筛选沿用上一批实现；列表状态增加中文标签，历史原件可显式分享/导出。
- 备份恢复包括新增来源与业务记录，校验学生和不可变快照指纹；路径重映射不改写历史证据。换机后网关关闭，设备私钥不迁移。
- 旧页面同步资料 API 保留兼容桥接，Room 在后台执行，但首次大库迁移和旧页面等待耗时仍需真机性能测量；没有据模拟测试宣称零 ANR、零耗电或完整无障碍通过。
