# Windows 主机 0.23.4 自动化纠偏候选

## 基线与交付边界

- 源码基线：`bfdcc73d76f857861da168cfbb2853aec157ea95`，即 Windows 主机 `0.23.4` 公共课程候选分支的干净提交。
- 移植来源：`windows-automation-v2-20261104` 中已经有定向测试证据的 Windows `0.23.2` 自动化切片。
- 本轮只移植 WorkBuddy 运行状态和资料自动化闭环，不整体合并原开发工作区。
- `cloud-report-service` 的 material-index/OAuth、产品授权等未达到同等级候选证据的改动不进入本候选。
- 正式版更新清单不改写；制品状态保持 `candidate`，完成真人测试前不得标记为 `device_verified` 或 `released`。

## 纳入范围

1. WorkBuddy 外部启动侦测，将进程存在、安装状态、桌面 IPC、授权和派发资格分开表达。
2. 项目资料的主归属、多学生引用、暂定项目收件箱和稳定幂等投递。
3. 消化产物缺失时的最多两次受限修复，以及证据安全的任务积压收敛。
4. 分阶段自动化回退开关。
5. 项目历史回填的稳定批次和检查点合同。历史原件扫描仍为显式启用，默认关闭，本轮不自动启动历史回填。

## 验收口径

- 运行 WorkBuddy、自动化标志、产物修复、项目资料、智能收件箱和积压收敛定向测试。
- 运行 TypeScript 类型检查、Windows 资源审计和构建脚本自带的源码、暂存、秘密及包内资源审计。
- 候选标签使用 `0.23.4-corrective-automation-20261107-r1`，不得覆盖已有 `0.23.4` 候选或正式制品。
- 安装包只从已经生成并审计的便携候选运行时二次封装，不从另一份源码重新构建。
