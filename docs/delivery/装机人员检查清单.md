# AI教育管家装机人员检查清单

适用版本：

- Windows 主机控制台：0.6.6
- AI教育管家平板终端：0.5.1
- 旧 Android 控制台：0.2.3，仅用于内部装机和测试，不作为客户主推版本

适用对象：装机人员、售后人员、内部测试人员

## 1. 文件准备

- [ ] `AI-edu-manager-console-Windows-0.6.6.zip`
- [ ] `AI-edu-manager-tablet-terminal-0.5.1.apk`
- [ ] `edu-manager-version.json`
- [ ] 用户协议链接：`https://www.greatbg.com/download/agreement.html`
- [ ] 隐私政策链接：`https://www.greatbg.com/download/privacy.html`
- [ ] QClaw 下载地址：`https://qclaw.qq.com/`
- [ ] Tailscale Windows 下载地址：`https://tailscale.com/download/windows`
- [ ] Tailscale Android 安装包：`https://www.greatbg.com/download/tailscalev1.88.1_nbwe_7273.com.apk`

## 2. Windows 主机基础检查

- [ ] Windows 可正常开机
- [ ] 当前用户有写入 `D:\` 的权限
- [ ] 可创建目录：`D:\学生资料`
- [ ] 网络可用
- [ ] 系统时间正确
- [ ] 磁盘剩余空间充足
- [ ] 防火墙允许主机服务端口，默认 `18777`

## 3. Windows 主机控制台启动

- [ ] 解压并启动 `AI-edu-manager-console-Windows-0.6.6.exe`
- [ ] 界面不空白
- [ ] 首页显示版本 `v0.6.6`
- [ ] 系统设置中默认根目录为 `D:\学生资料`
- [ ] 首页默认进入“本机独立模式”
- [ ] 未选择“主机-平板模式”时，主机服务模块默认隐藏

## 4. 许可证检查

- [ ] 系统设置显示“许可证授权”区域
- [ ] 可输入授权码激活
- [ ] 可刷新授权状态
- [ ] 可移除本机许可证
- [ ] 客户版中不出现“生成授权码”
- [ ] 客户版中不出现“刷新发码记录”
- [ ] 客户版中不出现“导出发码记录”
- [ ] 未激活或许可证过期时，左侧正式功能显示锁定提示
- [ ] 未激活或许可证过期时，不能初始化、新建学生、接管知识库
- [ ] 未激活或许可证过期时，不能导入资料、启动主机服务、扫码配对或绑定平板
- [ ] 未激活或许可证过期时，不能写入 Agent 记忆、设定、规则文件或对话资料
- [ ] 未激活或许可证过期时，可以进入系统设置完成激活
- [ ] 未激活或许可证过期时，可以只读浏览已有教育档案和已有学情报告
- [ ] 激活成功后，初始化、导入资料、主机服务和平板绑定恢复可用

说明：授权码生成和发码记录管理仅在内部授权管理工具中执行，不交付给客户。

## 5. Agent 工具检查

- [ ] QClaw 检测、打开按钮可用
- [ ] Hohu 检测、打开按钮可用或显示未安装
- [ ] Marvis 检测、打开按钮可用或显示未安装
- [ ] OpenClaw 检测、打开按钮可用或显示未安装
- [ ] Tailscale 检测、打开按钮和下载入口可用

正式交付建议优先使用 QClaw；其他工具按客户实际安装情况配置。

## 6. 创建标准测试学生

建议创建测试学生：

```text
张三
```

确认生成：

```text
D:\学生资料\张三知识库
D:\学生资料\张三知识库\AGENT.md
D:\学生资料\张三知识库\张三原始资料库
D:\学生资料\张三知识库\张三学情分析汇总
D:\学生资料\张三知识库\输出结果
```

- [ ] 目录没有误写入 Downloads
- [ ] 目录没有误写入 App 临时目录
- [ ] 目录没有误写入 Marvis workspace
- [ ] 学生列表显示“标准知识库”

## 7. 接管已有知识库测试

如客户已有旧知识库，测试“接管已有知识库”：

- [ ] 可选择已有知识库根目录
- [ ] 可识别 `AGENT.md`
- [ ] 可识别原始资料库
- [ ] 可识别学情分析汇总
- [ ] 可识别输出结果目录
- [ ] 可选择 Agent 工具：QClaw / Hohu / Marvis / OpenClaw
- [ ] 接管时不移动、不复制、不删除旧文件
- [ ] 学生列表显示“接管知识库”
- [ ] 上传资料进入接管目录的原始资料库
- [ ] 查看档案读取接管目录的学情分析汇总

## 8. Soul 工作规则检查

复制 Soul 内容，确认包含：

```md
## 工作规则

该 Agent 的工作协议使用：D:\学生资料\张三知识库\AGENT.md
后续所有学习资料消化都围绕该学生知识库执行。
```

如为接管知识库，应显示接管目录下的真实 `AGENT.md` 路径。

## 9. QClaw Agent 配置

- [ ] 创建 Agent：`张三 AI教育管家`
- [ ] 粘贴 Soul / 人设内容
- [ ] 粘贴 Memory / 长期记忆内容
- [ ] 让 QClaw 执行对应学生的 `AGENT.md`
- [ ] QClaw 后续读写目录与控制台目录一致

## 10. 主机服务测试

- [ ] 首页选择“主机-平板模式”
- [ ] 点击“启动主机服务”
- [ ] 显示局域网地址
- [ ] 如安装 Tailscale，显示 Tailscale 地址
- [ ] 显示二维码和配对码
- [ ] 可复制平板连接信息
- [ ] 可运行主机服务诊断

## 11. 平板终端安装

- [ ] 安装 `AI-edu-manager-tablet-terminal-0.5.1.apk`
- [ ] 打开后名称为“AI教育管家平板终端”
- [ ] 不出现初始化、Agent 创建、Obsidian 授权、目录管理等管理员入口
- [ ] 用户协议和隐私政策在系统设置中可见
- [ ] 系统设置默认折叠技术连接区域
- [ ] 可切换页面布局和五色皮肤

## 12. 平板绑定主机

- [ ] 平板点击“扫码绑定主机”
- [ ] 可扫码连接 Windows 主机
- [ ] 扫码失败时可使用“粘贴连接信息”
- [ ] Windows 设备列表出现该平板
- [ ] 平板可读取授权学生列表
- [ ] 撤销设备后，平板请求失败并提示重新绑定

## 13. 设备授权测试

- [ ] 可为设备重命名
- [ ] 可设置允许访问全部学生
- [ ] 可设置默认授权新学生
- [ ] 可勾选具体学生访问范围
- [ ] 修改授权后，平板学生列表同步变化

## 14. 上传资料测试

至少测试：

- [ ] 拍照上传
- [ ] 选择图片上传
- [ ] 选择文档上传
- [ ] Downloads 最近文件上传
- [ ] 从文件管理器分享上传

确认：

- [ ] 文件进入对应学生原始资料库
- [ ] Windows 上传记录显示学生、设备、文件名、时间、状态
- [ ] 平板端显示上传、待消化、已消化和档案状态

## 15. 消化闭环测试

- [ ] 上传后待消化数量增加
- [ ] 复制资料消化指令
- [ ] 在 QClaw Agent 中执行
- [ ] QClaw 生成或更新学情分析汇总 Markdown
- [ ] Windows 刷新后可看到档案
- [ ] 平板刷新后可看到档案
- [ ] 消化完成状态可同步或手动确认

## 16. 档案浏览测试

Windows 和平板均检查：

- [ ] 资料摘要
- [ ] 综合汇总
- [ ] 问答精华
- [ ] 其他
- [ ] 全部文件
- [ ] 阅读模式
- [ ] 原文模式
- [ ] 文档数量较多时列表可滚动或可下拉选择
- [ ] Markdown 表格可正常显示

Windows 0.6.1 及后续版本需重点回归：教育档案中 Markdown 表格不再消失。

## 17. Obsidian 入口

平板端检查：

- [ ] 已安装 Obsidian 时可打开 Obsidian
- [ ] 未安装时提示并提供下载入口

## 18. 远程连接测试

如使用 Tailscale：

- [ ] Windows 已安装并登录 Tailscale
- [ ] 平板已安装并登录 Tailscale
- [ ] Windows 显示 Tailscale 地址
- [ ] 平板连接模式选择“局域网 + Tailscale”
- [ ] 局域网失败后可尝试 Tailscale 地址

## 19. 数据维护与备份

- [ ] 可执行“备份主机数据”
- [ ] 备份 JSON 包含学生索引、设备授权、上传记录、主机事件
- [ ] 已向客户说明：该备份不包含完整学生知识库文件夹
- [ ] 如需完整迁移电脑，另行备份 `D:\学生资料`

## 20. 更新检查

Windows：

- [ ] 当前版本 `0.6.6` 应显示已是最新版
- [ ] 旧版应提示升级到 `0.6.6`

平板终端：

- [ ] 当前版本 `0.5.1` 应显示已是最新版
- [ ] 旧版应提示升级到 `0.5.1`

更新清单地址：

```text

```
