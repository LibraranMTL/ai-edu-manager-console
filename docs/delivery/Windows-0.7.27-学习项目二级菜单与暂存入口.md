# Windows 0.7.27 学习项目二级菜单与暂存入口

## 本次调整

- 界面版本号不再写死，统一读取应用安装包版本。
- “学习项目”导航拆分为“新建学习项目”和“已有学习项目”两个二级菜单。
- 新建页只展示项目创建、已有文件夹接管和工作空间目录自定义能力。
- 已有页集中展示项目列表、仪表盘、知识关联、研究暂存、消化、审核和归档能力。
- 已有项目页增加“暂存资料进入项目原始资料库”操作引导和定位按钮。

## 暂存资料进入原始资料库

1. 打开“学习项目 > 已有学习项目”，选择一个项目。
2. 在“研究暂存层”导入资料。
3. 选择待处理资料，执行“接受并应用保存策略”。
4. 点击“晋升为正式资产”。
5. 系统将资料登记为正式资产，写入项目知识空间的“原始资料库”，并加入待消化清单。
6. 选择 Agent，复制消化命令并在对应 Agent 工具中人工执行。
7. 返回系统标记已提交并同步消化结果，进入知识审核与项目归档流程。

可信且明确属于核心来源的资料，也可以使用“直接导入原始资料库”绕过暂存筛选。
