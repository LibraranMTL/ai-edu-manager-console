# Windows 0.8.5 学习项目四步主流程

## 交付范围

本批次把已有学习项目页从多个平铺操作区收束为四步主流程：

1. 添加资料：扫描项目工作空间、导入研究暂存、直接采用核心资料或复用正式资产。
2. AI 整理建议：识别重复和资料价值，推荐采用、保留观察或排除，并给出默认保存策略。
3. 确认并消化：人工确认正式资料，登记严格消化批次，检查 Agent 回执并审核风险知识。
4. 完成项目：核对共享项目知识、每名学生的独立成长证据和归档贡献清单。

## 主要交互

- 页面依据真实项目状态显示“系统建议下一步”，每次只突出一个主操作。
- 四步导航显示候选资料、正式资料、待整理、待消化、待审核和待归档数量。
- 研究暂存区升级为资料整理向导；搜索、状态筛选、来源保存策略、排除和批量操作收纳到高级区域。
- 工作空间扫描与目录模板收纳到高级区域，项目工作空间和项目知识空间仍可直接打开。
- 扫描、整理、晋升、消化同步、知识审核和完成项目的结果在当前阶段就地反馈。

## 数据约束

- `analyzed`、`promoted` 和 `discarded` 均视为暂存环节已收口，不重复计入待整理。
- 资料加入项目知识库仍调用 0.8.4 的审核与晋升事务，不绕过资产、来源和消化批次协议。
- Agent 消化仍使用独立请求、严格逐文件回执和 SHA-1 校验。
- 项目归档与发布仍受统一完成闸门约束。
