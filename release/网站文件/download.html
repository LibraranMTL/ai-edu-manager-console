完整功能 · 主机与多终端

Windows 主机端

v0.19.10 · 快速截屏与会话批量管理

完整功能，支持主机—多终端部署。学习卡片自动沿用学生设置的主要学习语言与辅助语言，可切换查看正在进行的旧卡和待练新卡。学情、计划或语言变化时，仅在复核通过后替换尚未开始的待练卡，保留原卡片与作答记录；重复生成会明确提示复用结果。原有采集、规划与云端文档功能保持兼容。生成卡片仍需真实学习证据及可用且获授权的 Agent。

便携版无需安装，解压后直接运行 EXE。0.19.10 已获用户真机测试通过确认：快捷工具条可直接完成快速截屏；自动会话采集可按待投递、已投递、全部和回收站分类，并支持多选、跨页全选、批量投递、恢复和回收。正式 EXE 与已测试候选包二进制一致。程序尚未进行代码签名，首次运行可能出现 Windows 安全提示。升级前请关闭旧版并备份资料。

Android 单机版

v1.2.5 · 正式签名版

不依赖 Windows 主机，在平板本机完成学生档案、资料采集、OCR/视觉解析、知识消化、课程学习、成长模型、学情报告、学习项目和加密备份。1.2.5 完善成长证据审核、报告选择与证据回退，并改进报告打印准备和最近输出记录。

本版使用产品长期证书，包名、递增版本号、v1/v2 签名和文件哈希已验证。覆盖升级前仍应先制作加密备份；早期测试版或 Debug 版签名不同，不可直接覆盖正式版。
