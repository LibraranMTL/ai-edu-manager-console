# AI教育管家三端资料投递：Windows 0.9.6 / Android 0.5.9

## 本版目标

把产品交付结构统一为 Windows 主机端、Windows 学生端和 Android 学生端，同时让普通本地文件、自动投递文件夹和屏幕采集资料使用同一套归属规则：上传到学生原始资料库，或上传到该学生绑定项目的原始资料库。

## 主要变化

- 新增独立 Windows 学生终端，避免学生误入主机管理功能。
- Windows 学生终端支持手动多文件上传、屏幕截图采集和可选自动投递文件夹。
- Windows 主机本地导入资料时增加目标选择。
- Android 0.5.9 的普通文件和屏幕采集上传增加目标选择，并补充按钮操作反馈。
- 主机 API 对终端上传统一执行设备鉴权、学生授权、项目绑定、封存状态和文件限制校验。
- 所有终端上传记录学生、项目、设备、来源类型、采集会话和上传编号；项目资料到达后自动标记为待消化。

## 兼容与迁移

- 现有 Android 配对、二维码、六位配对码和粘贴连接信息继续兼容。
- 现有学生资料和项目资料目录不搬迁、不改 ID。
- Windows 学生终端与主机使用同一局域网连接机制，但安装包、应用名称和本地配置目录独立。
- 自动投递只记录已经成功送达的文件，不删除、移动或改写学生电脑上的源文件。

## 验收范围

1. 三端普通文件入口都能选择学生资料库或绑定项目资料库。
2. 未授权学生、未绑定项目和封存项目无法通过直接请求绕过限制。
3. 重复上传编号不产生第二份知识资产。
4. 项目资料上传后进入项目待消化状态，保留来源追踪信息。
5. Windows 自动投递重启后不会重复上传已成功文件，失败文件可以继续重试。
6. Android 上传按钮在按下、处理中、成功和失败时具有明确反馈。
