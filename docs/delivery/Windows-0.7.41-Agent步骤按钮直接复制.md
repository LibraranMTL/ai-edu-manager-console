# Windows 0.7.41 - Agent 步骤按钮直接复制

## 更新内容

- 右侧 Agent 工具连接区的每个步骤卡片现在都是复制入口。
- 点击步骤卡片会同时选中该步骤并复制对应指令。
- 高级编辑区修改过的指令会优先复制。
- 复制成功后显示明确提示，说明可粘贴到当前 Agent 工具。
- 移除右上角尺寸较小的独立复制按钮。

## 操作方式

1. 在“新建教育智能体”页面完成学生档案初始化。
2. 在右侧“Agent 工具连接（可选）”区域点击任意步骤卡片。
3. 将已复制的指令粘贴到所选 Agent 工具中执行。

需要调整指令时，可先打开“高级”编辑内容，再点击相应步骤卡片复制。
