# AI教育管家 License v3 开发与发布计划

**计划版本：2026-08-08**
**适用产品：Windows 主机端 0.16.5+、Android 单机版 1.1.1、License 管理工具 0.4.1**

## 1. 方案结论

采用无需授权服务器的单机激活方案。License 管理工具离线签发 RSA-SHA256 数字签名激活码，客户端只内置公钥并在本机验签。激活码明确绑定产品、设备码、有效期和学生席位，Windows 主机端与 Android 单机版不能混用。

Windows 主机端 0.16.5 起只接受 License v3，并且只信任安装包内置的官方公钥。旧版短码、License v2、无 Schema 本地授权对象、本地公钥文件和运行时环境变量均不能扩展客户运行时信任。唯一存量付费客户在升级前换发绑定当前主机设备码的 License v3；试用客户如需继续使用，重新申请限时 v3 试用码。私钥只保存在授权管理电脑，不进入源码、安装包或客户设备。

## 3. 授权字段

- `productId`：`WINDOWS_HOST` 或 `ANDROID_STANDALONE`；
- `deviceId`：客户应用显示的目标设备码；
- `maxActiveStudents`：允许存在的有效学生档案数量；
- `maxDevices`：当前单机方案固定为 1；
- `issuedAt`、`expiresAt`：签发和到期时间；
- `capabilities`：产品能力声明；
- `issuer`、`keyId`、`signature`：签发者、公钥标识和数字签名。

## 4. 客户使用流程

1. 客户安装对应正式版本，复制产品页面显示的设备码。
2. 销售或客服在 License 管理工具选择正确产品，录入设备码、学生席位和有效期。
3. 管理工具生成 License v3 激活码并留存签发记录，可直接显示或保存只包含完整 `AIE3...` 激活码的二维码。
4. Android 客户可摄像头扫码、从相册识别二维码或粘贴激活码；识别后仍在本机验签，全程不需要授权服务器。
5. 换机或恢复出厂设置时按售后规则作废旧记录并补发新设备激活码。
6. Windows 旧版授权升级时不自动转换；客服按原套餐、有效期和席位为目标设备换发 License v3。未换发时已有档案保持只读，不删除资料。

## 5. 发布验收门槛

- 全量自动测试通过；
- Android `check`、R8、APK Signature Scheme v2 和非 Debug 证书检查通过；
- 正式 APK 的版本、包名、证书指纹和 SHA-256 写入发布元数据；
- Windows ZIP/EXE 和 License 管理工具产物生成并记录 SHA-256；
- Windows 包内不得包含旧式共享密钥验证、License v2 激活入口、运行时公钥环境变量或本地公钥信任合并；
- 伪造本地授权对象、本地公钥文件、跨产品码、跨设备码和旧版激活码必须全部拒绝；
- 真机分别验证未激活拦截、正确激活、跨产品拒绝、跨设备拒绝、席位上限和升级保留数据；
- 未完成上述门槛时，不把候选产物标记为正式发布。
