# AI教育管家 Windows 主机版操作手册

适用版本：Windows 主机控制台 0.6.6  
配套版本：AI教育管家平板终端 0.5.1  
适用对象：运营人员、教育顾问、装机人员、管理员  
默认学生资料根目录：`D:\学生资料`

## 1. 产品定位

Windows 主机版是 AI教育管家的管理员端和本地服务端，负责创建学生知识库、管理 Agent 辅助内容、接收平板上传资料、浏览学情档案、管理设备授权和维护主机数据。

普通家长或学生日常只需要使用“AI教育管家平板终端”。初始化、Agent 设置、目录管理、主机服务、许可证激活等管理功能均放在 Windows 主机端。

## 2. 安装与启动

1. 使用交付包：`AI-edu-manager-console-Windows-0.6.6.zip`。
2. 解压后运行：`AI-edu-manager-console-Windows-0.6.6.exe`。
3. 首次启动后进入“系统设置”，确认学生资料根目录为：`D:\学生资料`。
4. 如客户已指定其他数据盘，可在系统设置中更换根目录。

建议将 Windows 主机控制台放在固定目录，例如：

```text
D:\AI教育管家\Windows主机控制台
```

## 3. 首页模式

首页提供两种使用模式：

- 本机独立模式：只在 Windows 电脑上创建知识库、导入资料和查看档案，不启动主机服务。
- 主机-平板模式：需要平板上传资料或查看主机档案时，手动启动主机服务。

默认进入本机独立模式。只有选择“主机-平板模式”后，首页才显示“主机服务”模块。

## 4. 创建学生知识库

进入“初始化教育管家”或“新建教育智能体”，填写：

- 学生姓名
- 年级
- 学校
- 当前目标
- Agent 工具
- 创建方式

创建方式包括：

- 创建标准新知识库
- 接管已有知识库

标准新知识库默认创建到：

```text
D:\学生资料\张三知识库
```

主要目录为：

```text
D:\学生资料\张三知识库\AGENT.md
D:\学生资料\张三知识库\张三原始资料库
D:\学生资料\张三知识库\张三学情分析汇总
D:\学生资料\张三知识库\输出结果
```

## 5. 接管已有知识库

如果客户已经通过 QClaw、Hohu、OpenClaw、Marvis 等工具创建过学生知识库，可选择“接管已有知识库”。

接管时需要填写或选择：

- 学生姓名
- 年级
- 学校
- 当前目标
- 已有知识库根目录
- Agent 工具
- Agent 类型
- Agent 名称或会话备注

接管原则：

- 不移动原文件
- 不复制原文件
- 不删除旧目录
- 只在控制台学生索引中登记真实路径

接管后，上传资料会写入该学生记录中的 `rawPath`，档案浏览会读取该学生记录中的 `summaryPath`，消化指令也会使用已有知识库的真实路径。

## 6. Agent 工具

Windows 主机端支持记录和引导以下 Agent 工具：

- QClaw
- Hohu
- Marvis
- OpenClaw

其中 QClaw、Hohu、OpenClaw 默认按“子 Agent”方式使用；Marvis 默认按“主对话 / 普通对话”方式使用。

控制台会根据工具能力生成对应的：

- Soul / 人设内容
- Memory / 长期记忆内容
- AGENT.md 工作协议
- 资料消化指令
- 咨询提示

## 7. QClaw 消化资料闭环

推荐资料处理流程：

1. 平板或 Windows 端上传学习资料。
2. 文件进入对应学生的原始资料库。
3. Windows 上传记录和学生待消化状态更新。
4. 在“教育管家问答”中复制资料消化指令。
5. 粘贴到对应 QClaw Agent 执行。
6. QClaw 更新学情分析汇总目录中的 Markdown 档案。
7. Windows / 平板刷新档案查看结果。
8. 必要时在 Windows 端标记或同步消化状态。

如果原始资料库没有新增资料，QClaw 应在 `log.md` 中记录“无新增资料”，不要重复生成摘要。

## 8. 主机服务与平板配对

需要平板协作时：

1. 首页选择“主机-平板模式”。
2. 点击“启动主机服务”。
3. 确认显示局域网地址、Tailscale 地址、配对二维码和配对码。
4. 平板端点击“扫码绑定主机”完成绑定。

主机服务默认端口：`18777`。如被占用，可在系统设置中调整。

Windows 端支持三类连接方式：

- 局域网地址
- Tailscale 地址
- 手动远程主机地址

平板端扫码后会优先尝试局域网地址，失败后按设置尝试 Tailscale 或手动地址。

## 9. 设备授权管理

绑定成功后，Windows 主机端可在“主机服务”区域查看设备。

可管理内容包括：

- 设备名称
- 在线 / 离线状态
- 最近访问时间
- 最近访问 IP
- 客户端信息
- 上传文件数量
- 授权学生范围

可执行操作：

- 重命名设备
- 撤销设备
- 允许访问全部学生
- 默认授权新学生
- 勾选具体可访问学生

如平板丢失、转让或误绑定，应立即撤销设备授权。

## 10. 查看教育档案

进入“查看教育档案”后，可按以下分类浏览：

- 资料摘要
- 综合汇总
- 问答精华
- 其他
- 全部文件

内置 Markdown 阅读器支持阅读模式和原文模式，并支持标题、列表、引用、代码、链接和基础表格。Windows 0.6.1 及后续版本修复了部分 Markdown 表格在教育档案中不显示的问题。

“全部文件”会显示真实 Markdown 文件树。系统会尽量隐藏或降低技术文件的展示优先级，例如 `AGENT.md`、`log.md` 和配置类文件。

## 11. 智能体知识管理

“智能体知识管理”是左侧一级菜单，默认折叠，包含：

- Agent 记忆管理
- Agent 设定管理
- Agent 规则文件管理
- AI 扫描导入
- 模板中枢

可用于归集不同 Agent 工具中的 Memory、Soul、人设、规则文件和会话资料。对于 AI 扫描结果，建议让 QClaw、Marvis、Hohu、OpenClaw 等工具先输出 JSON 结果，再导入控制台解析。

规则文件管理可维护当前学生知识库中的 `AGENT.md`、`Claude.md`、`Claud.md`、`AGENTS.md` 等规则性 Markdown 文件。

## 12. 许可证授权

客户版 Windows 主机端只提供：

- 输入授权码激活
- 查看授权状态
- 刷新授权状态
- 移除本机许可证

授权码生成、发码记录和导出记录已经从客户版中剥离，改由内部“AI教育管家授权管理工具”完成。平板终端跟随 Windows 主机授权状态，不单独收费。

### 12.1 未激活或许可证过期时的限制

Windows 0.6.6 起，客户版按商业销售版本要求启用更严格的授权限制。未激活或许可证过期时，系统只允许进行有限浏览和激活操作。

允许使用：

- 首页查看
- 系统设置中的许可证激活、版本检查、用户协议和隐私政策
- 已存在教育档案的只读浏览
- 已存在学情报告的只读浏览

禁止使用：

- 初始化教育管家
- 新建教育智能体
- 接管已有知识库
- 导入资料、添加来源目录、扫描来源目录
- 启动主机服务、扫码配对、平板绑定和主机 API 访问
- 资料消化提交、同步消化结果
- 学生资料保存、删除学生、迁移或重命名知识库
- 智能体记忆、设定、规则文件、对话导入等知识写入功能
- 备份恢复、重置 API Token、设备授权管理等正式运营功能

未激活状态下，左侧正式功能菜单会显示锁定提示；进入受限功能时会提示先到“系统设置”激活许可证。

### 12.2 激活后检查

激活成功后建议检查：

- 首页“授权状态”显示为有效
- “初始化教育管家”“资料收集与处理”“主机服务”等正式功能恢复可用
- 平板端重新连接主机后可正常读取学生列表和上传资料

## 13. 数据维护与备份

“备份主机数据”会导出轻量 JSON 备份，内容包括：

- 主机设置
- 学生索引记录
- 设备授权记录
- 上传记录
- 主机事件记录

注意：当前“备份主机数据”不打包完整学生知识库文件夹，也不会复制 `D:\学生资料` 中的图片、PDF、Word 或 Markdown 文件。完整迁移电脑时，应额外备份学生资料根目录。

恢复备份会覆盖当前学生索引、设备授权和上传记录，请谨慎操作。

## 15. 常见问题

### 平板无法连接主机

请检查：

- Windows 主机服务是否已启动
- 平板和电脑是否在同一局域网
- Windows 防火墙是否允许端口 `18777`
- 是否需要使用 Tailscale 地址
- 设备 token 是否被撤销

### 上传成功但 Agent 看不到资料

请检查：

- 上传文件是否进入该学生的原始资料库
- 学生是否为接管知识库，路径是否登记正确
- QClaw / Hohu / OpenClaw / Marvis 是否使用正确的 `AGENT.md`
- Soul 工作规则中的工作协议路径是否对应当前学生知识库

### 档案看不到最新内容

请检查：

- Agent 是否已完成资料消化
- 学情分析汇总目录是否生成 Markdown 文件
- Windows 或平板是否点击了刷新
- 当前分类是否过滤掉目标文件，可切换到“全部文件”查看
