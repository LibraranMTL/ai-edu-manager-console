AI教育管家 Windows 学生端操作手册

适用版本：Windows 学生终端 0.14.2

配套主机：Windows 主机 0.14.2

1. 产品定位

Windows 学生端只承担学生进入、资料采集与投递，以及只读查看本人成长模型、报告、档案和关联项目知识。档案、项目、知识治理和发布仍由 Windows 主机端管理。

2. 首次连接

  1. 运行 Windows 学生端，不要把主机版安装给学生。
  2. 主机进入“主机-终端模式”并启动服务。
  3. 学生端可选择局域网或 Tailscale，使用附近主机、固定机器码或主机提供的连接信息发起连接。
  4. 主机确认后把设备设为个人终端或共享终端。

固定机器码仅用于识别设备，不需要 PIN。Tailscale 页面可检测安装状态并提供打开与下载入口。

3. 个人终端与共享终端

  • 个人终端固定绑定一名学生，适合一人长期使用，并支持自动投递文件夹。
  • 共享终端每次输入或扫描个人 ID，退出后再交给下一位学生，不持续监听自动投递文件夹。

4. 选择资料归属

普通文件和屏幕采集均可选择学生原始资料库或当前学生绑定且未封存的项目原始资料库。主机会再次校验学生与项目归属。

5. 上传与自动投递

“选择并上传文件”支持常见图片、PDF、Office、文本、Markdown、CSV 和 ZIP。个人终端还可选择自动投递文件夹，稳定文件会幂等上传，失败可重试，且不会删除本地文件。

6. 屏幕资料采集

进入学生空间后选择屏幕或窗口、资料目标并开始采集。会话开始时冻结当前学生和目标，共享终端必须结束采集后才能退出。

7. 资料进展与每日提醒

首页显示已提交资料、已完成知识化、近 7 天新增和近 30 天活跃频率；当天尚未提交时显示一次“提交本日学习资料”轻提醒。

8. 成长模型、学情报告、教育档案与项目知识

  • “查看成长模型”读取当前学生的能力画像、项目贡献和近期成长证据；只读展示，不触发评估、审核或重新分析。
  • “查看学情报告”读取主机已发布的当前学生报告。
  • “查看教育档案”读取当前学生可访问的 Markdown 档案。
  • “查看关联项目知识”列出当前学生绑定项目中的公开 Markdown；已封存项目仍可只读查看。
  • 主机按当前学生会话再次校验学生和项目范围，学生端不能读取其他学生或未关联项目，也不能修改或发布项目。

9. 上传反馈与退出

上传中会显示进度，失败文件保留本地。共享终端退出后清空学生、项目、档案、报告、正文和待传队列。

10. 常见问题

  • 看不到项目：确认项目已绑定当前学生。上传目标不显示已封存项目，但只读知识列表仍可显示。
  • 扫描不到主机：检查主机服务、同一局域网、Windows 防火墙专用网络或改用 Tailscale。
  • 上传失败是否删除本地文件：不会。
