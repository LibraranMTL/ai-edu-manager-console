# AI教育管家 Android 单机版操作手册

**适用版本：Android 单机版 1.2.2 正式版（知识协作功能按候选验收范围提供）**
**适用设备：Android 8.0 及以上的家庭平板**

## 1. 产品定位

Android 单机版是一套不依赖 Windows 主机的完整教育管家。学生档案、学习资料、知识库、成长模型和学情报告都保存在用户明确授权的本机目录中，适合单个家庭在一台平板上长期使用。

单机版不加入家长角色、终端权限审批或普通学生端协议。1.2.2 可以作为完整知识节点与受信任的 Windows 主机建立知识协作；Android 单机版之间的附近协作仍按候选验收范围提供。教育业务始终由“AI教育管家”承担，PalmClaw、MobileClaw、豆包、ChatGPT/Codex 以及兼容接口的 Agent 只作为问答、OCR/视觉理解或受控资料处理入口。

主要功能包括：

- 新建或接管学生学情档案；
- 文件资产中心、本机文件导入、拍照和连续屏幕采集；
- 设备本地 OCR、可选视觉理解和资料消化；
- 导入并学习 Windows 主机端导出的平台课程包；
- 检查并拉起 PalmClaw、MobileClaw、豆包或 ChatGPT/Codex，并主动保存选定对话历史；
- 成长模型、学情报告、学习项目和项目知识库；
- 与 Windows 完整知识节点建立设备信任，并按精确学生 ID 双向同步已确认知识、成长模型、已发布报告和教育档案；
- 界面皮肤、横竖屏布局、Agent 配置、检查版本更新、加密备份与恢复。

## 2. 安装与首次设置

1. 安装使用同一产品长期证书签名的 Android 单机版 1.2.2 正式 APK。Android Debug APK 只能用于结构检查，不能覆盖正式版，也不能作为真机升级验收包。
   注意：如果平板已安装早期测试版，且系统提示无法覆盖安装，请先在旧版执行“系统设置 → 加密备份”，将备份包复制到独立位置，再卸载测试版、安装正式版并恢复；不同签名证书的 APK 不能直接覆盖。
2. 首次启动进入“Android 单机版产品激活”。点击“复制设备码”，把设备码发送给销售或客服。
3. 销售或客服可发送完整激活码或二维码图片。二维码在另一台设备上时点击“扫码激活”；二维码已保存在本平板时点击“从相册识别二维码”。识别后确认激活，系统在本机校验产品、设备码、数字签名、有效期和学生席位。也可以继续使用“从剪贴板粘贴 → 激活并进入教育管家”。全程不需要连接授权服务器。
4. 激活成功后进入“教育档案”，点击“设置新建档案保存位置”。
5. 在 Android 系统目录选择器中选择一个长期保留的资料根目录，并确认授权。
6. 建议使用设备内部存储中的独立目录，不要选择临时缓存目录；空间不足时可选择受系统支持的外置存储目录。
7. 进入“系统设置”，根据需要选择界面皮肤和页面布局。

应用只访问你在 Android 系统选择器中明确授权的目录。卸载或清除应用数据前，请先制作加密备份。

激活码与本机设备码绑定，只能用于对应平板。相同正式签名的应用升级不会改变设备码；恢复出厂设置、改变 Android 用户空间或更换平板后可能需要联系客服补发。达到授权学生席位后，新建、接管和学生端迁移会停止，但已有档案仍可浏览和备份。

“扫码激活”只在用户点击后申请相机权限；拒绝权限时仍可从相册识别或粘贴激活码。摄像头画面和所选二维码图片只在本机内存中识别，不上传、不保存。二维码被转发到其他设备也不能绕过设备绑定。

### 从 Android 学生端一键升级

如果本平板原来使用 Android 学生端，并且完整学生档案仍在 Windows 主机：

1. 在 Android 学生端进入准确学生空间，打开“系统设置 → 一键升级为 Android 单机版”。
2. 学生端请求 Windows 主机固定当前学生快照，然后自动拉起本单机版。
3. 在本单机版中选择一个空目录作为该学生的完整档案目录。
4. 等待下载、逐文件 SHA-256 校验和写入完成。系统保留原学生 ID，并接管教育档案、资料、成长记录、学情报告及关联学习项目。

迁移包由单机版直接从主机下载，不需要用户手工导出或选择 ZIP。迁移操作本身是一次性复制，不会自动建立长期同步；如需后续共享已确认成果，应在迁移完成后另行进入“系统设置 → 知识协作”建立设备信任和学生映射。

### 从 Windows 主机通过 U 盘迁入大量资料

学生达到约 1000 个文件或 3 GB 时，优先在 Windows 主机的准确学生档案中点击“导出到 Android 单机版（U盘）”，再在本机进入“教育档案 → 从 U 盘迁移并接管”。核对学生 ID、文件、项目和课程数量后，选择一个空目标目录。

目标目录选择完成后，教育档案页面立即显示迁移状态卡，包括当前阶段、文件数、总容量、百分比、已用时间和当前大文件字节进度。Android 通知权限被拒绝不会影响应用内进度。切换页面或应用后返回时，页面会从迁移日志恢复状态；U 盘断开或应用中断后，使用“继续上次 U 盘迁移”接续已经校验完成的文件。

## 3. 首页导引

首页按当前资料状态提供六个入口：

- 添加资料：进入本机导入、拍照或连续屏幕采集；
- 处理中：查看等待 OCR、消化或整理的资料；
- 需要补充：检查 OCR 失败或视觉模型不可用的资料；
- 知识更新：查看教育档案和学习项目中的最新沉淀；
- 成长变化：查看有来源、可审核的成长证据；
- 报告与档案：进入学情报告或教育档案。

首页显示学生档案、学习项目、待处理资料和已完成 OCR 数量，便于判断下一步操作。

## 4. 教育档案

### 新建学情档案

1. 先设置新建档案保存位置。
2. 点击“新建学情档案”，填写学生姓名；年级、学校和学习目标可按需填写。
3. 系统自动建立与 Windows 主机版兼容的学生知识库、原始资料库、学情分析汇总、`AGENT.md`、`index.md` 和 `log.md`。
4. 在“已有学情档案”中点击学生卡片，可渲染浏览该学生的 Markdown 档案。

### 接管已有学情档案

1. 点击“接管已有学情档案”，填写学生信息。
2. 选择已有学生档案目录并授权。
3. 核对扫描结果后确认接管。系统只补齐缺失结构，不覆盖已有 `AGENT.md`、`index.md`、`log.md` 或原始资料。

每名学生使用独立学生 ID 和独立目录。导入、查询、成长证据和报告都必须先选择准确学生，不能跨学生回退。

在“已有学情档案”中点击学生可进入知识库分类浏览，按资料摘要、综合汇总、问答精华、成长模型、学情报告、项目贡献和全部文件查看 Markdown 或原始资料。长按学生卡片可以删除档案：默认只解除本机登记；只有再次明确确认时才删除已授权目录中的该学生资料，删除前应先完成备份。

### 与 Windows 主机或 Android 单机版建立知识协作

知识协作只适用于完整 Windows 主机端和 Android 单机版。普通 Windows/Android 学生端继续使用原有主机连接方式，不注册为知识协作节点。

1. Windows 主机与平板优先连接同一局域网；跨网络使用时先确认两端的 Tailscale 已在线。
2. Windows 主机进入“系统设置 → 知识协作”，创建设备连接。Android 可以扫描连接二维码、输入六位临时码，或粘贴完整连接信息。
3. Android 进入“系统设置 → 知识协作”，完成连接并核对设备名称。设备只需配对一次。Android 单机版之间测试时，先在接收端点击“开启附近接收”或“生成本机邀请二维码和六位码”，再由另一台设备扫码、输入六位码或粘贴完整连接信息。
4. Windows 针对需要共享的学生创建学生映射邀请；Android 必须人工选择本机准确学生，系统不会按姓名猜测。
5. 映射生效后，可在“共享学生”卡片点击“立即同步”。手工大文件同步会显示持续通知；后台也会低频检查并在断网后继续。
6. 可以独立暂停、恢复或解除某个学生共享，也可以暂停或撤销整台设备。解除学生共享或撤销设备不会删除已经接收的本地档案；设备撤销后必须重新配对。

自动同步范围仅包括已确认知识、成长模型、已发布学情报告和教育档案。原始资料、草稿、待审核报告、冲突副本、回收副本、API Key、License、设备密钥和本机绝对路径不会发送。顺序更新可自动前进；双方并发修改时保留本地正文并建立冲突副本；远端删除先进入可恢复回收区。

单个文本文件上限为 64 MB；单一同步范围最多支持 20000 个文本文件。达到上限或文件过大时会明确显示异常，不会静默标记为同步完成。

## 5. 资料收集与文件资产中心

进入“资料收集与处理”后，可以使用：

- 文件资产中心：按学生查看资料名称、来源、处理状态和 OCR 结果，失败项可重新加入待处理；
- 浏览原始资料库：在应用内按目录只读浏览当前学生的原始文件，并调用本机查看应用打开原文件；
- 本机导入：选择一个或多个文件，或直接拍照导入；
- 连续屏幕采集：采集其他学习应用或网页中的学习画面；
- OCR / 视觉解析资料：可多选，单批最多处理 200 份；
- 查看 OCR 识别结果；
- 导入智能体对话历史：与“AI 助手问答”共用同一套明确学生/项目归属、原文哈希和后续消化流程；
- 消化资料：只列出待消化、处理失败或需要补充的资料，可按明确勾选批量消化；
- 查看消化记录：按时间查看资料名称、学生/项目归属、消化时间、状态、摘要、输出文件和失败原因。

导入前必须先选择资料归属学生；如资料属于学习项目，再选择对应项目。系统复制资料到该学生的原始资料库，不删除设备中的原文件。

## 6. 连续屏幕采集

1. 在“资料收集与处理”点击“连续屏幕采集”。
2. 选择学生；需要时选择关联学习项目。
3. 阅读用途提示并继续，Android 会显示系统录屏授权。
4. 授权后，采集期间会持续显示通知；可从应用或通知暂停、继续和结束。
5. 已保存截图进入当前学生的原始资料库和文件资产中心。

同一时间只允许一个学生的采集任务。Android 系统的录屏授权不能备份，设备重启或重新开始任务后需要再次确认。

## 7. OCR、视觉理解与资料消化

### 仅本地 OCR

“仅本地 OCR”在设备上处理图片和 PDF，不把页面发送给外部模型。完成后可通过“查看 OCR 识别结果”渲染浏览 Markdown 结果，并结合原文件人工核对。

### OCR + 视觉理解

视觉理解会把压缩后的预览页发送给“系统设置”中配置的视觉模型。文本模型和视觉模型可以分别填写；视觉模型必须实际支持图片输入。若视觉请求失败，本地 OCR 结果仍会保留。

### 消化资料

1. 先完成必要的 OCR 或文档解析。
2. 点击“消化资料”，在包含学生姓名、文件名和处理状态的列表中多选资料；也可从首页“处理中”或“需要补充”直接进入对应队列。
3. 系统按每名学生目录内的 `AGENT.md` 规则分别执行，更新 LLM Wiki / KnowledgeEngine 索引、声明、来源和日志。单批最多 200 份，失败资料不会阻断其他学生组。
4. 资料原文保留，候选结论需要审核后才能进入成长模型或正式报告。

已成功消化且没有被重新标记为“需要补充”的资料不会继续出现在选择框中。进入“系统设置 → 自动消化资料”可以开启每日定时任务，设置执行时间、网络条件、是否仅充电时运行，以及每名学生单次处理上限。自动任务仅在已启用任务 Agent、设备网络满足设定条件时执行；它与手工消化使用相同的 `AGENT.md`、学生隔离、审计和失败重试规则，不会后台读取其他 App 的私有资料。

课程中心和“资料收集与处理”发起的屏幕采集现在使用同一套原始资料登记流程。课程截图仍保存在“课程采集”子目录，同时会出现在首页状态、文件资产中心和资料处理队列；升级后首次进入“资料收集与处理”会检查并补登记旧版已完成课程采集记录，不移动或重写原图。

## 8. 课程中心

Android 单机版可以导入 Windows 主机端平台版导出的 `.edu-coursepkg` 课程包。课程包应同时包含目录、课程介绍、课程图片、允许访问的域名和签名信息；图片缺失时课程卡片只能显示文字占位。

导入步骤：

1. 进入“系统设置 → 高级设置 → 导入离线平台课程包”。
2. 选择 Windows 主机端导出的课程包，等待签名、哈希和目录校验。
3. 回到“课程中心”，点击“查看和学习平台课程”，选择学生和课程。
4. 课程页面打开时，可选择并启动屏幕采集。

课程采集提供“智能混合（推荐）”“画面变化时采集”和“固定间隔（每 30 秒）”三种模式。只有用户点击开始并通过 Android 系统授权后才会采集；可从持续通知暂停或结束。

## 9. AI 助手与对话历史

“AI助手问答”可以拉起本机已安装的 PalmClaw、豆包、MobileClaw 或 ChatGPT/Codex。若应用未安装，教育管家会提示并允许打开预置的官方安装入口；网页只用于下载安装，不能替代本机 App 对话。

对话历史不会自动读取其他应用的私有聊天数据库。需要保存时：

1. 在 PalmClaw、豆包或其他 Agent 中主动复制、导出或分享当前/选定对话。
2. 回到“AI助手问答 → 导入智能体对话历史”。
3. 选择粘贴文字、导入 `.md`、`.txt`、`.json` 文件，或输入不需要登录的公开 HTTPS 对话链接。
4. 选择对话来源、准确学生，以及学生对话历史或关联项目原始资料库。
5. 在“管理已保存对话历史”中核对保存结果。

每条对话会显示来源、学生或学习项目归属，以及“未消化、处理中、已消化、处理失败”状态。点击记录后可以：

- 浏览并渲染保存的 Markdown 原文；打开前会重新校验 SHA-256，避免把被替换的文件作为学情证据；
- 让任务 Agent 按归属范围的 `AGENT.md` 进入消化流程，失败后可以重试；
- 查看已完成的 Markdown 消化结果；学生范围只生成有原文证据的候选声明，项目范围只写入项目知识库；
- 将记录移入回收站；没有消化结果、候选或已采用依赖时，才允许在回收站永久删除，并保留不含原文的哈希删除审计。

进入“AI助手问答 → 智能体对话知识管理”后，可按学生查看“收件箱、待处理、候选知识、已归档、回收站”。对话消化会把学习事实、概念、实体、问答、行动和成长证据先放入候选区；候选可编辑、确认采用、标记冲突、驳回、过期或恢复，最多一次确认 50 条。确认采用会写入带来源 URI 和原文哈希的受管知识记录，之后仍可撤回；候选编辑不会改写原始对话。

处理中记录不能移入回收站；已消化原文即使移入回收站，也会继续保留作为知识证据，不能直接永久删除。这样可避免学情结论失去来源。旧版本已经消化但没有候选索引的记录会保留在“已归档”，不会依据摘要反推不存在的候选知识。

## 10. 成长模型与学情报告

成长模型是长期事实层，只接收有来源、可审核的成长证据。可以查看摘要、添加成长证据候选、审核候选并重建结构化索引。

学情报告包括整体画像、历史变化、每周行动建议和阶段总结。生成报告草稿后需要在本机审核确认，正式报告只引用成长模型中的已确认证据。点击已有报告可渲染浏览 Markdown 内容。

## 11. 学习项目

### 新建学习项目

填写项目名称、类型、说明、目标和绑定学生。若尚未设置学生档案资料根目录，页面会直接打开 Android 目录选择器；授权后系统继续建立项目原始资料库、项目知识库、控制目录和项目 `AGENT.md`，无需返回教育档案重复操作。

### 接管已有项目知识库

选择已有知识库目录并授权。若学生档案资料根目录尚未设置，页面会先请求选择根目录并在授权后继续接管。系统保留原文件，只补齐项目运行需要的缺失结构。接管后应核对绑定学生和项目目录，避免把项目知识写入错误学生档案。

在“已有学习项目”中点击项目卡片，可渲染浏览项目 Markdown 知识。

## 12. Agent 配置

### Agent 工具适配

1. 进入“系统设置 → Agent 工具适配”。
2. 页面会分别检查 PalmClaw、MobileClaw、豆包和 ChatGPT/Codex，显示“已安装”或“未安装”。
3. 已安装的工具可以直接点击“打开应用”；未安装的工具可以点击“官方下载”。
4. 安装完成后返回此页面，点击“重新检查”。

安装检查只判断本机是否存在可启动的应用，不读取 Agent 账号、对话历史或其他 App 的私有数据库。官方下载按钮只打开应用内预置并校验过的 HTTPS 官方站点、官方仓库或官方应用商店地址。

### 任务 Agent 服务

1. 进入“系统设置 → 配置或修改本地任务 Agent”。
2. 填写完整的 OpenAI 兼容 `chat/completions` 地址、文本模型名称和 API Key。
3. 需要视觉理解时，另填实际支持图片输入的视觉模型名称。
4. 安全保存后点击“测试文本 / 视觉 Agent”。系统先发送最小文本请求，再用应用内生成的 128×128 非学生测试图单独验证视觉模型，不读取或上传学生资料；文本通过而视觉失败会分别显示。
5. 参数变化时可直接重新打开配置并修改；不再使用时点击“停用本地任务 Agent”。

API Key 使用 Android Keystore 加密保存，不进入备份、日志或课程包。服务返回 HTTP 400 时，通常表示模型不支持当前多模态消息格式，应改用兼容的视觉模型，而不是删除已经完成的本地 OCR 结果。

## 13. 界面与页面布局

系统设置支持紫色、粉色、绿色、蓝色和橙色皮肤，五套皮肤都使用高对比深色背景和各自的强调色。页面布局支持横屏、竖屏和自适应；设置后应用重新载入界面。横屏使用紧凑左侧导航和多列方块操作卡片，竖屏及较小屏幕会自动减少列数。左侧导航中的“系统设置”固定在底部，其他栏目可滚动；顶部“当前学生”可快速切换准确学生范围，避免反复弹出学生选择框。

## 14. 加密备份与恢复

### 换新平板：整机迁移（大量资料推荐）

整机迁移适合平板换机，也适合包含上千张照片或数 GB 文件的长期家庭资料库。它使用 U 盘目录逐文件复制，不生成大型 ZIP，并且支持中断后继续。

旧平板导出：

1. 进入“系统设置 → 设备迁移与备份 → 换新平板：导出整机迁移目录”。
2. 阅读排除项说明，选择 U 盘上的空目录。
3. 保持 U 盘连接，通过持续通知查看文件数和容量进度；中断后回到系统设置点击“继续上次整机迁移”。
4. 完成后安全弹出 U 盘。不要修改迁移目录中的 `migration.json`、`manifest.json`、`manifest.sha256`、`payload` 或 `.edu-manager`。

新平板接管：

1. 安装不低于来源版本的正式签名 APK，先使用新平板设备码完成独立激活；激活码不会随资料迁移。
2. 确认新单机版还没有学生档案和学习项目；整机接管不合并两套家庭资料库。
3. 进入“系统设置 → 在新平板恢复并接管”，选择 U 盘整机迁移目录。
4. 核对学生数、项目数、文件数、容量和来源版本，再选择本平板上的空资料目录。
5. 等待全部文件完成 SHA-256 校验、业务状态提交和旧 URI 重映射。学生 ID、项目 ID、课程状态、对话历史、成长模型与学情报告保持不变。
6. 完成后进入“配置或修改本地任务 Agent”，核对已迁移的接口和模型名称，重新填写 API Key 并测试连接。

不会迁移：License、旧设备码、Agent API Key、Android Keystore 密钥、旧 SAF 目录授权、录屏授权、缓存、迁移日志和知识协作设备绑定。界面皮肤、页面布局和 Agent 非秘密接口/模型参数会迁移。新平板上的激活码学生席位必须不少于迁移目录中的学生数量。

原“加密备份/备份恢复”继续用于长期归档、离线保管或小规模恢复；大资料换机优先使用整机迁移目录。

### 制作备份

1. 进入“系统设置 → 加密备份”。
2. 设置至少 8 个字符的备份密码。
3. 把迁移包保存到下载目录、U 盘或其他独立位置，不能保存在正在备份的资料根目录内。
4. 等待逐文件加密和 SHA-256 校验完成，再安全复制备份包。

### 恢复备份

1. 在新设备安装不低于备份来源版本的正式 APK。
2. 点击“备份恢复”，选择迁移包并输入原密码。
3. 选择一个空目录作为恢复目标。
4. 恢复完成后重新配置 Agent API Key，并重新授予需要的屏幕采集权限。

备份不包含 Agent API Key、Android 签名密钥、录屏授权和失效的旧目录授权。忘记备份密码将无法解密，产品方也不能代为恢复。

## 15. 常见问题

### 已有教育档案或学习项目无法打开

确认原目录仍在、Android 目录授权没有被撤销，然后点击对应学生或项目卡片。Markdown 浏览页只读取当前学生或项目授权范围内的文件。

### OCR 完成但视觉理解失败

先在“查看 OCR 识别结果”确认本地结果已保存，再检查视觉模型名称和接口是否支持图片输入。文本连接测试通过不代表视觉模型一定兼容。

### 课程图片不显示

重新从 Windows 主机端导出包含课程图片的完整课程包，并重新导入。只有图片地址、没有图片文件的离线包无法在单机端稳定显示封面。

### 屏幕采集一直显示 0

确认已通过 Android 系统录屏授权、通知栏存在持续采集通知，并让课程画面发生变化或等待固定间隔。若服务未启动、授权被系统撤销、投影回调失败或图片写入失败，状态卡会显示具体阶段和最近错误；按提示重新授权或重新选择资料目录。受 DRM 保护或系统禁止截屏的页面可能无法采集。

### Agent 工具无法打开

进入“系统设置 → Agent 工具适配”重新检查。已安装但无法打开时，先在 Android 桌面独立启动一次；显示未安装时，可使用“官方下载”进入 PalmClaw、MobileClaw、豆包或 ChatGPT/Codex 的官方安装入口。教育管家不会读取这些应用的私有数据。
